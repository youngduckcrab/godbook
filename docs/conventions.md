# 표기와 약속

작성자, 검토자, 출처 준비자가 모두 읽는다. 이 사이트에서 이미 정해진 것을 모아 둔 문서다. 정확한 문구는 해당 항목의 `:::statement`가 기준이다. 여기 적힌 것과 항목이 다르면 항목이 맞고, 이 문서를 고쳐야 한다.

## 표기

| 뜻 | 표기 | 비고 |
|---|---|---|
| 부정, 그리고, 또는 | $\lnot$, $\land$, $\lor$ | 출처(Hammack)는 부정을 ∼ 로 쓴다 |
| 조건문 | $\Rightarrow$ | |
| 논리적 동치 | $\equiv$ | 출처는 = 로 쓴다. 합동 $a \equiv b \pmod n$ 과 기호가 같으므로 문맥을 밝힌다 |
| 한정 기호 | $\forall x \in X,\ P(x)$ | 여러 변수는 처음 쓸 때 줄임임을 풀어 준다 |
| 여집합, 멱집합, 차집합 | $A^c$, $\mathscr{P}(A)$, $A - B$ | |
| 자연수 | $\mathbb{N} = \{1, 2, 3, \dots\}$ | 0을 포함하지 않는다 |
| 나누어떨어짐 | $a \mid b$ | $b = ac$ 인 정수 $c$ 가 존재 |
| 최대공약수 | $\gcd(a, b)$ | 둘 다 0 은 아닌 정수에 대해서만 정의. 1 이면 서로소 |
| 유한 곱 | $a_1 a_2 \cdots a_n$ | 정수의 곱. 실수의 곱은 아래 "실수의 유한 곱". `finite-product`에서 재귀적으로 정의. 열은 함수 {1, …, n} → ℤ. 성질 (P1)–(P5). 빈 곱은 정의하지 않는다. 항끼리 곱한 열(`finite-product-of-products`), 재배열(`rearranging-a-finite-product`), 공집합이 아닌 유한한 정수 집합 위의 곱(`product-over-a-finite-set`)이 있다 |
| 처음 n 개의 자연수 | $\{1, \dots, n\}$ | 정수 n ≥ 0 에 대해 {i ∈ ℤ : 1 ≤ i ≤ n}. n = 0 이면 공집합. `finite-set`에서 정의 |
| 원소의 개수 | $\lvert A \rvert = n$ | 유한집합에만. 전단사 {1, …, n} → A 가 존재. n 이 하나로 정해진다는 것과, 유한집합에서는 =, ≤, < 가 전단사·단사의 뜻과 정수의 뜻으로 일치한다는 것은 `number-of-elements-is-unique` |
| 계승 | $n!$ | n 은 자연수. 열 1, 2, …, n 의 곱(`factorial`). 0! 은 정의하지 않는다 |
| 오일러 피 함수 | $P_n$, $\varphi(n)$ | P_n = {a ∈ ℤ : 1 ≤ a ≤ n, gcd(a, n) = 1}, φ(n) 은 그 원소의 개수(`euler-phi-function`). φ 의 곱셈성과 φ(p^k) 는 아직 없다 |
| 실수의 뺄셈·나눗셈 | $a - b$, $a/b$ | a + (−b), a·b⁻¹ (b ≠ 0). `real-number-arithmetic`. 1/2 는 2⁻¹ |
| 벡터공간의 연산 | $u + v$, $\alpha v$ | "덧셈"과 "스칼라배". 스칼라는 ℝ 만 쓴다. 영벡터는 $0_V$ (문맥이 분명하면 0) |
| 함수의 공간, ℝⁿ | $\mathbb{R}^X$, $\mathbb{R}^n$ | ℝ^X 는 X 에서 ℝ 로의 함수 전체. ℝⁿ = ℝ^{{1,…,n}} (n 은 자연수). (x₁, …, xₙ) 은 i 에서의 값이 x_i 인 함수. 이 강의는 ℝ × ℝ 를 ℝ² 로 쓰지 않는다 (`real-function-space`) |
| 벡터의 열 | $v_1, \dots, v_n$ | {1, …, n} 에서 V 로의 함수. 길이 0 인 빈 열을 허용하고 같은 벡터가 되풀이되어도 된다. 벡터의 모임은 집합이 아니라 열로 다룬다. "덧붙인 열", "k 번째 항을 지운 열"은 `finite-sum-of-vectors` |
| 벡터의 유한 합 | $v_1 + \dots + v_n$ | 재귀로 정의. 빈 열의 합은 $0_V$. 실수의 유한 합은 ℝ 을 벡터공간으로 본 경우. 기호 Σ 는 쓰지 않는다 |
| 생성 | $\operatorname{span}(v_1, \dots, v_n)$ | 일차결합 전체의 집합. 빈 열의 생성은 {0_V} |
| 선형사상 | $Tv$, $T(v)$ | T : V → W 가 (T-합), (T-배)를 만족. 수에서의 값은 T(2) 처럼 괄호를 쳐 번호 (T2)와 구별한다. 열 v 의 상 Tv_1, …, Tv_n 은 합성 T ∘ v |
| 핵과 상 | $\operatorname{Ker} T$, $\operatorname{Ran} T$ | {v : Tv = 0_W}, {Tv : v ∈ V}. Ran T 는 `image-and-preimage`의 T(V). 부분집합 U 의 상 T(U) 와 구별해 쓴다. 핵을 역상 기호 T⁻¹({0}) 로 쓰지 않는다 |
| 선형사상의 공간 | $L(V, W)$ | 값마다의 덧셈과 스칼라배로 벡터공간. 영벡터는 영사상 |
| 행렬 | $M_{m \times n}$, $a_{j,k}$, $\mathbf{a}_k$ | m × n 행렬은 {1,…,m} × {1,…,n} 에서 ℝ 로의 함수(m, n 은 자연수). 성분 a_{j,k} 는 j 가 행, k 가 열. k 번째 열은 굵은 소문자 𝐚_k (ℝᵐ 의 원소). 식으로 나타낸 행렬의 성분은 (A + B)_{j,k}. 직사각형 배열은 이 함수를 적는 표기. ℝᵐ 과 M_{m×1} 을 같은 집합이라 하지 않는다 (`matrix`) |
| 1 × 1 행렬과 ℝ¹ | | 행렬은 언제나 배열(pmatrix)이나 이름으로, ℝ¹ 의 원소는 이름이나 "1 에서의 값이 c 인 원소"로 쓴다. 괄호 하나짜리 (1), (b) 로 쓰지 않는다. 같은 항목의 번호는 "이 항목의 (1)"처럼 쓴다 |
| 전치, 역행렬 | $A^T$, $A^{-1}$ | ℝⁿ 의 원소에는 ᵀ 를 쓰지 않는다. 가역은 m × n 행렬에 대해 왼쪽 역과 오른쪽 역이 모두 있는 것(`invertible-matrix`) |
| 차원 | $\dim V$ | 유한차원(생성하는 열이 있다)인 V 의 기저의 길이. 무한차원 공간에는 정의하지 않고 ∞ 를 쓰지 않는다 (`dimension`) |
| 연립방정식 | $Ax = b$, $(A \mid B)$ | 옆으로 붙인 행렬 (A \| B), 첨가행렬 (A \| b). E(A \| B) = (EA \| EB) (`system-of-linear-equations`) |
| 기본행렬 | $P_{j,k}$, $D_k(c)$, $R_{k,j}(c)$ | 두 행 맞바꾸기, 한 행에 0 이 아닌 수 곱하기, k 번째 행에 j 번째 행의 c 배 더하기. 일반 기본행렬은 G, 기본행렬의 곱(사슬로 정의)은 E, 기약 사다리꼴 행렬은 U. 기본행렬을 늘어놓은 것은 "M_{m×m} 의 벡터의 열"이라 쓴다. 정수론의 P_n 과는 다른 기호다 |
| 사다리꼴 | $r$, $\ell_1, \dots, \ell_r$ | "사다리꼴", "기약 사다리꼴"이 본 용어. 피벗의 자리 (j, ℓ_j), 피벗 열의 번호, 자유 열의 번호. 기약 사다리꼴의 유일성은 다루지 않았다 (`echelon-form`) |
| 고윳값 | $\operatorname{Ker}(T - \lambda i_V)$ | 고유공간은 이 기호로 쓴다(출처의 E_λ 는 쓰지 않는다). 다만 선형대수 2 의 `diagonalizable-iff-eigenspace-dimensions` 는 "T 의 고윳값을 빠짐없이 늘어놓은 열" μ_1, …, μ_r 에 대해 진술 안의 지역 줄임으로 E_k = Ker(T − μ_k i_V), g_k = dim E_k 를 쓴다. 첨자 k 는 고윳값이 아니라 열의 자리이고, 기본행렬의 곱 E 와는 다른 쓰임이다. 그 항목 밖에서 이 줄임을 쓸 때는 다시 정한다. 고윳값의 "개수"는 서로 다른 고윳값의 열의 길이로 말한다 |
| 기저에 관한 행렬 | $C_{\mathcal{B}}$, $[v]_{\mathcal{B}}$, $[T]_{\mathcal{C}\mathcal{B}}$, $[T]_{\mathcal{B}}$ | 기저는 𝒜, ℬ, 𝒞. 좌표 동형사상 C_ℬ : ℝⁿ → V (출처는 이 이름을 역방향에 쓴다), 좌표 벡터 [v]_ℬ = C_ℬ⁻¹(v), [T]_{𝒞ℬ} = [C_𝒞⁻¹ ∘ T ∘ C_ℬ] (둘째 첨자가 정의역의 기저). 차원 1 이상에서만. 닮음은 A = Q⁻¹BQ, 대각화는 A = SDS⁻¹, 대각행렬은 diag(d_1, …, d_n) |
| 행렬식 | $\det A$, $\det T$ | 정사각행렬에만. 식으로 나타낸 행렬에는 det(AB), det(A − xIₙ) 처럼 괄호를 친다. **막대 기호 \|A\| 는 행렬식에 쓰지 않는다**(원소의 개수·절댓값과 겹친다). "행렬식 함수"는 조건 (i)–(iii)을 만족하는 함수 M_{n×n} → ℝ 이고 det 은 그 유일한 것이다(`determinant-function`, `determinant`). det T 는 dim V ≥ 1 인 V 위의 선형사상에만, det [T]_ℬ 로 정의한다(`determinant-and-trace-of-linear-map`) |
| 소행렬 | $A^{(j,k)}$ | A 에서 j 번째 행과 k 번째 열을 지운 (n − 1) × (n − 1) 행렬. n ≥ 2 에서만 정의하고 1 × 1 에는 없다. 건너뛰는 번호 s_j(i) 는 `minor-matrix` 안의 지역 기호다 |
| 여인수, 여인수행렬, 수반행렬 | $(-1)^{j+k}\det A^{(j,k)}$, $\operatorname{cof} A$, $\operatorname{adj} A$ | (j, k) 여인수, (j, k) 성분이 (j, k) 여인수인 cof A, 그 전치 adj A = (cof A)ᵀ (adj A 의 (k, j) 성분이 (j, k) 여인수). **셋 다 n ≥ 2 에서만 정의한다.** 식에는 adj(Aᵀ) 처럼 괄호. **"수반행렬"은 adjugate(classical adjoint)의 번역이다.** 내적공간의 adjoint 와 다른 말이다. 그쪽은 선형대수 3 의 **수반사상** T* (`adjoint-map`)이고, 행렬에는 adjoint 의 이름과 기호 A* 를 쓰지 않는다(아래 "수반사상" 줄) |
| 열을 바꾼 행렬 | $A_k(b)$ | A 의 k 번째 열을 b ∈ ℝⁿ 로 바꾼 행렬(`cramers-rule`). 아래첨자 k 는 바꾼 열의 번호이고 성분의 첨자가 아니다 |
| 대각합 | $\operatorname{tr} A$, $\operatorname{tr} T$ | a_{1,1} + ⋯ + a_{n,n}(벡터의 유한 합을 ℝ 에 쓴 것). 정사각행렬에만, 식에는 tr(AB) 처럼 괄호(`trace`). tr T 는 det T 와 같이 dim V ≥ 1 에서만 |
| 판별식 | $\operatorname{disc} A$ | **2 × 2 행렬에만** (tr A)² − 4 det A (`real-eigenvalues-2x2`). 일반 다항함수의 판별식은 없다 |
| 실수의 유한 곱 | $a_1 a_2 \cdots a_n$ | 선형대수 2 `finite-product-of-reals`. n ≥ 0 인 정수와 길이 n 인 실수의 열에 재귀 정리로 정한다. **빈 곱은 1.** 곱 기호 Π 는 쓰지 않는다. 위의 정수의 유한 곱(`finite-product`, 빈 곱 없음)과 따로 정의하고 두 값이 같다는 것은 쓰지 않는다. 재배열은 (6) k 번째 항 떼어 내기 말고는 없다. 대각성분의 곱 a_{1,1} ⋯ a_{n,n}, (c_1 − x) ⋯ (c_n − x) 처럼 항이 식인 열에도 쓴다 |
| 거듭제곱 함수, 다항함수의 공간 | $t^k$, $t - c$, $\mathcal{P}_n$ | t^k 는 x 에서의 값이 x^k 인 함수 ℝ → ℝ (k ≥ 0, t⁰ 은 값이 1 인 함수, t¹ = t = i_ℝ). **t 는 수가 아니라 함수 이름의 일부이고, 함숫값은 x 로 말한다.** t − c 는 t¹ − c t⁰. 𝒫_n = span(t⁰, …, tⁿ) ⊆ ℝ^ℝ (n ≥ 0), 계수는 "0 부터 번호가 붙은 실수의 열" a_0, …, a_n 으로 a_0 t⁰ + ⋯ + a_n tⁿ. **𝒫_n (\mathcal{P}) 은 멱집합 𝒫(A) (\mathscr{P}) 와 다른 글씨다.** 영함수는 o (`polynomial-function`) |
| 함수의 곱 | $fg$, $f_1 \cdots f_p$, $f^k$ | ℝ^ℝ 에서 값마다의 곱. 길이 0 인 열의 곱은 t⁰. f 의 k제곱 f^k 는 모든 항이 f 인 열의 곱(`product-of-polynomial-functions`). 행렬과 선형사상의 거듭제곱과는 다르다(그것은 아직 없다) |
| 계수, 차수 | $\deg f$ | 다항함수 f 의 t^k 의 계수(표현에 상관없이 정해진다), 상수항 = f(0), 차수 deg f, 최고차계수. **영함수에는 차수를 정의하지 않는다.** "f ∈ 𝒫_n" 은 "f = o 이거나 deg f ≤ n" 과 같다(`coefficients-of-polynomial-function` (4)) |
| 근과 중복도 | | f(c) = 0 이면 c 는 f 의 근. 근의 개수는 서로 다른 근의 열의 길이로 말한다. "f 에서 c 의 중복도"는 기호 없이 말로 쓰고 영함수에는 정의하지 않는다(`multiplicity-of-a-root`) |
| 특성다항식 | $p_A$, $p_T$ | p_A 는 x 에서의 값이 det(A − xIₙ) 인 함수 ℝ → ℝ (`characteristic-polynomial`). 이 사이트는 ↦ 를 쓰지 않으므로 늘 "x 에서의 값이 … 인 함수"로 쓴다. p_A 는 함수의 이름이고 p_A(x) 가 값이다. 차수 n, 최고차계수 (−1)ⁿ (det(xIₙ − A) 꼴이 아니다). p_T = p_{[T]_ℬ} 는 dim V ≥ 1 에서만(`eigenvalue-iff-root`) |
| 대수적·기하적 중복도 | | "A(또는 T)에서 λ 의 대수적 중복도" = p_A 에서 λ 의 중복도, "기하적 중복도" = 고유공간의 차원. 모든 실수 λ 에 정의하고 고윳값이 아니면 둘 다 0. **기호(m_A(λ), g_A(λ) 등)를 붙이지 않고 말로 쓴다**(`algebraic-multiplicity`). 진술 안에서 열의 항으로 m_j, g_j 를 쓰는 것은 그 항목의 지역 이름이다 |
| 부분공간의 열과 합 | $V_1, \dots, V_p$, $V_1 + \cdots + V_p$ | 부분공간의 열은 값이 부분공간인 함수 {1, …, p} → 𝒫(V) (p 는 자연수, 같은 것이 되풀이되어도 된다). 합과 원소의 "표현". **"부분공간들이 일차독립"**이라고 늘 "부분공간들"을 붙여 벡터의 열의 일차독립과 구별한다(`independent-subspaces`). 기저를 "차례로 이어 붙인 열"과 첨자 집합 Λ 는 `concatenating-bases` (2). 직합에는 기호(⊕)를 두지 않았다("직합"은 alias 로만 있다. `vector-space` 의 확인 질문은 ⊕ 를 다른 덧셈의 이름으로 쓴다) |
| 내적 | $\langle x, y \rangle$, $\langle \cdot, \cdot \rangle$ | 선형대수 3 `inner-product-space`. 내적공간 V 위의 내적의 (x, y) 에서의 값이 ⟨x, y⟩, 함수 자체가 ⟨·, ·⟩. 조건은 **내적의 조건** (i) 대칭, (ii) 첫째 자리에 대한 선형성, (iii) 양의 정부호. **꺾쇠괄호는 늘 쉼표로 가른 두 자리에 쓴다.** 출처(Treil)의 (x, y) 는 쓰지 않는다(순서쌍·열린구간과 겹친다). **추상대수의 ⟨a⟩ (원소 하나로 생성한 순환 부분군, 자리 하나)와 다른 기호다.** 부분공간은 늘 제한한 내적으로 내적공간으로 보고 같은 기호로 쓴다((4)) |
| 표준내적 | $x_1 y_1 + \cdots + x_n y_n$ | ℝⁿ 의 **표준내적**(`standard-inner-product`). ℝⁿ 은 다른 말이 없으면 이 내적으로 보고, ℝ 위의 내적은 곱 xy 로 본다((6)). "점곱"·"스칼라곱"은 별칭(aliases)으로만 있고 기호는 ⟨x, y⟩ 하나다. M_{m×n} 위의 **프로베니우스 내적** tr(AᵀB) 는 `inner-product-examples` (2) |
| 노름 | $\lVert x \rVert$, $\lVert M \rVert_F$ | ‖x‖ = √⟨x, x⟩ (`norm-in-inner-product-space`). **내적이 정하는 노름에만 쓴다.** 내적에서 오지 않는 노름과 노름 공간 일반은 없다(거리공간과 완비성 강의의 고른 거리는 d_∞ 로 쓰고 출처의 고른 노름 ‖f‖ 은 쓰지 않는다). ‖x‖² 은 실수 ‖x‖ 의 거듭제곱. 프로베니우스 노름 ‖M‖_F = √tr(MᵀM) 은 프로베니우스 내적이 정하는 노름이다(`bound-for-matrix-times-vector`) |

| 직교, 직교 여공간 | $x \perp y$, $x \perp S$, $S^\perp$ | x ⊥ y 는 ⟨x, y⟩ = 0, x ⊥ S 는 S 의 모든 원소와 직교(`orthogonal-vectors`). S^⊥ = {x ∈ V : x ⊥ S} 는 **임의의 부분집합 S** 에 정의하고 늘 부분공간이다(`orthogonal-complement`). (E^⊥)^⊥ = E 와 E + E^⊥ = V 는 E 가 유한차원 부분공간일 때만 증명되어 있다 |

머리말의 `title`, `summary`, `aliases`는 수식으로 렌더링되지 않는다. 말이나 유니코드 기호(ℕ, ℤ, ≤, ⊆, ∅)로 쓴다.

## 용어

- **명제**는 statement 의 번역이다. 항목 종류 표시의 "명제"(proposition, 가벼운 정리)와 다르다.
- 전칭 기호, 존재 기호, 열린 문장, 나누어떨어짐, 대우 증명, 귀류법, 가산 무한 집합.
- **유한집합, 무한집합**은 `finite-set`의 정의를 쓴다. ℕ, ℕ 을 포함하는 집합, 가산 무한 집합이 무한집합이라는 것은 `natural-numbers-are-infinite`에 있다.

## 정의와 증명에 관한 약속

- 정의는 "정확히 ~일 때 ○○라 한다"로 양방향이 드러나게 쓴다.
- 증명이 인용할 수 있는 것은 `requires`에 있는 항목의 `:::statement`, 그 진술의 가정, 아래 "받아들인 사실"뿐이다. 다른 항목의 직관, 예시, 참고 블록에만 있는 내용은 인용할 수 없다.
- 변수는 범위를 밝힌다. 변수가 정해지지 않은 문장의 참·거짓을 말하지 않는다.
- 문자 $x$ 로 한 논증이 "모든 $x$"에 대한 증명이 되는 까닭은 `direct-proof`의 진술에 있다.

## 함수와 공역

- 함수는 순서쌍의 집합이다. A에서 B로의 관계(A × B 의 부분집합) 가운데 A의 각 원소에 값이 존재하고 유일한 것. `relation` 항목은 "A 위의 관계"만 정의하고, "A에서 B로의 관계"는 `function`의 진술에서 정의한다.
- **공역**은 "f : A → B"라고 적을 때 선언한 B 이다. 집합 f 만으로는 정해지지 않는다. f의 모든 값이 B′에 속하면 같은 집합 f 는 A에서 B′로의 함수이기도 하다.
- **단사**는 집합 f 만으로 정해진다. **전사, 전단사**는 선언한 공역에 대한 성질이다. "f : A → B 가 전사"처럼 공역을 밝혀 쓴다.
- 두 함수가 같다는 것은 정의역이 같고 모든 원소에서 값이 같다는 것이다. 공역은 같음의 조건이 아니다.
- $g \circ f$ 는 f : A → B, g : B → C 일 때 정의한다. f의 모든 값이 g의 정의역에 속하면 f를 다시 선언해 합성할 수 있다. 이때 "전사의 합성은 전사"는 성립하지 않는다.
- $f^{-1}$ 은 세 가지로 쓰인다: 역관계(언제나 있다), 역함수(역관계가 B에서 A로의 함수일 때), 역상 $f^{-1}(Y)$ (언제나 정의된다). 어느 것인지 밝힌다.

## 받아들인 사실 (증명 없이 쓰는 것)

새 항목에서 아래 사실을 쓸 때는 해당 항목을 `requires`에 넣고 "○○의 진술에서 받아들인 …"으로 인용한다. 목록에 없는 사실을 증명 없이 쓰려면 증명 첫머리에 목록을 만들어 이름을 붙이고, 보고에 적는다. 여러 항목이 쓰게 될 사실이면 지휘자가 어느 항목의 진술에 둘지 정한다.

받아들인 사실에서 **증명된** 것으로, 진술을 그대로 인용할 수 있는 것: `well-ordering-principle`의 (L1) a < b 와 b ≤ a 는 함께 성립하지 않는다, (L2) a ≤ b 이고 b ≤ a 이면 a = b, (L3) a − 1 < a < a + 1; 정렬 원리와 그 두 따름(아래로 유계인 정수 집합의 최소 원소, 위로 유계인 정수 집합의 최대 원소); `division-theorem`(나눗셈 정리, 나누는 수가 양수인 판); 정수론 입문 2단원의 유클리드 보조정리와 소인수분해의 유일성(정렬한 꼴), 3단원의 합동식의 계산·소거·역원; `coprime-to-modulus`의 (5) (0 ≤ c, d ≤ n − 1 이고 c ≡ d (mod n) 이면 c = d). `even-and-odd`가 받아들인 짝·홀의 이분은 이제 나눗셈 정리의 한 경우로 증명되지만, 그 항목을 인용하는 기존 항목들은 그대로 둔다.

자주 쓰는 꼴: 정수 c, k 에 대하여 c ≤ k 이거나 c ≥ k + 1 이다. (Z5)와 (Z1)에서 나오므로 "(Z5)와 (Z1)에 의해"로 인용한다.

"무한히 많은 n" 대신 "모든 M 에 대해 n ≥ M 인 n 이 있어"로 쓴다. **"실수의 완비성"은 (U)의 이름으로만 쓰고**, 코시 수열이 수렴한다는 성질은 "코시 완비성"이라 부른다(코시 완비성에서 (U)가 나오는지는 다루지 않았다). 식에 이름을 붙일 때 `\tag` 를 쓰지 않고 문장으로 붙인다.

해석학 입문 3단원에서 증명되어 번호로 인용하는 것: `recursion-theorem`(x(1) = a, x(n+1) = g(n, x(n)) 인 함수 ℕ → X 가 정확히 하나. (1) 값으로 정한 함수의 일반 집합판, (2) 두 함수를 함께 정하기, (3) X ⊆ ℝ 이면 수열, (4) g(k, n) > n 이면 순증가이고 x(k) ≥ k. 재귀로 정하는 것은 이 정리로 정당화한다. 받아들이는 사실 없이 증명했다. 선형대수와 정수론의 재귀 정의(유한 곱, 유한 합)는 그 항목의 진술에서 받아들인 그대로 둔다), `power-of-a-real-number`의 (1)–(7), `squeeze-lemma`의 (1)–(2), `limits-preserve-inequalities`의 (1)–(3), `comparison-with-null-sequence`의 (1)–(3), `limit-of-sum-and-product`의 (1)–(7) ((7): 0 으로 수렴 × 유계), `limit-of-absolute-value-and-square-root`의 (1)–(2), `geometric-sequence-limit`의 (1)–(4) (수열 (cⁿ) 의 첨자는 n ≥ 1), `ratio-test-for-sequences`의 (1)–(3) ((3): 어떤 번호부터 |x_{n+1}| ≤ r|x_n| 이면 |x_{M+j}| ≤ |x_M| rʲ). 꼬리 판(어떤 번호 이후에만 가정이 성립)이 조임 정리, 극한과 부등식, 비교에 있다.

해석학 입문 2단원에서 증명되어 번호로 인용하는 것: `absolute-value`의 (1)–(11) (두 수의 max, min 포함. |y − x| < ε ⇔ x − ε < y < x + ε), `triangle-inequality`의 (1)–(5), `sequence`의 (1)–(4) (수열은 ℕ 에서 ℝ 로의 함수, 유계의 동치, 단조이면 n ≤ m 에서 x_n ≤ x_m), `limit-of-sequence`의 (1)–(3) (ε–M 정의, 부정의 꼴, 발산), `limit-is-unique`(이 뒤에만 lim 기호를 쓴다. ∞ 는 기호의 일부이고 수가 아니다. x_n → L 은 쓰지 않는다), `basic-limits`의 (1)–(4), `convergent-sequence-is-bounded`의 (1)–(3) ((1): 처음 k 개 항을 누르는 수가 있다. 유한한 실수 집합의 최댓값 대신 쓴다), `monotone-convergence-theorem`의 (1)–(3), `tail-of-a-sequence`의 (1)–(3) (K 는 자연수, 0-꼬리는 없다).

앞에서 받아들였다가 해석학 입문 1단원에서 증명된 것(기존 항목의 문구는 그대로 둔다): (Y1) → `order-properties-of-reals`의 (5); `bernoulli-inequality`의 순서 사실 (R3)–(R6) → 같은 항목; `prime-number`의 (Z2), (Z3)의 실수판 → 같은 항목의 (4); "제곱하여 2 가 되는 양의 실수가 꼭 하나 있다" → `square-root-exists`의 (1). 해석학 입문의 항목은 이 받아들인 사실들을 인용하지 않고 증명된 쪽을 인용한다.

강한 귀납법은 받아들인 원리가 아니다. `strong-induction`이 보통의 귀납법에서 끌어낸다.
