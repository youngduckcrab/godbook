:::statement
$V$가 [[vector-space|벡터공간]]이고 $u$, $v$, $w$는 $V$의 임의의 원소, $\alpha$는 임의의 실수라 하자. 다음이 성립한다.

- (B1) 영벡터는 하나뿐이다. 이 영벡터를 $0_V$로 쓴다. (실수 $0$과 헷갈릴 염려가 없을 때는 $0$으로 줄여 쓴다.)
- (B2) 각 $v \in V$에 대하여 $v + w = 0_V$인 $w \in V$가 있고 하나뿐이다. 이 $w$를 $-v$로 쓰고 $v$의 **덧셈 역원**(additive inverse)이라 한다. $u - v$는 $u + (-v)$를 뜻한다.
- (B3) $0v = 0_V$이다. (왼쪽의 $0$은 실수이다.)
- (B4) $\alpha 0_V = 0_V$이다.
- (B5) $(-1)v = -v$이다. (왼쪽의 $-1$은 실수이다.)
- (B6) $\alpha v = 0_V$이면 $\alpha = 0$이거나 $v = 0_V$이다.
- (B7) (소거) $u + w = v + w$이면 $u = v$이다.
- (B8) $-(-v) = v$이다.
- (B9) $(-\alpha)v = -(\alpha v) = \alpha(-v)$이다.
- (B10) $-(u + v) = (-u) + (-v)$이다.
- (B11) $\alpha(u - v) = \alpha u - \alpha v$이고 $(\alpha - \beta)v = \alpha v - \beta v$이다. ($\beta$는 임의의 실수이다.)
- (B12) $u - v = 0_V$인 것은 정확히 $u = v$일 때이다.
:::

:::english
Let $V$ be a vector space, let $u$, $v$, $w$ be arbitrary elements of $V$, and let $\alpha$ be an arbitrary real number. Then the following hold.

- (B1) There is exactly one zero vector. We write it $0_V$. (When no confusion with the real number $0$ is possible, we abbreviate it to $0$.)
- (B2) For each $v \in V$ there is a $w \in V$ with $v + w = 0_V$, and it is unique. We write this $w$ as $-v$ and call it the **additive inverse** of $v$. $u - v$ means $u + (-v)$.
- (B3) $0v = 0_V$. (The $0$ on the left is the real number.)
- (B4) $\alpha 0_V = 0_V$.
- (B5) $(-1)v = -v$. (The $-1$ on the left is the real number.)
- (B6) If $\alpha v = 0_V$, then $\alpha = 0$ or $v = 0_V$.
- (B7) (Cancellation) If $u + w = v + w$, then $u = v$.
- (B8) $-(-v) = v$.
- (B9) $(-\alpha)v = -(\alpha v) = \alpha(-v)$.
- (B10) $-(u + v) = (-u) + (-v)$.
- (B11) $\alpha(u - v) = \alpha u - \alpha v$ and $(\alpha - \beta)v = \alpha v - \beta v$, where $\beta$ is an arbitrary real number.
- (B12) $u - v = 0_V$ exactly when $u = v$.
:::

## 직관

(B1)–(B12)는 수의 계산에서 "당연하다"고 느끼던 것들이 벡터공간의 여덟 법칙만으로 따라 나온다는 것을 보여 줍니다. 정의는 영벡터가 "있다"고만 했는데, 정의의 어느 법칙도 영벡터가 하나뿐이라고 말하지 않았습니다. 그것은 (V1)과 (V3)에서 나옵니다. 영벡터가 정해지면 (V4)가 덧셈 역원의 존재를 주고, 그 유일성 덕분에 $-v$라는 기호가 한 벡터를 가리킬 수 있습니다.

(B3)–(B6)은 벡터에 실수를 곱하는 연산이 영벡터와 어떻게 만나는지를 말합니다. 눈여겨볼 곳은 (B3)의 증명입니다. $0v$가 영벡터인 것은 "0을 곱했으니 사라진다"는 감각으로 보이지만, 증명에서는 $0v$를 $x$라 두고 $x = x + x$임을 보인 뒤 $x$의 덧셈 역원을 더해 $x = 0_V$를 얻습니다. 이 방식은 (B4)에서도 그대로 쓰입니다. (B6)의 증명은 0이 아닌 실수 $\alpha$에 역수 $\alpha^{-1}$이 있다는 사실을 써서 $\alpha v$에 $\alpha^{-1}$을 곱해 $v$를 되찾습니다. (B8)–(B12)는 부호를 다루는 규칙입니다. 수에서 익숙한 "마이너스를 안으로 넣는다" 같은 계산이 벡터에서도 같은 근거로 성립합니다.

## 증명

:::idea
(B1), (B2)의 유일성은 "두 후보를 서로 더해 보면" 같아진다는 식의 계산이다. (B3), (B4)는 $x = x + x$이면 $x = 0_V$라는 보조 사실로 한꺼번에 처리하고, (B5)는 (B2)의 유일성, (B6)은 (V5), (V6)과 실수의 역수, (B7)은 역원을 더하는 계산, (B8)–(B10)은 (B2)의 유일성과 (B3), (B4)를, (B11), (B12)는 (B9)와 (B2)를 쓴다.
:::

:::

:::proof
$V$는 벡터공간이다. 증명에서 인용하는 (V1)–(V8)은 [[vector-space]]의 것이고 (K1)–(K12)는 [[real-number-arithmetic]]의 것이다.

**(B1)의 증명.** (V3)에 의해 영벡터가 있다. $z$와 $z'$가 영벡터라 하자. $z'$이 영벡터이므로 모든 $v$에서 $v + z' = v$이고, $v = z$로 두면 $z + z' = z$이다. $z$가 영벡터이므로 $v = z'$로 두면 $z' + z = z'$이다. (V1)에 의해 $z + z' = z' + z$이므로 $z = z + z' = z' + z = z'$이다. 따라서 영벡터는 하나뿐이다.

**(B2)의 증명.** $v \in V$라 하자. (B1)에 의해 영벡터 $0_V$가 하나로 정해져 있고, (V4)에서 $z = 0_V$로 두면 $v + w = 0_V$인 $w \in V$가 있다. 유일성을 보이기 위해 $v + w = 0_V$이고 $v + w' = 0_V$라 하자. 그러면
$$w = w + 0_V = w + (v + w') = (w + v) + w' = (v + w) + w' = 0_V + w' = w' + 0_V = w'$$
이다. 차례로 영벡터의 성질($0_V$가 영벡터이므로 $w + 0_V = w$), $v + w' = 0_V$, (V2), (V1), $v + w = 0_V$, (V1), 영벡터의 성질에 의한다. 따라서 $w = w'$이다. 이 $w$를 $-v$로 쓴다. 그러면 $v + (-v) = 0_V$이고, (V1)에 의해 $(-v) + v = 0_V$이기도 하다.

**보조 사실.** $x \in V$이고 $x = x + x$이면 $x = 0_V$이다. 증명: (B2)에 의해 $x + y = 0_V$인 $y$가 있다. 그러면
$$0_V = x + y = (x + x) + y = x + (x + y) = x + 0_V = x$$
이다. 차례로 $x + y = 0_V$, 가정 $x = x + x$, (V2), $x + y = 0_V$, 영벡터의 성질에 의한다.

**(B3)의 증명.** $x = 0v$라 하자. (K4)에 의해 실수 $0 + 0 = 0$이므로 (V8)에 의해 $x = 0v = (0 + 0)v = 0v + 0v = x + x$이다. 보조 사실에 의해 $x = 0_V$, 곧 $0v = 0_V$이다. (쓴 것: (V8), (V2), (V3)과 (V4)(보조 사실과 (B2)를 통해), (K4).)

**(B4)의 증명.** $x = \alpha 0_V$라 하자. $0_V$가 영벡터이므로 $0_V + 0_V = 0_V$이다. (V7)에 의해 $x = \alpha 0_V = \alpha(0_V + 0_V) = \alpha 0_V + \alpha 0_V = x + x$이다. 보조 사실에 의해 $x = 0_V$이다.

**(B5)의 증명.** (K5)와 (K8)의 (ii)에 의해 실수 $-1$은 $1 + (-1) = 0$인 수이다. (V5)에 의해 $v = 1v$이므로
$$v + (-1)v = 1v + (-1)v = (1 + (-1))v = 0v = 0_V$$
이다. 차례로 (V5), (V8), $1 + (-1) = 0$, (B3)에 의한다. 따라서 $(-1)v$는 $v + w = 0_V$인 벡터 $w$이고, (B2)의 유일성에 의해 $(-1)v = -v$이다. (쓴 것: (V5), (V8), (B3), (B2); (V6)은 쓰지 않는다.)

**(B6)의 증명.** $\alpha v = 0_V$라 하자. $\alpha = 0$이면 결론이 성립하므로 $\alpha \ne 0$이라 하고 $v = 0_V$를 보인다. (K6)과 (K8)에 의해 역수 $\alpha^{-1}$이 있고, (K1)에 의해 $\alpha^{-1}\alpha = 1$이다. 그러면
$$v = 1v = (\alpha^{-1}\alpha)v = \alpha^{-1}(\alpha v) = \alpha^{-1}0_V = 0_V$$
이다. 차례로 (V5), $\alpha^{-1}\alpha = 1$, (V6), 가정 $\alpha v = 0_V$, (B4)에 의한다.

**(B7)의 증명.** $u + w = v + w$라 하자. (B2)의 $-w$에 대하여 $w + (-w) = 0_V$이다. 그러면
$$u = u + 0_V = u + (w + (-w)) = (u + w) + (-w) = (v + w) + (-w) = v + (w + (-w)) = v + 0_V = v$$
이다. 차례로 영벡터의 성질, $w + (-w) = 0_V$, (V2), 가정, (V2), $w + (-w) = 0_V$, 영벡터의 성질에 의한다.

**(B8)의 증명.** (B2)에 의해 $v + (-v) = 0_V$이고 (V1)에 의해 $(-v) + v = 0_V$이다. 곧 $v$는 $(-v) + w = 0_V$인 벡터 $w$이다. (B2)의 유일성을 벡터 $-v$에 적용하면 이런 $w$는 $-(-v)$뿐이므로 $v = -(-v)$이다.

**(B9)의 증명.** $\alpha v + (-\alpha)v = (\alpha + (-\alpha))v = 0v = 0_V$이다. 차례로 (V8), $\alpha + (-\alpha) = 0$((K8)), (B3)에 의한다. 따라서 $(-\alpha)v$는 $\alpha v + w = 0_V$인 벡터 $w$이고, (B2)의 유일성에 의해 $(-\alpha)v = -(\alpha v)$이다. 또 $\alpha v + \alpha(-v) = \alpha(v + (-v)) = \alpha 0_V = 0_V$이다. 차례로 (V7), (B2), (B4)에 의한다. 따라서 $\alpha(-v)$도 $\alpha v + w = 0_V$인 벡터 $w$이고 $\alpha(-v) = -(\alpha v)$이다.

**(B10)의 증명.** $(u + v) + ((-u) + (-v))$를 계산한다. (V2)에 의해 이것은 $((u + v) + (-u)) + (-v)$이다. $(u + v) + (-u) = (v + u) + (-u) = v + (u + (-u)) = v + 0_V = v$이다. 차례로 (V1), (V2), (B2), 영벡터의 성질에 의한다. 따라서 합은 $v + (-v) = 0_V$이다. 곧 $(-u) + (-v)$는 $(u + v) + w = 0_V$인 벡터 $w$이고, (B2)의 유일성에 의해 $(-u) + (-v) = -(u + v)$이다.

**(B11)의 증명.** $\alpha(u - v) = \alpha(u + (-v)) = \alpha u + \alpha(-v) = \alpha u + (-(\alpha v)) = \alpha u - \alpha v$이다. 차례로 뺄셈의 정의, (V7), (B9), 뺄셈의 정의에 의한다. $(\alpha - \beta)v = (\alpha + (-\beta))v = \alpha v + (-\beta)v = \alpha v + (-(\beta v)) = \alpha v - \beta v$이다. 차례로 실수의 뺄셈의 정의, (V8), (B9), 벡터의 뺄셈의 정의에 의한다.

**(B12)의 증명.** $u = v$이면 $u - v = v + (-v) = 0_V$이다((B2)). 거꾸로 $u - v = u + (-v) = 0_V$라 하자. (B2)와 (V1)에 의해 $(-v) + v = 0_V$이므로
$$u = u + 0_V = u + ((-v) + v) = (u + (-v)) + v = 0_V + v = v$$
이다. 차례로 영벡터의 성질, $(-v) + v = 0_V$, (V2), 가정, (V1)과 영벡터의 성질에 의한다. $\blacksquare$

## 예시와 반례

:::example[더해서 변하지 않으면 영벡터이다]
$V$가 벡터공간이고 $u$, $v \in V$이며 $u + v = u$라 합시다. 그러면 $v = 0_V$입니다. $v + u = u + v = u$((V1))이고 $0_V + u = u + 0_V = u$((V1), 영벡터의 성질)이므로 $v + u = 0_V + u$입니다. (B7)에 의해 $v = 0_V$입니다. 영벡터의 정의는 모든 벡터에서 $v + z = v$이기를 요구하지만, 벡터 $u$ 하나에서 $u + z = u$이기만 해도 $z$는 영벡터입니다.
:::

:::example[$\mathbb{R}$에서의 각 성질]
[[vector-space|벡터공간]] 항목의 첫째 예시에서 확인했듯이 $V = \mathbb{R}$(보통의 합과 곱)은 벡터공간입니다. 여기서 영벡터는 실수 $0$이고, $v$의 덧셈 역원은 (K8)의 $-v$입니다. (B3)은 (K9)의 $0v = 0$, (B4)는 (K9)의 $a0 = 0$, (B5)는 (K9)의 $(-1)v = -v$, (B6)은 (K10), (B7)은 $u + w = v + w$에서 $-w$를 더하는 소거입니다. 벡터공간 $\mathbb{R}$의 성질이 [[real-number-arithmetic]]에서 이미 증명한 성질과 일치합니다.
:::

:::counterexample[(V8)이 깨진 곳에서는 (B3)이 깨질 수 있다]
[[vector-space|벡터공간]] 항목의 확인 질문처럼 $V = \mathbb{R}$에서 덧셈을 $u \oplus v = (u + v) + 1$로, 스칼라배를 보통의 곱으로 정합니다. 이 공간에서 $0v = 0 \cdot v = 0$((K9))인데 $0$은 영벡터가 아닙니다. $0$이 영벡터라면 $0 \oplus 0 = 0$이어야 하지만 $0 \oplus 0 = (0 + 0) + 1 = 1$이고 $1 \ne 0$이기 때문입니다. 그러므로 이 공간에서는 (B3)이 성립하지 않습니다. (V8)이 깨져 있습니다. $(0 + 0)v = 0$인데 $0v \oplus 0v = 0 \oplus 0 = 1$입니다. 기본 성질은 (V1)–(V8)이 모두 성립한다는 가정 아래에서 증명한 것입니다.
:::

## 확인 질문

:::check[벡터공간 $V$의 벡터 $v$에 대하여 $(-1)v + v = 0_V$임을 (B1)–(B7)과 (V1)–(V8)을 인용해 보여라.]
(B5)에 의해 $(-1)v = -v$이므로 $(-1)v + v = (-v) + v$입니다. (B2)에서 보았듯이 (V1)에 의해 $(-v) + v = v + (-v) = 0_V$입니다. 따라서 $(-1)v + v = 0_V$입니다.
:::

:::check[벡터공간 $V$의 벡터 $v$에 대하여 $2v = 0_V$이면 $v = 0_V$인가?]
그렇습니다. $2 \ne 0$이므로((K7)) (B6)에서 $\alpha = 2$로 두면 $\alpha = 0$일 수 없어서 $v = 0_V$입니다.
:::
