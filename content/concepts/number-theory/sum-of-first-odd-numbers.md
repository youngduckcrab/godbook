:::statement
모든 자연수 $n$에 대하여 홀수인 자연수를 작은 것부터 $n$개 더한 합은 $n^2$이다. 곧
$$1 + 3 + 5 + \cdots + (2n - 1) = n^2$$
이다. 좌변은 $j$번째 항이 $2j - 1$인 $n$개의 항의 합이며, $n = 1$이면 항이 $1$ 하나뿐이고 식은 $1 = 1^2$이다.
:::

:::english
For every natural number $n$, the sum of the $n$ smallest odd natural numbers equals $n^2$; that is,
$$1 + 3 + 5 + \cdots + (2n - 1) = n^2.$$
The left side is the sum of $n$ terms whose $j$th term is $2j - 1$; when $n = 1$ it consists of the single term $1$, and the equation reads $1 = 1^2$.
:::

## 직관

$n$이 작을 때 직접 더해 봅시다. $n = 1$이면 $1 = 1^2$, $n = 2$이면 $1 + 3 = 4 = 2^2$, $n = 3$이면 $1 + 3 + 5 = 9 = 3^2$입니다.

홀수인 자연수를 작은 것부터 늘어놓으면 $1, 3, 5, \dots$이고 $j$번째가 $2j - 1$입니다. 이는 다음과 같이 확인됩니다. 자연수 $j$에 대해 $2j - 1 = 2(j-1) + 1$은 [[even-and-odd]]의 정의에 의해 홀수인 자연수입니다. 거꾸로 홀수인 자연수 $m$은 $m = 2a + 1$인 정수 $a$가 있고 $m \ge 1$이므로 $a \ge 0$이며, $j = a + 1$이면 $m = 2j - 1$입니다. $j$가 커지면 $2j - 1$도 커집니다.

이 항목이 증명하는 것은 아래 등식이고, 좌변은 $j$번째 항을 $2j - 1$로 정한 합입니다.

타일 $n^2$개로 만든 $n \times n$ 정사각형의 위쪽과 오른쪽 두 변을 따라 ㄱ자 모양으로 한 겹 덧붙여 $(n+1) \times (n+1)$으로 키울 때 필요한 타일은 $(n+1)^2 - n^2 = 2n + 1$개이고, 이는 $n + 1$번째 홀수인 자연수 $2(n+1) - 1$과 같습니다. 이 비유는 아래 귀납 단계가 하는 계산과 같은 것입니다. 다만 비유는 증명이 아니므로, 모든 $n$에 대한 증명은 [[mathematical-induction]]으로 합니다.

## 증명

:::idea
$n = k$일 때 성립한다고 가정하고 $n = k + 1$일 때의 좌변을 "$n = k$일 때의 좌변 + 새 항 $2k + 1$"로 나누어, 귀납 가정으로 앞부분을 $k^2$으로 바꾼다.
:::

:::hint
$S_n$: "$1 + 3 + \cdots + (2n-1) = n^2$"이라 하고 $S_{k+1}$의 좌변을 써 보라. $k + 1$번째 항은 $2(k+1) - 1$이다.
:::

:::hint
$S_{k+1}$의 좌변은 $S_k$의 좌변에 한 항을 더한 것이다. 귀납 가정으로 $S_k$의 좌변을 바꾸고 나면 $k^2 + (\text{새 항})$을 $(k+1)^2$과 비교하면 된다.
:::

:::proof
자연수 $n$에 대하여 $S_n$을 "$1 + 3 + \cdots + (2n-1) = n^2$"이라 하고, [[mathematical-induction]]으로 모든 자연수 $n$에 대해 $S_n$이 참임을 증명한다.

(기초 단계) $n = 1$이면 좌변은 항 하나 $2 \cdot 1 - 1 = 1$이고 우변은 $1^2 = 1$이므로 $S_1$이 참이다.

(귀납 단계) 임의의 자연수 $k$를 하나 잡고 $S_k \Rightarrow S_{k+1}$을 직접 증명한다. $S_k$, 곧
$$1 + 3 + \cdots + (2k - 1) = k^2$$
이 참이라고 가정한다(귀납 가정). $S_{k+1}$의 좌변은 $k + 1$개의 항의 합이며, 마지막 항은 $2(k+1) - 1 = 2k + 1$이다. 앞의 $k$개 항은 $S_k$의 좌변과 같다. ($k = 1$이면 $S_k$의 좌변은 항 하나 $1$이고 $S_2$의 좌변은 $1 + 3$이다.) 따라서
$$1 + 3 + \cdots + (2k-1) + \bigl(2(k+1) - 1\bigr) = \bigl(1 + 3 + \cdots + (2k-1)\bigr) + (2k + 1)$$
이다. 귀납 가정에 의해 괄호 안은 $k^2$이므로 우변은 $k^2 + 2k + 1$이고, 이는 $(k+1)^2$과 같다. 따라서 $1 + 3 + \cdots + (2(k+1) - 1) = (k+1)^2$, 곧 $S_{k+1}$이 참이다. 이로써 모든 자연수 $k$에 대하여 $S_k \Rightarrow S_{k+1}$이 증명되었다.

기초 단계와 귀납 단계에 의해 모든 자연수 $n$에 대하여 $S_n$이 참이다. $\blacksquare$
:::

## 예시와 반례

:::example[$n = 6$과 큰 합]
$n = 6$이면 $1 + 3 + 5 + 7 + 9 + 11 = 36 = 6^2$이다. 이 정리를 쓰면 $1 + 3 + 5 + \cdots + 99$를 모두 더하지 않고 구할 수 있다. 마지막 항 $99 = 2n - 1$에서 $n = 50$이므로 합은 $50^2 = 2500$이다.
:::

:::counterexample[흔한 실수: 짝수의 합에 같은 식을 쓰기]
"짝수인 자연수를 작은 것부터 $n$개 더한 합도 $n^2$일 것"이라고 생각하면 틀립니다. $n = 2$이면 $2 + 4 = 6$이고 $2^2 = 4$이므로 같지 않습니다. 이 경우 합은 $n(n+1)$($n = 2$에서 $2 \cdot 3 = 6$)로 보이지만, 이 항목에서 증명하지는 않습니다. 위 증명에서 귀납 단계가 성립한 것은 새로 더하는 항 $2k + 1$이 $(k+1)^2 - k^2$과 정확히 같기 때문이며, 항이 달라지면 이 계산이 맞지 않습니다.
:::

:::counterexample[흔한 실수: 마지막 항 어긋남]
$n$번째 홀수인 자연수는 $2n - 1$이지 $2n + 1$이 아닙니다. $n = 3$일 때 $1 + 3 + 5 = 9$는 마지막 항이 $2 \cdot 3 - 1 = 5$입니다. 마지막 항을 $2 \cdot 3 + 1 = 7$로 착각해 $1 + 3 + 5 + 7$을 더하면 $16$이 되어 $3^2 = 9$와 맞지 않습니다.
:::

## 확인 질문

:::check[$1 + 3 + 5 + \cdots + 41$의 값은?]
마지막 항 $41 = 2n - 1$에서 $n = 21$이므로 정리에 의해 $21^2 = 441$입니다.
:::

:::check[귀납 단계에서 $k = 6$일 때 귀납 가정과 보일 식은? 둘 사이의 계산을 확인하라.]
귀납 가정은 $1 + 3 + 5 + 7 + 9 + 11 = 6^2 = 36$이고, 보일 식은 $1 + 3 + 5 + 7 + 9 + 11 + 13 = 7^2 = 49$입니다. 새 항은 $2 \cdot 7 - 1 = 13$이고 $36 + 13 = 49$입니다.
:::
