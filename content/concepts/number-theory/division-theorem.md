:::statement
$a$가 정수이고 $b$가 양의 정수일 때, 다음 두 조건을 모두 만족하는 정수 $q$, $r$이 존재한다.

$$a = qb + r, \qquad 0 \le r < b.$$

또 이 조건을 만족하는 쌍 $(q, r)$은 하나뿐이다. 곧 정수 $q$, $r$, $q'$, $r'$이 $a = qb + r = q'b + r'$, $0 \le r < b$, $0 \le r' < b$를 만족하면 $q = q'$이고 $r = r'$이다.

이때 $q$를 $a$를 $b$로 나눈 **몫**(quotient), $r$을 **나머지**(remainder)라 한다.

증명에서 정수의 순서에 관한 (Z1)–(Z4)는 [[prime-number]]에서, (Z5)–(Z7)과 아래 경계·최소 원소에 관한 정리는 [[well-ordering-principle]]에서 받아들이거나 증명한 것을 쓴다.
:::

:::english
Let $a$ be an integer and $b$ a positive integer. Then there exist integers $q$ and $r$ satisfying both of the following conditions.

$$a = qb + r, \qquad 0 \le r < b.$$

Moreover, the pair $(q, r)$ satisfying these conditions is unique. That is, if integers $q$, $r$, $q'$, $r'$ satisfy $a = qb + r = q'b + r'$, $0 \le r < b$, and $0 \le r' < b$, then $q = q'$ and $r = r'$.

Here $q$ is called the **quotient** and $r$ the **remainder** of $a$ divided by $b$.

The proof uses (Z1)–(Z4) on the order of the integers, accepted on the site's earlier page on prime numbers, and (Z5)–(Z7) together with the theorem on bounded sets of integers, accepted or proved on the site's page on the well-ordering principle.
:::

## 직관

$a$개의 구슬을 한 바구니에 $b$개씩 담는다고 합시다. 꽉 찬 바구니가 $q$개이고 남는 구슬이 $r$개이면 $a = qb + r$이고, 남은 구슬은 한 바구니를 채우지 못했으므로 $0 \le r < b$입니다. 몇 바구니를 채울 수 있는지($q$)는 하나로 정해집니다. 한 바구니를 더 채울 수 있으면 아직 덜 담은 것이고, 한 바구니를 덜 채우면 남는 구슬 수가 $b$ 이상이 되어 규칙에 어긋나기 때문입니다.

$a$가 음수이면 바구니 비유가 어색하지만 같은 식이 성립합니다. 예를 들어 $a = -17$, $b = 5$이면 $q = -4$, $r = 3$이고, 나머지는 항상 $0$ 이상 $b$ 미만으로 잡습니다.

증명의 아이디어는 $a$에서 $b$의 배수를 계속 빼서 음이 아닌 수들 가운데 가장 작은 것을 고르는 것입니다. 그 수가 나머지입니다. 가장 작은 수가 있다는 것은 [[well-ordering-principle|정렬 원리]]가 보장합니다.

## 증명

:::idea
$a$에서 $b$의 정수배를 뺀 값 가운데 음이 아닌 것들의 집합에서 최소 원소 $r$을 고르고, $r \ge b$이면 $r - b$가 더 작은 원소라는 모순을 낸다. 유일성은 두 표현을 빼서 $b$의 배수가 $-b$와 $b$ 사이에 있음을 보인다.
:::

:::hint
집합 $A = \{a - xb : x$는 정수이고 $a - xb \ge 0\}$을 만들고 [[well-ordering-principle|정렬 원리]]를 쓰세요. 이 집합이 공집합이 아님을 보이는 데에는 $a \ge 0$인 경우와 $a < 0$인 경우를 따로 보면 됩니다.
:::

:::hint
유일성에서는 두 표현 $qb + r = q'b + r'$를 $r - r' = (q' - q)b$로 바꾸고, $r - r'$이 $-b$와 $b$ 사이에 있다는 것과 $b$의 배수라는 것을 함께 쓰세요.
:::

:::proof
**존재.** 집합
$$A = \{a - xb : x \text{는 정수이고 } a - xb \ge 0\}$$
을 만든다. $a - xb$는 정수 $a$, $b$, $x$의 곱과 차이므로 정수이다([[even-and-odd]]에서 받아들인 사실). 따라서 $A$는 정수의 집합이고 모든 원소가 $0$ 이상이므로 $0$을 아래 경계로 갖는다.

*$A$는 공집합이 아니다.* 두 경우로 나눈다.

- $a \ge 0$인 경우: $x = 0$으로 두면 $a - 0 \cdot b = a \ge 0$이므로 $a \in A$이다.
- $a < 0$인 경우: $x = a$로 두면 $a - ab$가 $A$의 원소임을 보인다. $b$가 양의 정수이므로 (Z1)에 의해 $1 \le b$이고, 양변에서 $1$을 빼면 (Z7)에 의해 $0 \le b - 1$이다. $a < 0$의 양변에 $-a$를 더하면 (Z7)에 의해 $0 < -a$이다. 따라서 (Z3)에 의해 $0 \cdot (-a) \le (b - 1)(-a)$, 곧 $0 \le (b-1)(-a)$이다. 분배법칙으로 $(b-1)(-a) = -ab + a = a - ab$이므로 $a - ab \ge 0$이고 $a - ab \in A$이다.

(가) ([[well-ordering-principle]])에 의해 $A$는 최소 원소 $r$을 갖는다. $r \in A$이므로 어떤 정수 $q$에 대하여 $r = a - qb$이고 $0 \le r$이다. 양변에 $qb$를 더하면 (Z7)에 의해 $a = qb + r$이다.

$r < b$임을 보인다. $r < b$가 아니라고 하자. (Z5)에 의해 $r = b$ 또는 $r > b$이고, 어느 쪽이든 $b \le r$이다. 양변에서 $b$를 빼면 (Z7)에 의해 $0 \le r - b$이다. 또 $r - b = (a - qb) - b = a - (q + 1)b$이고 $q + 1$이 정수이므로 $r - b$는 $a - xb$ 꼴이고 $0$ 이상이다. 곧 $r - b \in A$이다. $r$이 $A$의 최소 원소이므로 $r \le r - b$이다. 한편 $b > 0$의 양변에 $r - b$를 더하면 (Z7)에 의해 $r - b < r$이다. $r \le r - b$는 $r < r - b$ 또는 $r = r - b$인데, 둘 다 $r - b < r$과 함께 성립할 수 없다((Z5): 셋 가운데 정확히 하나만 성립한다). 모순이다. 따라서 $r < b$이다. 곧 $0 \le r < b$이고 $a = qb + r$이다.

**유일성.** 정수 $q$, $r$, $q'$, $r'$이 $a = qb + r = q'b + r'$, $0 \le r < b$, $0 \le r' < b$를 만족한다고 하자. $qb + r = q'b + r'$의 양변에서 $qb + r'$을 빼면 (Z7)에 의해
$$r - r' = (q' - q)b$$
이다. $t = q' - q$로 두면 $t$는 정수이고 $r - r' = tb$이다(곧 $b \mid r - r'$이다, [[divisibility|나누어떨어짐]]). 먼저 $-b < r - r' < b$임을 보인다.

- $0 \le r'$의 양변에 $r - r'$을 더하면 (Z7)에 의해 $r - r' \le r$이다. $r < b$이므로 (Z6)에 의해 $r - r' < b$이다.
- $0 \le r$의 양변에 $-r'$을 더하면 (Z7)에 의해 $-r' \le r - r'$이다. $r' < b$의 양변에 $-r' - b$를 더하면 (Z7)에 의해 $-b < -r'$이다. 따라서 (Z6)에 의해 $-b < r - r'$이다.

곧 $-b < tb < b$이다. 이제 $t = 0$임을 보인다. (Z5)에 의해 $t < 0$, $t = 0$, $t > 0$ 가운데 정확히 하나가 성립한다.

- $t > 0$이면 정수 $t$에 대해 (Z1)에 의해 $1 \le t$이다. $b > 0$이므로 (Z3)에 의해 $1 \cdot b \le tb$, 곧 $b \le tb$이다. $b \le tb$는 $b < tb$ 또는 $b = tb$인데, 둘 다 $tb < b$와 함께 성립할 수 없다((Z5)). 모순이다.
- $t < 0$이면 (Z1)에 의해 $t + 1 \le 0$이고, 양변에서 $1$을 빼면 (Z7)에 의해 $t \le -1$이다. $b > 0$이므로 (Z3)에 의해 $tb \le (-1)b = -b$이다. $tb \le -b$는 $tb < -b$ 또는 $tb = -b$인데, 둘 다 $-b < tb$와 함께 성립할 수 없다((Z5)). 모순이다.

따라서 $t = 0$이다. $t = q' - q = 0$의 양변에 $q$를 더하면 (Z7)에 의해 $q' = q$이다. 또 $r - r' = tb = 0 \cdot b = 0$이므로 양변에 $r'$을 더하면 $r = r'$이다. $\blacksquare$
:::

:::remark[짝수와 홀수는 이 정리의 한 경우이다]
[[even-and-odd]]는 "모든 정수는 짝수이거나 홀수이며 둘 다인 정수는 없다"를 증명 없이 받아들였다. 이 사실은 $b = 2$인 나눗셈 정리에서 나온다. 위 증명은 짝수·홀수의 이분을 쓰지 않았으므로 순환이 아니다.

정수 $a$에 대해 $b = 2$로 나눗셈 정리를 쓰면 $a = 2q + r$, $0 \le r < 2$인 정수 $q$, $r$이 있다. $r < 2$에서 (Z1)에 의해 $r + 1 \le 2$이고 (Z7)에 의해 $r \le 1$이다. $r = 0$이거나 $r > 0$이며, $r > 0$이면 (Z1)에 의해 $1 \le r$이므로 $r \le 1$과 함께 $r = 1$이다($r \ne 1$이면 $r < 1$이고 $1 < r$이므로 (Z5)에 어긋난다). 곧 $r = 0$ 또는 $r = 1$이다. $r = 0$이면 $a = 2q$이므로 짝수이고, $r = 1$이면 $a = 2q + 1$이므로 홀수이다. 따라서 모든 정수는 짝수이거나 홀수이다.

$a$가 짝수이면서 홀수라고 하자. $a = 2s$와 $a = 2s' + 1$인 정수 $s$, $s'$이 있다. $0 \le 0 < 2$이고 $0 \le 1 < 2$이므로 $(q, r) = (s, 0)$과 $(s', 1)$은 모두 $a = 2q + r$, $0 \le r < 2$를 만족하는 쌍이다. 유일성에 의해 두 쌍이 같아야 하므로 $0 = 1$이 되어 모순이다. 따라서 둘 다인 정수는 없다. 이 항목은 그렇게 해서 위 받아들인 사실을 정리로 만든다. [[even-and-odd]] 항목의 진술은 그대로 증명 없이 받아들인 사실로 남아 있다.
:::

## 예시와 반례

:::example[몫과 나머지 구하기]
$a = 100$, $b = 7$이면 $100 = 14 \cdot 7 + 2$이고 $0 \le 2 < 7$이므로 $q = 14$, $r = 2$입니다. $a < b$이면 $q = 0$입니다. $a = 3$, $b = 8$이면 $3 = 0 \cdot 8 + 3$이므로 $q = 0$, $r = 3$입니다. $b \mid a$이면 $r = 0$입니다. $a = 35$, $b = 5$이면 $35 = 7 \cdot 5 + 0$입니다.

$a$가 음수일 때는 나머지가 음수가 되지 않도록 $q$를 정합니다. $a = -17$, $b = 5$이면 $-17 = (-4) \cdot 5 + 3$이고 $0 \le 3 < 5$이므로 $q = -4$, $r = 3$입니다. $q = -3$을 쓰면 $-17 = (-3) \cdot 5 + (-2)$인데 $-2 < 0$이므로 조건 $0 \le r$에 어긋납니다.
:::

:::example[증명의 집합 $A$]
$a = -17$, $b = 5$에서 증명의 집합은 $A = \{-17 - 5x : x \in \mathbb{Z}, -17 - 5x \ge 0\}$입니다. $a < 0$이므로 증명처럼 $x = a = -17$을 넣으면 $-17 + 85 = 68 \in A$로 공집합이 아닙니다. $x = -4$이면 $3$, $x = -5$이면 $8$, $x = -6$이면 $13$이므로 $A = \{3, 8, 13, 18, \dots\}$이고 최소 원소는 $r = 3$, 그때의 $x$가 $q = -4$입니다.
:::

:::counterexample
조건 하나를 빼거나 바꾸면 깨집니다.

- $0 \le r$를 빼면 유일성이 깨집니다. $a = 17$, $b = 5$이면 $17 = 3 \cdot 5 + 2$이고 $17 = 4 \cdot 5 + (-3)$입니다. 두 번째 쌍도 $r < 5$를 만족하지만 $0 \le r$를 만족하지 않습니다. 이 조건이 있을 때만 쌍이 하나로 정해집니다.
- $r < b$를 빼면 마찬가지로 유일성이 깨집니다. $17 = 2 \cdot 5 + 7$이고 $0 \le 7$이지만 $7 \not< 5$입니다.
- $b > 0$을 빼면 존재가 깨집니다. $b = 0$이면 $0 \le r < 0$인 $r$이 없고, $b = -3$이면 $0 \le r < -3$인 $r$이 없습니다. $0 \le r$와 $r < -3$을 함께 만족하면 (Z6)에 의해 $0 < -3$이 되는데, $-3 < 0$이므로 (Z5)에 어긋나기 때문입니다.
:::

## 확인 질문

:::check[$a = -40$, $b = 6$일 때 몫 $q$와 나머지 $r$을 구하라.]
$-40 = qb + r$, $0 \le r < 6$이어야 합니다. $q = -7$이면 $-42 + r = -40$에서 $r = 2$이고 $0 \le 2 < 6$이므로 조건을 만족합니다. 유일성에 의해 $q = -7$, $r = 2$입니다. $q = -6$이면 $r = -4 < 0$이고 $q = -8$이면 $r = 8 \ge 6$이어서 조건에 맞지 않습니다.
:::

:::check[$b = 1$이면 임의의 정수 $a$의 몫과 나머지는 무엇인가?]
$a = a \cdot 1 + 0$이고 $0 \le 0 < 1$이므로 $q = a$, $r = 0$이 조건을 만족합니다. 유일성에 의해 이것이 유일한 쌍입니다. 곧 $1$로 나누면 나머지는 항상 $0$입니다.
:::
