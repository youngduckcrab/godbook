:::statement
$a$, $b$가 둘 다 $0$은 아닌 정수이고 $n$이 정수일 때, $a$와 $b - an$도 둘 다 $0$은 아니며

$$\gcd(a, b) = \gcd(a, b - an)$$

이다.
:::

:::english
Let $a$ and $b$ be integers that are not both $0$, and let $n$ be an integer. Then $a$ and $b - an$ are also not both $0$, and

$$\gcd(a, b) = \gcd(a, b - an).$$
:::

## 직관

$a$와 $b$를 모두 나누는 수 $d$는 $a$의 정수배 $an$도 나눕니다. 그러면 $b$에서 $an$을 뺀 수도 나눕니다. 곧 $a$와 $b$의 공약수는 $a$와 $b - an$의 공약수이기도 합니다. 반대로 $a$와 $b - an$의 공약수 $d$는 $b = (b - an) + an$도 나눕니다. 두 쌍의 공약수가 정확히 같으므로 그 가운데 가장 큰 것도 같습니다.

비유하면 두 끈 $a$, $b$를 같은 길이의 토막으로 남김없이 자르는 문제에서, 긴 끈 $b$에서 짧은 끈 $a$ 길이만큼을 $n$번 잘라 내고 남은 끈과 $a$를 비교해도 가능한 토막 길이는 달라지지 않는다는 이야기입니다. 이 비유에서 $n$이 음수이거나 $a$가 음수인 경우는 보이지 않지만, 증명은 그 경우도 똑같이 처리합니다.

이 성질은 큰 수의 최대공약수를 작은 수의 최대공약수로 바꾸어 계산하는 데 쓰입니다.

## 증명

:::idea
$a$와 $b$의 공약수의 집합과 $a$와 $b - an$의 공약수의 집합이 같음을 두 방향으로 보인다. 같은 집합의 최대 원소는 같으므로 최대공약수가 같다.
:::

:::hint
$d \mid a$이고 $d \mid b$이면 $b - an$을 $d$로 묶어 쓸 수 있는지 보세요. 반대 방향에는 $b = (b - an) + an$을 쓰세요.
:::

:::hint
두 집합이 같다는 것은 한 집합의 모든 원소가 다른 집합의 원소이고, 그 반대도 성립한다는 것입니다. 방향마다 따로 증명하세요.
:::

:::proof
**$a$와 $b - an$이 둘 다 $0$은 아니다.** 둘 다 $0$이라고 하자. $a = 0$이므로 $an = 0 \cdot n = 0$이고 $b - an = b - 0 = b$이다. $b - an = 0$이므로 $b = 0$이다. 곧 $a = b = 0$이어서 $a$, $b$가 둘 다 $0$은 아니라는 가정에 어긋난다. 따라서 $a$와 $b - an$은 둘 다 $0$은 아니고, $\gcd(a, b - an)$이 [[greatest-common-divisor]]의 정의에 의해 정의된다. 또 $b - an$은 정수이다(정수의 합·곱은 정수라는 기본 성질, [[even-and-odd]]에서 증명 없이 받아들임).

$a$와 $b$의 공약수의 집합을 $D(a, b)$, $a$와 $b - an$의 공약수의 집합을 $D(a, b - an)$이라 쓴다. 두 집합이 같음을 보인다.

**$D(a, b) \subseteq D(a, b - an)$.** 정수 $d$가 $D(a, b)$의 원소라 하자. 곧 $d \mid a$이고 $d \mid b$이다. [[divisibility|나누어떨어짐]]의 정의에 의해 $a = dc$, $b = de$인 정수 $c$, $e$가 있다. 그러면
$$b - an = de - (dc)n = d(e - cn)$$
이다(분배법칙과 결합법칙). $e - cn$은 정수이므로(정수의 합·곱은 정수) $d \mid b - an$이다. 또 $d \mid a$이므로 $d$는 $a$와 $b - an$의 공약수, 곧 $d \in D(a, b - an)$이다.

**$D(a, b - an) \subseteq D(a, b)$.** 정수 $d$가 $D(a, b - an)$의 원소라 하자. 곧 $d \mid a$이고 $d \mid b - an$이다. 정의에 의해 $a = dc$, $b - an = df$인 정수 $c$, $f$가 있다. $b = (b - an) + an$이므로
$$b = df + (dc)n = d(f + cn)$$
이다. $f + cn$은 정수이므로 $d \mid b$이다. 또 $d \mid a$이므로 $d \in D(a, b)$이다.

두 포함에 의해 $D(a, b) = D(a, b - an)$이다. 이제 $g = \gcd(a, b)$로 두자. [[greatest-common-divisor]]의 정의에 의해 $g$는 $D(a, b)$의 원소이고 $D(a, b)$의 모든 원소 $d$에 대해 $d \le g$이다. $D(a, b) = D(a, b - an)$이므로 $g$는 $a$와 $b - an$의 공약수이고, $a$와 $b - an$의 모든 공약수 $d$에 대해 $d \le g$이다. 이는 $g$가 $\gcd(a, b - an)$이 되는 두 조건과 정확히 같으므로 $g = \gcd(a, b - an)$이다. 곧 $\gcd(a, b) = \gcd(a, b - an)$이다. $\blacksquare$
:::

## 예시와 반례

:::example
$a = 14$, $b = 100$, $n = 7$이면 $b - an = 100 - 98 = 2$입니다. $\gcd(14, 100)$: $14$의 양의 약수 $1, 2, 7, 14$ 가운데 $100$을 나누는 것은 $1, 2$뿐($7 \cdot 14 = 98$, $7 \cdot 15 = 105$이므로 $100$은 $7$의 배수가 아니고, $14 \cdot 7 = 98$, $14 \cdot 8 = 112$이므로 $14$의 배수도 아님)이어서 $\gcd(14, 100) = 2$입니다. $\gcd(14, 2)$: $2$의 양의 약수 $1, 2$ 모두 $14$를 나누므로 $2$입니다. 두 값이 같습니다.

$n$이 음수여도 성립합니다. $a = 6$, $b = 4$, $n = -1$이면 $b - an = 4 - 6 \cdot (-1) = 10$입니다. $\gcd(6, 4)$: $6$의 양의 약수 $1, 2, 3, 6$ 가운데 $4$를 나누는 것은 $1, 2$이므로 $2$입니다. $\gcd(6, 10)$: $6$의 양의 약수 가운데 $10$을 나누는 것은 $1, 2$이므로 $2$입니다. 같습니다.

$n$을 고르면 $b - an = 0$이 될 수도 있습니다. $a = 7$, $b = 35$, $n = 5$이면 $b - an = 0$이고 $\gcd(7, 0) = 7$([[greatest-common-divisor]]의 (iv))이므로 $\gcd(7, 35) = 7$입니다.
:::

:::counterexample
$a$의 **정수배**를 빼야 합니다. $a = 6$, $b = 4$에서 $\gcd(6, 4) = 2$입니다. $a$의 배수가 아닌 $1$을 빼 $\gcd(6, 4 - 1) = \gcd(6, 3)$을 만들면, $3$이 $6$을 나누므로 $\gcd(6, 3) = 3$이고 $2$와 다릅니다. 증명에서 $d \mid b$이고 $d \mid a$이면 $d \mid b - an$이 되는 것은 $an$이 $a$의 배수이기 때문입니다. 실제로 $D(6, 4)$의 양의 원소는 $1, 2$이고 $D(6, 3)$의 양의 원소는 $1, 3$이어서 공약수의 집합이 달라집니다.
:::

## 확인 질문

:::check[$a = 15$, $b = 100$, $n = 6$일 때 $b - an$을 구하고, 이 정리로 $\gcd(15, 100)$을 구하라.]
$b - an = 100 - 15 \cdot 6 = 100 - 90 = 10$입니다. 정리에 의해 $\gcd(15, 100) = \gcd(15, 10)$입니다. $15$의 양의 약수 $1, 3, 5, 15$ 가운데 $10$을 나누는 것은 $1, 5$이므로 $\gcd(15, 10) = 5$이고 $\gcd(15, 100) = 5$입니다.
:::

:::check[$n$을 어떻게 고르면 $b - an = 0$이 되는가? $a = 9$, $b = 54$에서 구하고 $\gcd(9, 54)$를 말하라.]
$54 = 9 \cdot 6$이므로 $n = 6$이면 $b - an = 0$입니다. 정리에 의해 $\gcd(9, 54) = \gcd(9, 0)$이고, $9 > 0$이므로 [[greatest-common-divisor]]의 (iv)에 의해 $\gcd(9, 0) = 9$입니다. 따라서 $\gcd(9, 54) = 9$입니다.
:::
