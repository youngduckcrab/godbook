:::statement
절댓값은 [[absolute-value]]의 것이다. 실수 $x$, $y$, $z$에 대하여 다음이 성립한다. 여기서 $x + y + z$는 $(x + y) + z$를 뜻한다.

1. (**삼각부등식**, triangle inequality) $|x + y| \le |x| + |y|$이다.
2. (**역삼각부등식**, reverse triangle inequality) $\bigl|\,|x| - |y|\,\bigr| \le |x - y|$이다.
3. $|x - y| \le |x| + |y|$이다.
4. $|x - z| \le |x - y| + |y - z|$이다.
5. $|x + y + z| \le |x| + |y| + |z|$이다.
:::

:::english
The absolute value is the one in the entry on absolute value. For real numbers $x$, $y$, $z$ the following hold. Here $x + y + z$ means $(x + y) + z$.

1. (**Triangle inequality**) $|x + y| \le |x| + |y|$.
2. (**Reverse triangle inequality**) $\bigl|\,|x| - |y|\,\bigr| \le |x - y|$.
3. $|x - y| \le |x| + |y|$.
4. $|x - z| \le |x - y| + |y - z|$.
5. $|x + y + z| \le |x| + |y| + |z|$.
:::

## 직관

[[absolute-value|절댓값]]을 수직선 위의 거리로 읽으면, (4)는 "$x$에서 $z$로 곧장 가는 거리는 $y$를 거쳐 가는 거리 이하"라는 말입니다. 학교에서 집으로 가는 길에 편의점을 들르면 걷는 거리가 같거나 늘어나는 것과 같습니다. 평면에서 삼각형의 한 변의 길이가 다른 두 변의 길이의 합 이하라는 것과 같은 꼴입니다.

수직선 위에서는 세 점이 한 줄에 있으므로, 그림으로 보면 편의점 $y$가 $x$와 $z$ 사이에 있을 때는 거쳐 가도 거리가 같고, 바깥에 있을 때는 돌아가는 만큼 길어집니다. 비유가 맞지 않는 곳은 이 항목이 "거리"나 "길"을 정의하지 않는다는 점입니다. 증명은 그림이 아니라 [[absolute-value|절댓값]]의 (6), (7)과 부등식의 덧셈으로만 합니다.

(1)의 증명에서 쓰는 생각은 간단합니다. $x$는 $-|x|$와 $|x|$ 사이에, $y$는 $-|y|$와 $|y|$ 사이에 있으므로, 더한 $x + y$는 $-(|x| + |y|)$와 $|x| + |y|$ 사이에 있습니다. 나머지 (2)–(5)는 (1)에 알맞은 수를 넣어 얻습니다.

## 증명

:::idea
$-|x| \le x \le |x|$와 $-|y| \le y \le |y|$를 더하면 $x + y$가 $-(|x| + |y|)$와 $|x| + |y|$ 사이에 있다. 나머지는 (1)에 $x - y$, $y$ 같은 수를 넣어 얻는다.
:::

:::hint
(1)에서 "$|a| \le b$인 것은 정확히 $-b \le a \le b$일 때"를 $a = x + y$, $b = |x| + |y|$에 쓴다.
:::

:::hint
(2)는 $x = (x - y) + y$에 (1)을 써서 $|x| - |y| \le |x - y|$를 얻고, $x$와 $y$의 역할을 바꾼 부등식과 합친다.
:::

:::proof
(K…)는 [[real-number-arithmetic]]의 진술이다. "순서 성질 (2)의 (iii)"처럼 쓴 것은 [[order-properties-of-reals]]의 번호이고, "절댓값 (7)"처럼 쓴 것은 [[absolute-value]]의 번호이다. 증명에서 쓰는 계산을 먼저 적는다. $a$, $b$, $c$는 실수이다.

- (가) $(a - b) + b = a$이다. (K2), (K1), $-b$의 정의((K8)의 (ii)), (K4)에 의해 $(a + (-b)) + b = a + ((-b) + b) = a + (b + (-b)) = a + 0 = a$이다.
- (나) $-(a - b) = b - a$이다. (K12)의 (iv), (K9)의 $-(-b) = b$, (K1)에 의해 $-(a + (-b)) = (-a) + (-(-b)) = (-a) + b = b + (-a)$이다.
- (다) $(a - b) + (b - c) = a - c$이다. (K2)를 두 번 쓰면 $(a + (-b)) + (b + (-c)) = a + (((-b) + b) + (-c))$이고, (K1)과 $-b$의 정의에 의해 $(-b) + b = 0$, (K1)과 (K4)에 의해 $0 + (-c) = -c$이므로 $a + (-c) = a - c$이다.

**1의 증명.** 절댓값 (6)에 의해 $-|x| \le x \le |x|$이고 $-|y| \le y \le |y|$이다. 순서 성질 (2)의 (iii)에 의해 $x + y \le |x| + |y|$이고 $(-|x|) + (-|y|) \le x + y$이다. (K12)의 (iv)에 의해 $(-|x|) + (-|y|) = -(|x| + |y|)$이므로
$$
-(|x| + |y|) \le x + y \le |x| + |y|
$$
이다. 절댓값 (7)의 첫 문장을 $x + y$와 $|x| + |y|$에 쓰면 $|x + y| \le |x| + |y|$이다.

**2의 증명.** (가)에 의해 $x = (x - y) + y$이므로 (1)에 의해 $|x| \le |x - y| + |y|$이다. 순서 성질 (2)의 (i)로 양변에 $-|y|$를 더하면 $|x| + (-|y|) \le (|x - y| + |y|) + (-|y|)$이다. 왼쪽은 $|x| - |y|$이고, 오른쪽은 (K2), $-|y|$의 정의((K8)의 (ii)), (K4)에 의해 $|x - y| + (|y| + (-|y|)) = |x - y| + 0 = |x - y|$이다. 따라서
$$
|x| - |y| \le |x - y|
$$
이다. 이 논증을 $x$와 $y$의 자리를 바꾸어 다시 쓴다. (가)에 의해 $y = (y - x) + x$이므로 (1)에 의해 $|y| \le |y - x| + |x|$이다. 순서 성질 (2)의 (i)로 양변에 $-|x|$를 더하면 $|y| + (-|x|) \le (|y - x| + |x|) + (-|x|)$이고, 오른쪽은 (K2), $-|x|$의 정의, (K4)에 의해 $|y - x| + (|x| + (-|x|)) = |y - x| + 0 = |y - x|$이므로 $|y| - |x| \le |y - x|$이다. 절댓값 (3)에 의해 $|y - x| = |x - y|$이고, (나)에 의해 $|y| - |x| = -(|x| - |y|)$이므로 $-(|x| - |y|) \le |x - y|$이다. 순서 성질 (3)의 (iii)에 의해 $-|x - y| \le -(-(|x| - |y|))$이고, (K9)에 의해 $-(-(|x| - |y|)) = |x| - |y|$이다. 따라서
$$
-|x - y| \le |x| - |y| \le |x - y|
$$
이고, 절댓값 (7)의 첫 문장을 $|x| - |y|$와 $|x - y|$에 쓰면 $\bigl|\,|x| - |y|\,\bigr| \le |x - y|$이다.

**3의 증명.** (1)을 $x$와 $-y$에 쓰면 $|x + (-y)| \le |x| + |-y|$이다. 뺄셈의 정의에 의해 $x + (-y) = x - y$이고, 절댓값 (3)에 의해 $|-y| = |y|$이므로 $|x - y| \le |x| + |y|$이다.

**4의 증명.** (다)에 의해 $x - z = (x - y) + (y - z)$이다. (1)을 $x - y$와 $y - z$에 쓰면 $|x - z| \le |x - y| + |y - z|$이다.

**5의 증명.** (1)을 $x + y$와 $z$에 쓰면 $|(x + y) + z| \le |x + y| + |z|$이다. (1)에 의해 $|x + y| \le |x| + |y|$이므로 순서 성질 (2)의 (i)에 의해 $|x + y| + |z| \le (|x| + |y|) + |z|$이다. 순서 성질 (1)의 (v)에 의해 $|x + y + z| \le |x| + |y| + |z|$이다. $\blacksquare$
:::

## 예시와 반례

:::example[등호가 성립하는 경우와 아닌 경우]
$x = 2$, $y = 3$이면 $|x + y| = |5| = 5$이고 $|x| + |y| = 2 + 3 = 5$이어서 (1)에서 등호가 성립합니다. $x = 3$, $y = -5$이면 $x + y = -2$이고 $|-2| = 2$, $|x| + |y| = 3 + 5 = 8$이어서 $2 < 8$입니다. 뒤의 경우에는 부호가 다른 $3$과 $-5$가 더해지며 일부가 상쇄되어 $|x + y|$가 $|x| + |y|$보다 작아졌습니다. (여기서 $0 \le 2$, $0 \le 3$, $0 \le 5$이므로 [[absolute-value|절댓값]]의 (1)에 의해 각 수의 절댓값은 자신이고, $-2$와 $-5$는 음수이므로 절댓값의 정의와 (K9)에 의해 $|-2| = 2$, $|-5| = 5$입니다.)
:::

:::example[같은 수에 가까운 두 수]
실수 $s$, $t$가 $|s - 4| < 1$이고 $|t - 4| < 1$을 만족하면 $|s - t| < 2$입니다. (4)에 의해 $|s - t| \le |s - 4| + |4 - t|$이고, [[absolute-value|절댓값]]의 (3)에 의해 $|4 - t| = |t - 4| < 1$입니다. [[order-properties-of-reals]]의 (2)의 (iv)를 $|s - 4| < 1$과 $|4 - t| \le 1$에 쓰면 $|s - 4| + |4 - t| < 1 + 1 = 2$이므로, 그 항목의 (1)의 (v)에 의해 $|s - t| < 2$입니다. 두 수가 모두 $4$에서 $1$ 미만으로 떨어져 있으면, 서로는 $2$ 미만으로 떨어져 있습니다.
:::

:::counterexample[$|x - y| \le |x| - |y|$는 $x = 1$, $y = -1$에서 성립하지 않는다]
(1)을 빼기에도 같은 꼴로 옮겨 "$|x - y| \le |x| - |y|$"라고 쓰는 실수가 있습니다. $x = 1$, $y = -1$이면 (K9)에 의해 $x - y = 1 + (-(-1)) = 1 + 1 = 2$이므로 $|x - y| = 2$이고, $|-1| = -(-1) = 1$이므로 $|x| - |y| = 1 - 1 = 0$입니다. [[order-properties-of-reals]]의 (10)에 의해 $0 < 2$이고, 그 항목의 (1)의 (i)에 의해 $0 < 2$와 $2 \le 0$은 함께 성립하지 않으므로 $2 \le 0$은 성립하지 않습니다. 맞는 부등식은 방향이 반대인 (2)의 $\bigl|\,|x| - |y|\,\bigr| \le |x - y|$와 (3)의 $|x - y| \le |x| + |y|$입니다. 이 수에서 두 부등식은 $0 \le 2$와 $2 \le 2$입니다.
:::

## 확인 질문

:::check[실수 $x$가 $|x - 5| < 1$을 만족하면 $|x| < 6$인가?]
그렇습니다. (K2), (K1), $-5$의 정의((K8)의 (ii)), (K4)에 의해 $(x - 5) + 5 = x + ((-5) + 5) = x + 0 = x$이므로, (1)에 의해 $|x| \le |x - 5| + |5| = |x - 5| + 5$입니다. $|x - 5| < 1$에 [[order-properties-of-reals]]의 (2)의 (ii)로 $5$를 더하면 $|x - 5| + 5 < 1 + 5 = 6$이고, 그 항목의 (1)의 (v)에 의해 $|x| < 6$입니다.
:::

:::check[$x = -2$, $y = 3$에서 (2)의 양변은 같은가?]
같지 않습니다. $|x| = 2$, $|y| = 3$이므로 $|x| - |y| = -1$이고 $\bigl|\,|x| - |y|\,\bigr| = |-1| = 1$입니다. 한편 $x - y = -5$이므로 $|x - y| = 5$입니다. (2)는 $1 \le 5$이고, $1 < 5$이므로 등호는 성립하지 않습니다.
:::
