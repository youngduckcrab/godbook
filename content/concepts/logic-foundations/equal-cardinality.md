:::statement
$A$와 $B$가 [[set]]일 때, $A$에서 $B$로의 전단사인 함수(줄여서 **전단사**, bijection) $f : A \to B$([[injective-surjective-bijective]], 공역은 $f : A \to B$라고 쓸 때 밝힌 $B$)가 **존재하면** $A$와 $B$는 **크기가 같다**(have the same cardinality)고 하고 $|A| = |B|$로 쓴다. 이런 $f$가 **하나도 없으면** $A$와 $B$의 크기가 같지 않다고 하고 $|A| \ne |B|$로 쓴다.

이 정의는 "$|A| = |B|$"라는 표기 전체에 뜻을 준다. $A$가 [[set]]에서 말한 원소가 유한 개인 집합일 때의 $|A|$는 원소의 개수였지만, 이 정의에서는 $|A|$ 자체에 어떤 수도 짝지어 주지 않는다. $|A| = |B|$인지 아닌지는 $A$에서 $B$로의 전단사가 있느냐 없느냐로 정해진다.
:::

:::english
Let $A$ and $B$ be sets. If there **exists** a bijective function (a **bijection**) $f : A \to B$ (here $B$ is the codomain named in the notation $f : A \to B$), then $A$ and $B$ are said to have the **same cardinality**, and we write $|A| = |B|$. If **no** such function exists, then $A$ and $B$ are said not to have the same cardinality, and we write $|A| \ne |B|$.

This definition gives a meaning to the whole expression "$|A| = |B|$". For a set $A$ with finitely many elements, $|A|$ was the number of elements, but under this definition no number is assigned to $|A|$ itself. Whether $|A| = |B|$ holds is decided by whether there exists a bijection from $A$ to $B$.
:::

## 직관

강당에서 손님들이 의자에 앉는 상황을 생각합시다. 손님 수도 의자 수도 세지 않아도, 모든 손님이 의자 하나에 앉았고(함수: 모든 손님에게 의자가 있고 한 손님이 의자 둘을 차지하지 않는다), 한 의자에 두 명이 앉지 않았고(단사), 빈 의자가 없다(전사)는 것만 확인하면 손님과 의자가 "같은 수"라고 말할 수 있습니다. 손님의 집합이 $A$, 의자의 집합이 $B$, 앉는 규칙이 $f : A \to B$입니다. 이 정의는 "짝짓기가 가능하다"를 크기가 같다는 말의 뜻으로 삼습니다.

원소가 유한 개인 집합에서는 짝지을 수 있을 때와 개수가 같을 때가 일치하는 것이 우리의 경험입니다. 아래 첫째 예가 그런 경우입니다. 이 항목은 이것을 일반적으로 증명하지 않습니다. 새로운 점은 원소를 다 셀 수 없는 집합에도 같은 정의를 쓴다는 것입니다. 이때 $|A|$는 어떤 수가 아니고, $|A| = |B|$라는 표기가 "$A$에서 $B$로의 전단사가 존재한다"를 줄여 쓴 것입니다. 정의는 $A$에서 $B$로 가는 방향으로 쓰여 있습니다. $B$에서 $A$로의 전단사를 말하는 것이 아니며, 두 방향의 관계는 이 항목에서 다루지 않습니다. 크기가 같다는 관계가 반사·대칭·추이를 만족한다는 사실은 이 항목이 증명하지 않으며 쓰지도 않습니다. 이 단원의 뒤에서 따로 증명합니다.

이 정의에서는 집합의 일부가 전체와 크기가 같을 수 있습니다. 아래 둘째 예에서 짝수인 자연수의 집합은 자연수의 집합에 들어 있는 일부인데, 둘 사이에 전단사가 있습니다. 의자가 5개이고 손님 5명이 모두 앉아 있을 때, 같은 손님 5명을 의자 일부(예: 3개)에만 한 명씩 앉힐 수는 없다는 것이 우리의 경험입니다(이 항목은 이를 증명하지 않습니다). 그런데 의자와 손님에게 $1, 2, 3, \dots$번이 끝없이 붙어 있으면, 손님 $n$을 의자 $2n$에 앉혀 손님 전원이 짝수 번 의자에만 한 명씩 앉을 수 있습니다. 유한한 강당의 경험은 이 비유가 놓치는 곳이고, 여기서 깨집니다.

## 예시와 반례

변수 문자와 겹치지 않도록 원소 이름으로 가, 나, 다를 씁니다.

:::example[크기가 같은 작은 유한집합]
$A = \{1, 2, 3\}$, $B = \{\text{가}, \text{나}, \text{다}\}$이고 $f = \{(1, \text{다}), (2, \text{가}), (3, \text{나})\}$라 합시다. $1, 2, 3$ 각각이 첫째 성분으로 정확히 한 번 나오고 둘째 성분은 모두 $B$의 원소이므로 $f : A \to B$는 함수입니다. 값 $f(1) = \text{다}$, $f(2) = \text{가}$, $f(3) = \text{나}$가 서로 다르므로 단사입니다. 가, 나, 다가 모두 값으로 나오므로($\text{가} = f(2)$, $\text{나} = f(3)$, $\text{다} = f(1)$) 전사입니다. 따라서 $f$는 전단사이고 $|A| = |B|$입니다.
:::

:::example[자연수와 짝수인 자연수]
$E$를 짝수인 자연수의 집합, 곧 $E = \{n \in \mathbb{N} : n \text{은 짝수}\}$라 하고, $f(n) = 2n$으로 정한 $f : \mathbb{N} \to E$를 봅시다. 정수의 곱은 정수이므로 $2n$은 정수이고, $n \ge 1$이므로 [[prime-number|소수]] 항목의 진술에서 받아들인 성질 (Z3)에 의해 $2n \ge 2 \cdot 1 = 2$이니 $2n \in \mathbb{N}$입니다. $2n = 2 \cdot n$이고 $n$은 정수이므로 $2n$은 [[even-and-odd|짝수]]입니다. 따라서 $f(n) \in E$이고 $f$는 $\mathbb{N}$에서 $E$로의 함수입니다.

단사: $f(a) = f(a')$이면 $2a = 2a'$이고 양변을 $2$로 나누면 $a = a'$입니다. 전사: $e \in E$라 합시다. $e$가 짝수이므로 $e = 2k$인 정수 $k$가 있습니다. $k \le 0$이면 (Z3)에 의해 $e = 2k \le 0$인데 $e \ge 1$이므로 모순이고, 따라서 $k > 0$입니다. 정수 $k > 0$이면 (Z1)에서 $0 + 1 \le k$이므로 $k \ge 1$이고 $k \in \mathbb{N}$입니다. $f(k) = 2k = e$입니다. 따라서 $f$는 전단사이고 $|\mathbb{N}| = |E|$입니다.

$E \subseteq \mathbb{N}$이지만 $1 \in \mathbb{N}$은 $1 = 2 \cdot 0 + 1$이므로 홀수이고, 짝수이면서 홀수인 정수는 없으므로 $1 \notin E$입니다. 일부분 $E$가 전체 $\mathbb{N}$과 크기가 같습니다. 이 예에서 증명 없이 쓴 성질은 (Z1), (Z3) 말고도 등식의 양변을 $2$로 나눌 수 있다는 것, $\le$와 $<$의 추이, 정수가 $0$ 이하가 아니면 $0$보다 크다는 것입니다.
:::

:::counterexample[원소가 2개인 집합과 3개인 집합]
"$|A| \ne |B|$"는 전단사가 하나도 없다는 뜻이므로, 함수 하나가 전단사가 아니라는 것만으로는 보이지 못합니다. 예를 들어 $A = \{1, 2\}$, $B = \{\text{가}, \text{나}\}$이고 $g = \{(1, \text{가}), (2, \text{가})\}$는 $g(1) = g(2)$이고 $1 \ne 2$이므로 단사가 아니어서 전단사가 아닙니다. 그러나 $\{(1, \text{가}), (2, \text{나})\}$는 전단사이므로 $|A| = |B|$입니다.

$|A| \ne |B|$를 보이려면 가능한 함수를 빠짐없이 따져야 합니다. $A = \{1, 2\}$, $B = \{\text{가}, \text{나}, \text{다}\}$로 합시다. $A$에서 $B$로의 함수는 $f(1)$과 $f(2)$를 각각 $B$의 원소로 고르는 것이므로 모두 $9$개이고 $(f(1), f(2))$로 나열하면 다음과 같습니다. 각각 값으로 나오지 않는 공역의 원소가 적어도 하나 있으므로(표에는 그중 하나를 적었습니다) 전사가 아닙니다.

| $(f(1), f(2))$ | 값이 아닌 공역의 원소 |
|---|---|
| (가, 가) | 나 |
| (가, 나) | 다 |
| (가, 다) | 나 |
| (나, 가) | 다 |
| (나, 나) | 가 |
| (나, 다) | 가 |
| (다, 가) | 나 |
| (다, 나) | 가 |
| (다, 다) | 가 |

전단사가 하나도 없으므로 $|A| \ne |B|$입니다. 이 확인은 $A$에서 $B$로의 함수만 다룹니다.
:::

:::counterexample[전사가 아닌 함수가 있다고 크기가 다른 것은 아니다]
$h(n) = 2n$인 $h : \mathbb{N} \to \mathbb{N}$은 $2a = 2a'$이면 $a = a'$이므로 단사입니다. $1 \in \mathbb{N}$에 대하여 $2n = 1$인 정수 $n$이 없으므로($n \le 0$이면 $2n \le 0$이고 $n \ge 1$이면 $2n \ge 2$) 전사가 아닙니다. 그렇다고 $|\mathbb{N}| \ne |\mathbb{N}|$인 것은 아닙니다. $\mathrm{id}(n) = n$인 $\mathrm{id} : \mathbb{N} \to \mathbb{N}$은 $\mathrm{id}(a) = \mathrm{id}(a')$이면 $a = a'$이므로 단사이고, 모든 $b \in \mathbb{N}$에 대해 $\mathrm{id}(b) = b$이므로 전사이어서 전단사이고, $|\mathbb{N}| = |\mathbb{N}|$입니다.
:::

## 확인 질문

:::check[$A = \{1, 2, 3\}$, $B = \{5, 6, 7\}$이고 $f(n) = n + 4$이다. $|A| = |B|$임을 보여라.]
$f(1) = 5$, $f(2) = 6$, $f(3) = 7$이므로 $f : A \to B$는 함수이고, 세 값이 서로 달라 단사이며, $B$의 원소 $5, 6, 7$이 모두 값이므로 전사입니다. 전단사가 존재하므로 $|A| = |B|$입니다.
:::

:::check[$A = \{1, 2, 3\}$, $B = \{2, 4, 6\}$이고 $g(n) = 2$로 정한 $g : A \to B$는 상수함수이다. $g$가 전단사가 아니므로 $|A| \ne |B|$인가?]
아닙니다. $g(1) = g(2) = 2$이고 $1 \ne 2$이므로 $g$는 단사가 아니어서 전단사가 아닙니다. 그러나 $|A| \ne |B|$는 전단사가 하나도 없다는 뜻인데, $h(n) = 2n$으로 정한 $h : A \to B$는 $h(1) = 2$, $h(2) = 4$, $h(3) = 6$이므로 값이 서로 다르고 $B$의 원소가 모두 나와 전단사입니다. 따라서 $|A| = |B|$입니다.
:::
