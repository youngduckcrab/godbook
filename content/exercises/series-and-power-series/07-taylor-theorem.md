:::exercise[$x \exp(x)$의 고계 도함수와 극소]
$f(x) = x \exp(x)$로 정한 $f : \mathbb{R} \to \mathbb{R}$를 생각한다.

1. $f$가 무한 번 미분가능하고 $0$ 이상인 모든 정수 $k$와 실수 $x$에서 $f^{(k)}(x) = (x + k)\exp(x)$임을 보여라.
2. $T_3^{0} f$를 구하라.
3. $f'(x) = 0$인 실수 $x$를 모두 구하고, 그 점에서 $f$가 엄격한 극소인지 엄격한 극대인지 판정하라.
:::

:::solution
**(1)** $0$ 이상인 정수 $k$마다 $v_k(x) = (x + k)\exp(x)$로 정한 $v_k : \mathbb{R} \to \mathbb{R}$를 생각한다. $0$ 이상인 정수 $n$에 대한 명제 "$f$는 $n$번 미분가능하고 $0 \le k \le n$인 모든 $k$에서 $f^{(k)} = v_k$이다"를 [[mathematical-induction|수학적 귀납법]](시작점 $0$)으로 보인다.

- $n = 0$: [[higher-derivative|고계 도함수]]의 정의에 의해 $f$는 $0$번 미분가능하고, 그 (1)에 의해 $f^{(0)} = f = v_0$이다.
- $n$에서 $n + 1$로: $x$에서의 값이 $x + n$인 함수는 [[derivative|미분계수와 도함수]]의 (1)에 의해 미분가능하고 도함수의 값이 $1$이며, [[exponential-function|지수함수]]의 (3)에 의해 $\exp' = \exp$이다. [[derivative-rules|미분의 선형성과 곱·몫의 법칙]]의 (6)의 곱의 법칙에 의해 $v_n$은 미분가능한 함수이고, [[real-number-arithmetic|실수의 계산 법칙]]의 (K3), (K4)로
  $$
  \begin{aligned}
  v_n'(x) &= (x + n)\exp(x) \\
  &\qquad + 1 \cdot \exp(x) \\
  &= v_{n+1}(x)
  \end{aligned}
  $$
  이다. 귀납 가정에 의해 $f^{(n)} = v_n$은 미분가능한 함수이므로, 고계 도함수의 (2)에 의해 $f$는 $n + 1$번 미분가능하고 (1)에 의해 $f^{(n+1)} = (f^{(n)})' = v_{n+1}$이다. $k \le n$에서는 귀납 가정이 그대로 $f^{(k)} = v_k$를 준다.

따라서 $f$는 $0$ 이상인 모든 $n$에서 $n$번 미분가능하여 무한 번 미분가능하고, $f^{(k)} = v_k$이다.

**(2)** 지수함수의 (1)에 의해 $\exp(0) = 1$이므로 $f^{(k)}(0) = k$이다. [[taylor-polynomial|테일러 다항식]]의 정의와 [[factorial-from-zero|0부터의 계승]]의 (1)($0! = 1! = 1$, $2! = 2$, $3! = 6$)에 의해
$$
\begin{aligned}
T_3^{0} f(x) &= 0 + 1 \cdot x + 2 \cdot 2^{-1} x^2 \\
&\qquad + 3 \cdot 6^{-1} x^3 \\
&= x + x^2 + 2^{-1} x^3
\end{aligned}
$$
이다.

**(3)** 지수함수의 (1)에 의해 $0 < \exp(x)$이므로 $\exp(x) \ne 0$이고, (K10)과 (K9)에 의해 $f'(x) = (x + 1)\exp(x) = 0$인 것은 정확히 $x + 1 = 0$, 곧 $x = -1$일 때이다. (1)에 의해 $f$는 $2$번 미분가능하고 $f''(-1) = (-1 + 2)\exp(-1) = \exp(-1) > 0$이다. [[second-derivative-test|이계도함수 판정법]]의 (2)에 의해 $f$는 $-1$에서 엄격한 극소이고, 그 값은 $f(-1) = -\exp(-1)$이다.
:::

:::exercise[테일러 다항식의 도함수]
$I$를 구간, $x_0$을 $I$의 원소, $n$을 $0$ 이상인 정수라 하고, $f : I \to \mathbb{R}$가 $n + 1$번 미분가능하다고 하자.

1. $f'$이 $n$번 미분가능함을 보여라.
2. $T_{n+1}^{x_0} f$의 도함수가 $T_n^{x_0}(f')$임을 보여라. 두 함수는 모두 $\mathbb{R}$ 위의 함수이다.
3. 문제 1의 $f(x) = x\exp(x)$와 $x_0 = 0$, $n = 2$에서 (2)를 직접 확인하라.
:::

:::solution
**(1)** $n + 1 \ge 1$이므로 [[higher-derivative|고계 도함수]]의 (2)에 의해 $f$는 $1$번 미분가능하고, 그 (1)에 의해 미분가능한 함수이다. 같은 항목의 (4)에 의해 $f'$은 $n$번 미분가능하고, $0 \le k \le n$인 모든 $k$에서 $(f')^{(k)} = f^{(k+1)}$이다.

**(2)** $0 \le j \le n + 1$인 $j$에서 $b_j = f^{(j)}(x_0)\,(j!)^{-1}$로 두면, [[taylor-polynomial|테일러 다항식]]의 정의에 의해 $T_{n+1}^{x_0} f$는 고계 도함수의 (8)의 꼴의 함수 $h(x) = \sum_{j=0}^{n+1} b_j (x - x_0)^j$에서 중심이 $x_0$, $m = n + 1$, 계수가 $b_0, \dots, b_{n+1}$인 것이다. 그 (8)의 (i)을 $\ell = 1$에 쓰고 (1)의 $h^{(1)} = h'$을 쓰면, 모든 실수 $x$에서
$$
h'(x) = \sum_{j=0}^{n} \frac{(j + 1)!}{j!}\, b_{j+1}\, (x - x_0)^j
$$
이다. [[factorial-from-zero|0부터의 계승]]의 (4)의 첫째 식과 셋째 식에 의해
$$
\begin{aligned}
\frac{(j + 1)!}{j!}\, b_{j+1} &= (j + 1)\,\bigl((j + 1)!\bigr)^{-1} \\
&\qquad \cdot f^{(j+1)}(x_0) \\
&= (j!)^{-1} f^{(j+1)}(x_0)
\end{aligned}
$$
이고, (1)에 의해 이것은 $(f')^{(j)}(x_0)\,(j!)^{-1}$이다. 합의 각 항이 같으므로([[series-indexed-from-zero]]의 범위에서만 정해진 항의 합의 정의와 [[finite-sum-of-reals|실수의 유한 합]]의 (4)) $h'(x) = T_n^{x_0}(f')(x)$이고, [[real-valued-function|실함수와 그 연산]]의 (2)에 의해 $(T_{n+1}^{x_0} f)' = T_n^{x_0}(f')$이다.

**(3)** 문제 1의 (1)에 의해 $f^{(k)}(0) = k$이고 $f'$은 $x$에서의 값이 $(x + 1)\exp(x)$인 함수이며, (1)에 의해 $(f')^{(k)}(0) = f^{(k+1)}(0) = k + 1$이다. 문제 1의 (2)의 $T_3^{0} f(x) = x + x^2 + 2^{-1}x^3$을 고계 도함수의 (8)의 (i)로 미분하면 $1 + 2x + 3 \cdot 2^{-1} x^2$이다. 한편
$$
\begin{aligned}
T_2^{0}(f')(x) &= 1 + 2x + 3 \cdot (2!)^{-1} x^2 \\
&= 1 + 2x + 3 \cdot 2^{-1} x^2
\end{aligned}
$$
이므로 두 값이 같다.
:::

:::exercise[이계도함수가 0 이상인 함수와 접선]
$I$를 구간이라 하고 $f : I \to \mathbb{R}$가 $2$번 미분가능하며 $I$의 모든 점 $t$에서 $0 \le f''(t)$라 하자.

1. $I$의 모든 원소 $x_0$, $x$에서 $f(x_0) + f'(x_0)(x - x_0) \le f(x)$임을 보여라.
2. 이를 써서 모든 실수 $x$에서 $4x - 3 \le x^4$임을 보여라.
3. $p(x) = x^3$으로 정한 $p : \mathbb{R} \to \mathbb{R}$, $x_0 = 1$에서는 $p(x_0) + p'(x_0)(x - x_0) \le p(x)$가 $x = -3$에서 성립하지 않음을 보이고, (1)의 가정 가운데 무엇이 성립하지 않는지 말하라.
:::

:::solution
아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**(1)** $x = x_0$이면 양쪽이 모두 $f(x_0)$이다(K9). $x \ne x_0$이라 하자. [[taylor-theorem|테일러 정리]]의 (3)을 $n = 1$에 쓰면 $\min\{x_0, x\} < c < \max\{x_0, x\}$이고 $c \in I$인 실수 $c$가 있어
$$
\begin{aligned}
f(x) &= T_1^{x_0} f(x) \\
&\qquad + f^{(2)}(c)\,(2!)^{-1} (x - x_0)^2
\end{aligned}
$$
이다. [[taylor-polynomial|테일러 다항식]]의 (1)에 의해 $T_1^{x_0} f(x) = f(x_0) + f'(x_0)(x - x_0)$이다. 가정에 의해 $0 \le f''(c) = f^{(2)}(c)$이고, $(2!)^{-1} = 2^{-1} > 0$이며([[factorial-from-zero|0부터의 계승]]의 (1), 순서 성질 (6)의 (i)), [[power-of-a-real-number|실수의 거듭제곱]]의 (1)과 순서 성질 (5)의 (iii)에 의해 $0 \le (x - x_0)^2$이다. 순서 성질 (4)의 (iv)에 의해 마지막 항은 $0$ 이상이고, 순서 성질 (2)의 (i)에 의해 $T_1^{x_0} f(x) \le f(x)$이다.

**(2)** $f(x) = x^4$은 [[higher-derivative|고계 도함수]]의 (8)의 꼴에서 $a = 0$, $m = 4$, $c_4 = 1$, 나머지 계수가 $0$인 함수이다. 그 (8)에 의해 $f$는 무한 번 미분가능하고, (8)의 (i)에 의해 $f'(x) = 4!\,(3!)^{-1} x^3 = 4x^3$, $f''(x) = 4!\,(2!)^{-1} x^2 = 12 x^2$이다. 순서 성질 (5)의 (iii), (10)의 $0 < 12$와 (4)의 (iv)에 의해 모든 $t$에서 $0 \le f''(t)$이므로, (1)을 $I = \mathbb{R}$, $x_0 = 1$에 쓰면 $f(1) = 1$, $f'(1) = 4$에서
$$
1 + 4(x - 1) = 4x - 3 \le x^4
$$
이다. 예컨대 $x = 0$에서 $-3 \le 0$이고 $x = 2$에서 $5 \le 16$이며, $x = 1$에서 등호이다.

**(3)** 고계 도함수의 (8)에 의해 $p'(x) = 3x^2$, $p''(x) = 6x$이다. $p(1) + p'(1)(-3 - 1) = 1 + 3 \cdot (-4) = -11$이고 $p(-3) = -27$이며 $-27 < -11$이므로, 순서 성질 (1)의 (i)에 의해 부등식은 성립하지 않는다. 성립하지 않는 가정은 "모든 $t$에서 $0 \le p''(t)$"이다. 예컨대 $p''(-1) = -6 < 0$이다. 실제로 테일러 정리의 (3)이 주는 $c$는 $-3 < c < 1$인 점이고, 이 예에서 나머지항 $p''(c)\,(2!)^{-1}\,16 = -27 + 11 = -16$에서 $c = -3^{-1}$이며 $p''(c) = -2 < 0$이다.
:::

:::exercise[$f'' = f$이고 0 에서 값과 미분계수가 0 인 함수]
1. $f : \mathbb{R} \to \mathbb{R}$가 $2$번 미분가능하고 $f'' = f$이며 $f(0) = 0$, $f'(0) = 0$이면 $f$는 값이 $0$인 상수함수임을 보여라.
2. $g : \mathbb{R} \to \mathbb{R}$가 $2$번 미분가능하고 $g'' = g$이며 $g(0) = 1$, $g'(0) = 1$이면 $g = \exp$임을 보여라.
:::

:::solution
아래에서 "고계 도함수"는 [[higher-derivative|고계 도함수]]의 번호이다.

**(1)** *첫째 걸음.* $0$ 이상인 정수 $n$에 대한 명제 "$f$는 $n$번 미분가능하고, $n$이 짝수이면 $f^{(n)} = f$, 홀수이면 $f^{(n)} = f'$이다"를 [[mathematical-induction|수학적 귀납법]](시작점 $0$)으로 보인다. [[even-and-odd|짝수와 홀수]]에서 받아들인 사실에 의해 각 정수는 짝수이거나 홀수이고 둘 다는 아니며, $n = 2b$이면 $n + 1 = 2b + 1$은 홀수이고 $n = 2b + 1$이면 $n + 1 = 2(b + 1)$은 짝수이다.

- $n = 0$은 짝수이고 고계 도함수의 (1)에 의해 $f^{(0)} = f$이다.
- $f$가 $2$번 미분가능하므로 고계 도함수의 (2)와 (1)에 의해 $f$와 $f'$은 미분가능한 함수이고 $f'' = (f')'$이다. $n$이 짝수이면 $f^{(n)} = f$가 미분가능한 함수이므로 고계 도함수의 (2), (1)에 의해 $f$는 $n + 1$번 미분가능하고 $f^{(n+1)} = f'$이다. $n$이 홀수이면 $f^{(n)} = f'$이 미분가능한 함수이므로 같은 이유로 $f^{(n+1)} = (f')' = f'' = f$이다.

따라서 $f$는 무한 번 미분가능하고, 모든 $k$에서 $f^{(k)}$는 $f$이거나 $f'$이며 $f^{(k)}(0) = 0$이다.

*둘째 걸음.* 실수 $x \ne 0$을 정하고 $R = |x|$로 두면 [[absolute-value|절댓값]]의 (2)에 의해 $0 < R$이다. 고계 도함수의 (7)을 $n = 2$에 쓰면 $f$와 $f'$은 연속함수이므로, [[continuous-on-closed-interval-is-bounded|닫힌구간 위의 연속함수는 유계이다]]의 (2)에 의해 $[-R, R]$의 모든 $t$에서 $|f(t)| \le B_0$, $|f'(t)| \le B_1$인 실수 $B_0$, $B_1$이 있다. $K = \max\{B_0, B_1\}$로 두면 절댓값의 (10)에 의해 $[-R, R]$에서 $|f(t)| \le K$, $|f'(t)| \le K$이다. $\min\{0, x\} < t < \max\{0, x\}$이면 $-R \le t \le R$이다($0 < x$이면 $0 < t < x = R$이고, $x < 0$이면 $-R = x < t < 0$이다).

$0$ 이상인 정수 $n$을 정한다. 첫째 걸음에 의해 $f$는 $n + 1$번 미분가능하고 $f^{(n+1)}$은 $f$이거나 $f'$이므로, 위의 $t$에서 $|f^{(n+1)}(t)| \le K$이다. [[taylor-polynomial|테일러 다항식]]의 정의에서 각 항은 $0 \cdot (k!)^{-1} x^k = 0$이므로([[real-number-arithmetic|실수의 계산 법칙]]의 (K9)) [[cauchy-product|코시 곱]]의 (5)의 (iv)를 $a = 0$으로 쓰면 $T_n^{0} f(x) = 0$이다. [[taylor-theorem|테일러 정리]]의 (3)의 가정 아래 그 (4)를 쓰면
$$
|f(x)| \le K\, |x|^{n+1} \bigl((n + 1)!\bigr)^{-1}
$$
이다.

*셋째 걸음.* [[power-series-examples|멱급수의 예]]의 (2)에 의해 중심 $0$, 계수 $(n!)^{-1}$인 멱급수는 $|x|$에서 수렴하므로, [[power-series|멱급수]]의 (5)에 의해 $n$번째 항이 $(n!)^{-1}|x|^n$인 수열은 $0$으로 수렴한다. $n$번째 항이 $v_n = |x|^{n+1}\bigl((n + 1)!\bigr)^{-1}$인 수열은 그 $1$-꼬리이므로 [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $0$으로 수렴하고, [[limit-of-sum-and-product|극한의 사칙연산]]의 (5)에 의해 $(K v_n)$도 $0$으로 수렴한다. 둘째 걸음에 의해 모든 자연수 $n$에서 $|f(x)| \le K v_n$이므로, 모든 항이 $|f(x)|$인 상수 수열([[basic-limits|기본적인 극한]]의 (1))과 [[limits-preserve-inequalities|극한과 부등식]]의 (1)에 의해 $|f(x)| \le 0$이다. 절댓값의 (2)와 [[order-properties-of-reals|실수의 순서의 성질]]의 (1)의 (ii)에 의해 $|f(x)| = 0$이고 $f(x) = 0$이다. $x = 0$에서는 가정에 의해 $f(0) = 0$이다.

**(2)** 고계 도함수의 (9)와 [[exponential-function|지수함수]]의 (3)에 의해 $\exp$는 무한 번 미분가능하고 $\exp'' = \exp$이다. $h = g + (-1)\exp$로 두면 고계 도함수의 (6)에 의해 $h$는 $2$번 미분가능하고 $h'' = g'' + (-1)\exp'' = g + (-1)\exp = h$이다. 또 지수함수의 (1)에 의해 $\exp(0) = 1$이므로 $h(0) = 1 - 1 = 0$이고, 고계 도함수의 (6)의 $k = 1$인 경우와 $\exp'(0) = \exp(0) = 1$에 의해 $h'(0) = g'(0) - \exp'(0) = 0$이다. (1)에 의해 $h$는 값이 $0$인 상수함수이므로 모든 $x$에서 $g(x) = \exp(x)$이고, [[real-valued-function|실함수와 그 연산]]의 (2)에 의해 $g = \exp$이다.
:::

:::exercise[차수를 올리자 오차가 커지는 $x - x^3$]
$f(x) = x - x^3$으로 정한 $f : \mathbb{R} \to \mathbb{R}$와 $x_0 = 0$을 생각한다.

1. $n = 0, 1, 2, 3$에서 $T_n^{0} f$를 구하라.
2. $x = 2$에서 오차 $|f(2) - T_n^{0} f(2)|$를 $n = 0, 1, 2, 3$에 대해 구하고, $n = 0$에서 $n = 1$로 차수를 올리면 오차가 커짐을 보여라.
3. $x = 10^{-1}$에서 같은 오차를 $n = 0, 1$에 대해 구하라.
:::

:::solution
**(1)** $f$는 [[taylor-polynomial|테일러 다항식]]의 (4)의 꼴에서 $x_0 = 0$, $m = 3$, $c_0 = 0$, $c_1 = 1$, $c_2 = 0$, $c_3 = -1$인 함수이다. 그 (4)의 (ii)에 의해 모든 실수 $x$에서 $T_0^{0} f(x) = 0$, $T_1^{0} f(x) = x$, $T_2^{0} f(x) = x + 0 \cdot x^2 = x$이고, $T_3^{0} f = f$이다.

**(2)** $f(2) = 2 - 8 = -6$이다. 오차는 $n = 0$에서 $|-6 - 0| = 6$, $n = 1$과 $n = 2$에서 $|-6 - 2| = 8$, $n = 3$에서 $0$이다. $6 < 8$이므로 차수를 $0$에서 $1$로 올리면 $x = 2$에서의 오차가 커진다. [[taylor-theorem|테일러 정리]]의 (4)는 오차의 위쪽 어림만 준다. 예컨대 $n = 1$이면 [[higher-derivative|고계 도함수]]의 (8)의 (i)에 의해 $f''(t) = -6t$이고 $0 < t < 2$에서 $|f''(t)| = 6t < 12$이므로, $K = 12$로 쓰면 어림은 $12 \cdot 2^2 \cdot (2!)^{-1} = 24$이고 실제 오차 $8$은 그 아래에 있다. 이 어림은 차수가 올라갈 때 오차가 줄어든다는 것을 말하지 않는다.

**(3)** $f(10^{-1}) = 10^{-1} - 1000^{-1} = 99 \cdot 1000^{-1}$이다. 오차는 $n = 0$에서 $99 \cdot 1000^{-1}$이고, $n = 1$에서 $|99 \cdot 1000^{-1} - 100 \cdot 1000^{-1}| = 1000^{-1}$이다. $x_0 = 0$에 가까운 이 점에서는 차수를 올리자 오차가 줄었다. 테일러 다항식은 $x_0$에서의 도함수를 맞춘 것이므로, $x_0$에서 먼 점에서는 차수를 올린다고 근사가 좋아진다는 보장이 없다.
:::

:::exercise[짝함수의 홀수 계 도함수]
$n$을 $0$ 이상인 정수, $f : \mathbb{R} \to \mathbb{R}$를 $n$번 미분가능한 함수라 하고, 모든 실수 $x$에서 $f(-x) = f(x)$라 하자(이런 $f$를 짝함수라 부른다).

1. $g(x) = f(-x)$로 정한 $g : \mathbb{R} \to \mathbb{R}$가 $n$번 미분가능하고, $0 \le k \le n$인 모든 $k$와 실수 $x$에서 $g^{(k)}(x) = (-1)^k f^{(k)}(-x)$임을 보여라.
2. $k$가 $n$ 이하인 홀수이면 $f^{(k)}(0) = 0$임을 보여라.
3. 모든 실수 $x$에서 $T_n^{0} f(-x) = T_n^{0} f(x)$임을 보여라.
:::

:::solution
아래에서 "고계 도함수"는 [[higher-derivative|고계 도함수]]의 번호이고, $m(x) = -x$로 정한 $m : \mathbb{R} \to \mathbb{R}$를 쓴다. [[derivative|미분계수와 도함수]]의 (1)을 기울기 $-1$, 상수 $0$에 쓰면 $m$은 미분가능한 함수이고 모든 점에서 $m'(x) = -1$이다.

**(1)** $0 \le k \le n$인 정수 $k$에 대한 명제 "$g$는 $k$번 미분가능하고 $g^{(k)} = (-1)^k (f^{(k)} \circ m)$이다"를 [[mathematical-induction|수학적 귀납법]](시작점 $0$, $k \le n$까지)으로 보인다. $k = 0$이면 고계 도함수의 (1)과 [[power-of-a-real-number|실수의 거듭제곱]]의 정의 $(-1)^0 = 1$에 의해 양쪽이 $g = f \circ m$이다([[function-composition|합성]]).

$k < n$에서 명제가 성립한다고 하자. $f$는 $n$번 미분가능하므로 고계 도함수의 (2)에 의해 $k + 1$번 미분가능하고, (1)에 의해 $f^{(k)}$는 미분가능한 함수이며 $(f^{(k)})' = f^{(k+1)}$이다. [[chain-rule|연쇄 법칙]]의 (2)에 의해 $f^{(k)} \circ m$은 미분가능한 함수이고 $(f^{(k)} \circ m)'(x) = f^{(k+1)}(-x) \cdot (-1)$이다. [[derivative-rules|미분의 선형성과 곱·몫의 법칙]]의 (6)의 상수배에 의해 $g^{(k)} = (-1)^k (f^{(k)} \circ m)$은 미분가능한 함수이고, 거듭제곱의 (1)과 [[real-number-arithmetic|실수의 계산 법칙]]의 (K2)에 의해
$$
(g^{(k)})'(x) = (-1)^{k+1} f^{(k+1)}(-x)
$$
이다. 고계 도함수의 (2), (1)에 의해 $g$는 $k + 1$번 미분가능하고 $g^{(k+1)} = (g^{(k)})'$이므로 $k + 1$에서도 명제가 성립한다.

**(2)** 가정에 의해 모든 $x$에서 $g(x) = f(x)$이므로 [[real-valued-function|실함수와 그 연산]]의 (2)에 의해 $g = f$이고, 따라서 $g^{(k)} = f^{(k)}$이다. (1)을 $x = 0$에 쓰면 $f^{(k)}(0) = (-1)^k f^{(k)}(0)$이다. $k$가 홀수이면 거듭제곱의 (5)에 의해 $(-1)^k = -1$이므로 $f^{(k)}(0) = -f^{(k)}(0)$이고, (K3)으로 $2 f^{(k)}(0) = 0$이다. $2 \ne 0$이므로 (K10)에 의해 $f^{(k)}(0) = 0$이다.

**(3)** $0 \le k \le n$인 $k$에서 테일러 다항식의 $k$번째 항을 비교한다. 거듭제곱의 (2)의 (iii)에 의해 $(-x)^k = (-1)^k x^k$이다. $k$가 짝수이면 거듭제곱의 (5)에 의해 $(-1)^k = 1$이므로 두 항이 같고, $k$가 홀수이면 (2)에 의해 계수 $f^{(k)}(0)\,(k!)^{-1}$이 $0$이므로 두 항이 모두 $0$이다((K9)). [[even-and-odd|짝수와 홀수]]에서 받아들인 사실에 의해 모든 $k$는 둘 가운데 하나이므로 항마다 같고, [[taylor-polynomial|테일러 다항식]]의 정의와 [[finite-sum-of-reals|실수의 유한 합]]의 (4)에 의해 $T_n^{0} f(-x) = T_n^{0} f(x)$이다.
:::
