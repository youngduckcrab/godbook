:::exercise[6n + 9 를 정의로 따지기]
정수 $n$에 대하여 다음을 보여라.

1. $3 \mid (6n + 9)$이다.
2. $6n + 9$는 홀수이다.
3. $6 \nmid (6n + 9)$이다.
:::

:::solution
1. $6n + 9 = 3(2n + 3)$이다. 정수의 합·곱은 정수라는 기본 성질([[even-and-odd|짝수와 홀수]]에서 증명 없이 받아들임)에 의해 $2n + 3$은 정수이다. 따라서 [[divisibility|나누어떨어짐]]의 정의에 의해 $3 \mid (6n + 9)$이다.
2. $6n + 9 = 6n + 8 + 1 = 2(3n + 4) + 1$이다. 같은 기본 성질에 의해 $3n + 4$는 정수이므로, 홀수의 정의에 의해 $6n + 9$는 홀수이다.
3. [[proof-by-contradiction|귀류법]]으로 보인다. $6 \mid (6n + 9)$라고 가정한다. 나누어떨어짐의 정의에 의해 $6n + 9 = 6c$인 정수 $c$가 있다. 그러면 $6n + 9 = 2(3c)$이고, 같은 기본 성질에 의해 $3c$는 정수이므로 $6n + 9$는 짝수이다. 한편 2에 의해 $6n + 9$는 홀수이다. 짝수이면서 홀수인 정수는 없으므로([[even-and-odd|짝수와 홀수]]에서 받아들인 사실) $C$를 "$6n + 9$는 짝수이다"로 잡으면 $C \land (\lnot C)$가 나와 모순이다. 따라서 가정이 틀렸고 $6 \nmid (6n + 9)$이다. 곧 $6n + 9 = 6c$인 정수 $c$는 하나도 없다.

예를 들어 $n = -2$이면 $6n + 9 = -3 = 3 \cdot (-1) = 2 \cdot (-2) + 1$이어서 1과 2가 그대로 보인다.
:::

:::exercise[a | b 와 a | (b + c) 에서 a | c 로]
$a$, $b$, $c$가 정수라 하자.

1. $a \mid b$이고 $a \mid (b + c)$이면 $a \mid c$임을 직접 증명하라.
2. 1에서 가정 $a \mid b$를 빼면 결론이 나오지 않을 수 있다. $a \mid (b + c)$이지만 $a \nmid c$인 정수 $a$, $b$, $c$를 하나 찾고, 그것이 조건을 만족함을 보여라.
:::

:::solution
1. [[direct-proof|직접 증명]]의 틀에 따라 $a \mid b$이고 $a \mid (b + c)$라고 가정한다. [[divisibility|나누어떨어짐]]의 정의에 의해 $b = ax$인 정수 $x$가 있고, $b + c = ay$인 정수 $y$가 있다. 두 가정에서 따로 얻은 정수이므로 다른 문자를 쓴다. 그러면
   $$
   \begin{aligned} c &= (b + c) - b \\ &= ay - ax = a(y - x) \end{aligned}
   $$
   이다. 정수의 합·차·곱은 정수라는 기본 성질([[even-and-odd|짝수와 홀수]]에서 증명 없이 받아들임)에 의해 $y - x$는 정수이다. 따라서 정의에 의해 $a \mid c$이다.

2. $a = 2$, $b = 1$, $c = 1$로 잡는다.
   - $b + c = 2 = 2 \cdot 1$이고 $1$은 정수이므로 $2 \mid (b + c)$이다.
   - $2 \nmid 1$이다. $1 = 2k$인 정수 $k$가 있다고 하면 짝수의 정의에 의해 $1$은 짝수이다. 그런데 $1 = 2 \cdot 0 + 1$이므로 $1$은 홀수이다. 짝수이면서 홀수인 정수는 없으므로([[even-and-odd|짝수와 홀수]]에서 받아들인 사실) 그런 $k$는 없다. 곧 $2 \nmid c$이다.

   이 예에서는 $b = 1$이므로 같은 이유로 $a \nmid b$이기도 하다. 1의 가정 가운데 $a \mid b$가 성립하지 않으면 결론 $a \mid c$도 성립하지 않을 수 있음을 보여 주는 예이다.
:::

:::exercise[xy 가 홀수일 때의 x 와 y]
정수 $x$, $y$에 대하여 "$xy$가 홀수이면 $x$와 $y$는 둘 다 홀수이다"를 대우 증명으로 보여라.
:::

:::solution
$P$를 "$xy$는 홀수이다", $Q_1$을 "$x$는 홀수이다", $Q_2$를 "$y$는 홀수이다"라 하면 증명할 명제는 $P \Rightarrow (Q_1 \land Q_2)$이다. [[contrapositive-law|대우 법칙]]에 의해 이는 $\bigl(\lnot(Q_1 \land Q_2)\bigr) \Rightarrow (\lnot P)$와 같은 말이고, [[de-morgan-laws-logic|드 모르간 법칙(논리)]]의 (1)에 의해 $\lnot(Q_1 \land Q_2) \equiv (\lnot Q_1) \lor (\lnot Q_2)$이다. 따라서 [[proof-by-contrapositive|대우 증명]]의 틀에 따라 "$x$가 홀수가 아니거나 $y$가 홀수가 아니면 $xy$는 홀수가 아니다"를 보인다.

$x$가 홀수가 아니거나 $y$가 홀수가 아니라고 가정한다. 논리합이 참이므로 둘 가운데 적어도 하나가 성립한다. 성립하는 쪽으로 경우를 나눈다(둘 다 성립하면 어느 경우로 보아도 된다).

*경우 1: $x$가 홀수가 아니다.* 모든 정수는 짝수이거나 홀수이므로([[even-and-odd|짝수와 홀수]]에서 받아들인 사실) $x$는 짝수이고, $x = 2a$인 정수 $a$가 있다. 그러면 $xy = 2(ay)$이고, 정수의 곱은 정수라는 기본 성질(같은 항목에서 받아들임)에 의해 $ay$는 정수이므로 $xy$는 짝수이다.

*경우 2: $y$가 홀수가 아니다.* 같은 사실에 의해 $y$는 짝수이고 $y = 2b$인 정수 $b$가 있다. 그러면 $xy = x(2b) = 2(xb)$이고 $xb$는 정수이므로 $xy$는 짝수이다.

어느 경우든 $xy$는 짝수이고, 짝수이면서 홀수인 정수는 없으므로 $xy$는 홀수가 아니다. 이로써 대우가 증명되었고, 대우 법칙에 의해 원래 명제가 증명되었다.
:::

:::exercise[a + b, b + c, c + a 가 모두 홀수인 세 정수]
$a + b$, $b + c$, $c + a$가 모두 홀수인 정수 $a$, $b$, $c$는 없음을 귀류법으로 보여라.
:::

:::solution
증명할 명제는 "$a + b$, $b + c$, $c + a$가 모두 홀수인 정수 $a$, $b$, $c$가 존재한다"의 부정이다. [[logical-connectives|논리 연결사]]의 부정의 뜻에 의해 이 명제가 거짓이라는 것은 그런 정수가 존재한다는 것이다. [[proof-by-contradiction|귀류법]]의 틀에 따라 그런 정수 $a$, $b$, $c$가 있다고 가정한다.

홀수의 정의([[even-and-odd|짝수와 홀수]])에 의해
$$
\begin{aligned} a + b &= 2p + 1, \\ b + c &= 2q + 1, \\ c + a &= 2r + 1 \end{aligned}
$$
인 정수 $p$, $q$, $r$가 있다. 정수 $t = (a + b) + (b + c) + (c + a)$를 두 가지로 계산한다.

- $t = 2a + 2b + 2c = 2(a + b + c)$이다. 정수의 합·곱은 정수라는 기본 성질([[even-and-odd|짝수와 홀수]]에서 증명 없이 받아들임)에 의해 $a + b + c$는 정수이므로 $t$는 짝수이다.
- $t = (2p + 1) + (2q + 1) + (2r + 1) = 2(p + q + r + 1) + 1$이다. 같은 기본 성질에 의해 $p + q + r + 1$은 정수이므로 $t$는 홀수이다.

짝수이면서 홀수인 정수는 없으므로([[even-and-odd|짝수와 홀수]]에서 받아들인 사실) $C$를 "$t$는 짝수이다"로 잡으면 $C \land (\lnot C)$가 나와 모순이다. 따라서 가정이 틀렸고, 세 수가 모두 홀수인 정수 $a$, $b$, $c$는 없다.

예를 들어 $a = 0$, $b = 1$, $c = 2$이면 $a + b = 1$, $b + c = 3$은 홀수이지만 $c + a = 2$는 짝수이다.
:::

:::exercise[8 | b 를 이끌어내기]
정수 $a$, $b$에 대하여 $a^2$이 짝수이고 $a^3 \mid b$이면 $8 \mid b$임을 보여라. 여기서 $a^3 = (a \cdot a) \cdot a$이다.
:::

:::solution
$a^2$이 짝수이고 $a^3 \mid b$라고 가정한다.

[[even-square-implies-even|제곱이 짝수이면 짝수라는 명제]]에 의해 $a$는 짝수이므로 $a = 2c$인 정수 $c$가 있다. 그러면 곱셈의 교환·결합법칙에 의해
$$
a^3 = (2c \cdot 2c) \cdot 2c = 8\bigl((c \cdot c) \cdot c\bigr)
$$
이고, 정수의 곱은 정수라는 기본 성질([[even-and-odd|짝수와 홀수]]에서 증명 없이 받아들임)에 의해 $(c \cdot c) \cdot c$는 정수이다. 따라서 [[divisibility|나누어떨어짐]]의 정의에 의해 $8 \mid a^3$이다.

$8 \mid a^3$이고 $a^3 \mid b$이므로 [[divisibility-is-transitive|나누어떨어짐의 추이성]]에 의해 $8 \mid b$이다.

$a = 0$이어도 같은 논증이 통한다. 이때 $a^3 = 0$이고 $0 \mid b$는 $b = 0 \cdot k$인 정수 $k$가 있다는 뜻이므로 $b = 0$이며, 실제로 $0 = 8 \cdot 0$이다.
:::

:::exercise[곱이 유리수인 두 무리수]
무리수 $x$, $y$로서 $xy$가 유리수인 것을 하나 찾고, 그것이 조건을 만족함을 보여라.
:::

:::solution
$x = y = \sqrt{2}$로 잡는다. [[sqrt2-is-irrational|√2는 무리수라는 정리]]의 진술에서 $\sqrt{2}$는 제곱하여 $2$가 되는 양의 실수이고, 같은 진술에 의해 $\sqrt{2}$는 무리수이다. 따라서 $x$와 $y$는 무리수이다.

$xy = \sqrt{2} \cdot \sqrt{2} = (\sqrt{2})^2 = 2$이다. $2 = \tfrac{2}{1}$이고 $2$, $1$은 정수이며 $1 \ne 0$이므로, [[rational-and-irrational-numbers|유리수와 무리수]]의 정의에 의해 $xy$는 유리수이다.

따라서 "무리수 둘의 곱은 무리수이다"라는 문장은 $x = y = \sqrt{2}$에서 거짓이다.
:::
