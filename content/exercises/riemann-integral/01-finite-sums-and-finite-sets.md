:::exercise[3i² − i + 2 의 합]
$0$ 이상인 모든 정수 $n$에 대하여
$$
\sum_{i=1}^{n} (3i^2 - i + 2) = n^3 + n^2 + 2n
$$
임을 보여라. 이것으로 $\sum_{i=4}^{6} (3i^2 - i + 2)$를 구하라. 여기서 합의 항은 $i$번째 항이 $3i^2 - i + 2$인 수열이다.
:::

:::solution
아래에서 [[linearity-and-order-of-finite-sums|유한 합의 선형성과 부등식]]의 번호를 "선형성 (1)"처럼, [[sum-of-integers-and-squares|1부터 n까지의 합과 제곱의 합]]의 번호를 "합의 공식 (1)"처럼 쓴다. 정수의 계산은 [[real-number-arithmetic|실수의 계산 법칙]]의 (K7)에 의해 실수로서 해도 같고, 거듭제곱 $i^2 = ii$, $n^3 = n^2 n$은 [[power-of-a-real-number|실수의 거듭제곱]]의 것이다.

**합의 식.** 모든 자연수 $i$에서 (K1), (K2)에 의해 $3i^2 - i + 2 = 3i^2 + (2 - i)$이다. 선형성 (1)의 첫째 식을 $c = 3$, $i$번째 항이 $i^2$인 수열과 $i$번째 항이 $2 - i$인 수열에 쓰면
$$
\begin{aligned}
&\sum_{i=1}^{n} (3i^2 - i + 2) \\
&\quad = 3 \sum_{i=1}^{n} i^2 + \sum_{i=1}^{n} (2 - i)
\end{aligned}
$$
이다(왼쪽과 오른쪽 첫 합의 항이 모든 번호에서 같으므로 [[finite-sum-of-reals|실수의 유한 합]]의 (4)에 의해 같은 합이다). 선형성 (1)의 둘째 식과 선형성 (2)에 의해 $\sum_{i=1}^{n} (2 - i) = \sum_{i=1}^{n} 2 - \sum_{i=1}^{n} i = 2n - \sum_{i=1}^{n} i$이다(선형성 (2)에서 $(n - 1 + 1) \cdot 2 = 2n$). 합의 공식 (1), (2)를 넣으면
$$
\begin{aligned}
&\sum_{i=1}^{n} (3i^2 - i + 2) \\
&\quad = 3 \cdot \frac{n(n + 1)(2n + 1)}{6} \\
&\qquad - \frac{n(n + 1)}{2} + 2n \\
&\quad = \frac{n(n + 1)\bigl((2n + 1) - 1\bigr)}{2} + 2n \\
&\quad = n^2(n + 1) + 2n \\
&\quad = n^3 + n^2 + 2n
\end{aligned}
$$
이다. 둘째 줄에서 넷째 줄로는 (K12)의 (vi)에 의해 $6^{-1} = (2 \cdot 3)^{-1} = 2^{-1} 3^{-1}$이어서 $3 \cdot 6^{-1} = 2^{-1}$이라는 것과 분배법칙 (K3), (K12)의 (i)을 썼고, 다섯째 줄에서는 $2n \cdot 2^{-1} = n$을 썼다. $n = 0$이면 왼쪽은 빈 합 $0$이고 오른쪽도 $0$이다.

**$i = 4$부터 $6$까지의 합.** 이 수열의 부분합을 $s_n$이라 하면 [[finite-sum-of-reals|실수의 유한 합]]의 (1)의 첫째 식과 위의 결과에 의해 모든 자연수 $n$에서 $s_n = n^3 + n^2 + 2n$이다. 같은 (1)의 둘째 식을 $k = 3$, $n = 6$에 쓰면
$$
\begin{aligned}
\sum_{i=4}^{6} (3i^2 - i + 2) &= s_6 - s_3 \\
&= (216 + 36 + 12) \\
&\quad - (27 + 9 + 6) \\
&= 264 - 42 = 222
\end{aligned}
$$
이다.

검산으로 세 항을 직접 구하면 $i = 4$에서 $48 - 4 + 2 = 46$, $i = 5$에서 $75 - 5 + 2 = 72$, $i = 6$에서 $108 - 6 + 2 = 104$이고 $46 + 72 + 104 = 222$이다. 또 $n = 3$에서 $4 + 12 + 26 = 42 = s_3$이다.
:::

:::exercise[모든 원소가 작은 두 집합을 이어 늘어놓기]
$A$, $B$를 $\mathbb{R}$의 공집합이 아닌 유한 부분집합이라 하자.

1. $A$의 모든 원소 $a$와 $B$의 모든 원소 $b$에서 $a < b$인 것은 정확히 $\max A < \min B$일 때임을 보여라.
2. 1의 조건이 성립하고, $A$가 원소를 $n$개, $B$가 원소를 $m$개 가지며, $u$, $v$가 각각 $A$, $B$의 크기순 나열이라 하자. $A \cup B$는 원소를 $n + m$개 갖고, 그 크기순 나열 $w$는 $1 \le i \le n$이면 $w(i) = u(i)$, $n + 1 \le i \le n + m$이면 $w(i) = v(i - n)$임을 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (v)"처럼 쓴다. [[maximum-of-finite-set|유한집합의 최댓값과 최솟값]]의 (1)에 의해 $\max A$, $\min A$, $\max B$, $\min B$가 있다.

1. ($\max A < \min B$이면) $a \in A$, $b \in B$라 하자. 최댓값은 상계이고 최솟값은 하계이므로([[upper-bound-and-supremum|상계와 상한]]의 정의) $a \le \max A$이고 $\min B \le b$이다. $a \le \max A < \min B$에서 순서 성질 (1)의 (v)에 의해 $a < \min B$이고, 다시 $a < \min B \le b$에서 $a < b$이다.

   (모든 $a$, $b$에서 $a < b$이면) $b \in B$를 하나 잡자. 가정에 의해 $A$의 모든 원소 $a$에서 $a < b$이므로, 유한집합의 최댓값과 최솟값의 (5)의 첫째 문장의 둘째 부분($c = b$)에 의해 $\max A < b$이다. 이것이 $B$의 모든 원소 $b$에서 성립하므로, 같은 (5)의 마지막 부분($c = \max A$)에 의해 $\max A < \min B$이다.

2. **$w$가 함수로 정해진다.** $\{1, \dots, n + m\}$의 원소 $i$는 [[well-ordering-principle|정렬 원리]]의 (Z5)에 의해 $i \le n$이거나 $n < i$이고, 정확히 한 경우에 든다. 뒤의 경우 [[prime-number]]의 (Z1)에 의해 $n + 1 \le i$이고 (Z7)에 의해 $1 \le i - n \le m$이므로 $v(i - n)$이 정해진다. 따라서 [[real-valued-function|실함수]]의 (1)에 의해 $w : \{1, \dots, n + m\} \to \mathbb{R}$가 정해진다($\{1, \dots, n + m\} \subseteq \mathbb{R}$은 [[increasing-listing-of-finite-set|유한집합을 크기순으로 늘어놓기]]의 진술 첫머리).

   **$w$는 순증가이다.** $i < j$인 $i, j \in \{1, \dots, n + m\}$을 잡는다.
   - $j \le n$이면 $i < j \le n$이고, $u$가 순증가이므로 $w(i) = u(i) < u(j) = w(j)$이다.
   - $n + 1 \le i$이면 $i < j$와 (Z6)에 의해 $n + 1 \le j$이고, (Z7)에 의해 $i - n < j - n$이므로, $v$가 순증가이므로 $w(i) = v(i - n) < v(j - n) = w(j)$이다.
   - $i \le n$이고 $n + 1 \le j$이면 $w(i) = u(i) \in A$, $w(j) = v(j - n) \in B$이므로 1의 조건에 의해 $w(i) < w(j)$이다.

   (Z5)에 의해 $j \le n$이거나 $n + 1 \le j$이고, 뒤의 경우 $i \le n$이거나 $n + 1 \le i$이므로 세 경우가 모든 $i < j$를 덮는다.

   **$w$의 치역은 $A \cup B$이다.** $w$의 값은 $u$의 값이거나 $v$의 값이므로 $A \cup B$에 속한다. 거꾸로 $x \in A$이면 $u$가 전사이므로 $x = u(i) = w(i)$인 $i \le n$이 있고, $x \in B$이면 $x = v(j)$인 $j \in \{1, \dots, m\}$이 있어 $n + 1 \le j + n \le n + m$이고 $w(j + n) = v(j) = x$이다.

   유한집합을 크기순으로 늘어놓기의 (1)의 셋째 문장을 순증가인 $w$에 쓰면, 그 치역 $A \cup B$는 원소를 $n + m$개 갖고 $w$(공역을 $A \cup B$로 둔 것)는 $A \cup B$의 크기순 나열이다. 같은 (1)에 의해 크기순 나열은 하나뿐이므로 $A \cup B$의 크기순 나열은 이 $w$이다.

검산으로 $A = \{-1, 0\}$, $B = \{3, 5, 6\}$이면 $\max A = 0 < 3 = \min B$이고, $w$는 $-1, 0, 3, 5, 6$이다. 1의 조건이 없으면 2의 식은 크기순 나열이 아닐 수 있다. $A = \{0, 2\}$, $B = \{1\}$이면 식대로 만든 $w$는 $0, 2, 1$이어서 $w(2) > w(3)$이다.
:::

:::exercise[세제곱의 망원 합으로 제곱의 합 구하기]
$0$ 이상인 정수 $n$에 대하여 $0 \le i \le n$인 정수 $i$마다 $c_i = i^3$으로 둔다.

1. [[telescoping-sum|망원 합]]을 써서 $\sum_{i=1}^{n} (3i^2 - 3i + 1) = n^3$임을 보여라.
2. 1과 선형성, 그리고 $\sum_{i=1}^{n} i = \dfrac{n(n + 1)}{2}$만으로 $\sum_{i=1}^{n} i^2 = \dfrac{n(n + 1)(2n + 1)}{6}$을 얻어라. ([[sum-of-integers-and-squares|1부터 n까지의 합과 제곱의 합]]의 (2)는 쓰지 않는다.)
:::

:::solution
거듭제곱은 [[power-of-a-real-number|실수의 거듭제곱]]의 것이다. 그 정의와 (1)에 의해 $i^2 = ii$이고 $i^3 = i^2 i$이다.

1. $1 \le i \le n$인 정수 $i$를 잡는다. $(i - 1)^2 = i^2 - 2i + 1$이고([[real-number-arithmetic|실수의 계산 법칙]]의 (K1)–(K3), (K12)), 다시 분배법칙으로
   $$
   \begin{aligned}
   (i - 1)^3 &= (i^2 - 2i + 1)(i - 1) \\
   &= i^3 - 3i^2 + 3i - 1
   \end{aligned}
   $$
   이다. 따라서 $c_i - c_{i-1} = i^3 - (i - 1)^3 = 3i^2 - 3i + 1$이다. 망원 합의 (1)에 의해
   $$
   \begin{aligned}
   \sum_{i=1}^{n} (c_i - c_{i-1}) &= c_n - c_0 \\
   &= n^3 - 0^3 = n^3
   \end{aligned}
   $$
   이다. $0^3 = 0$은 거듭제곱의 (2)의 (iv)이다. 왼쪽은 $1 \le i \le n$에서만 정해진 항 $c_i - c_{i-1}$의 합이고, 그 항은 $1 \le i \le n$에서 $i$번째 항이 $3i^2 - 3i + 1$인 수열의 항과 같으므로, [[finite-sum-of-reals|실수의 유한 합]]의 범위에서만 정해진 항의 합의 약속과 그 (4)에 의해 $\sum_{i=1}^{n} (3i^2 - 3i + 1) = n^3$이다. $n = 0$이면 두 쪽 모두 $0$이다.

2. $S = \sum_{i=1}^{n} i^2$, $T = \sum_{i=1}^{n} i = \dfrac{n(n + 1)}{2}$로 두자. 모든 자연수 $i$에서 $3i^2 - 3i + 1 = 3i^2 + (1 - 3i)$이므로 [[linearity-and-order-of-finite-sums|유한 합의 선형성과 부등식]]의 (1)과 (2)에 의해
   $$
   \begin{aligned}
   &\sum_{i=1}^{n} (3i^2 - 3i + 1) \\
   &\quad = 3S + \sum_{i=1}^{n} 1 - 3T \\
   &\quad = 3S + n - 3T
   \end{aligned}
   $$
   이다. 1에 의해 이것이 $n^3$이므로
   $$
   \begin{aligned}
   3S &= n^3 - n + \frac{3n(n + 1)}{2} \\
   &= \frac{2n^3 + 3n^2 + n}{2} \\
   &= \frac{n(n + 1)(2n + 1)}{2}
   \end{aligned}
   $$
   이다. 마지막 등식은 $(n + 1)(2n + 1) = 2n^2 + 3n + 1$이다. 양변에 $3^{-1}$을 곱하면 $S = \dfrac{n(n + 1)(2n + 1)}{6}$이다.

검산으로 $n = 2$이면 1의 왼쪽은 $1 + 7 = 8 = 2^3$이고, 2의 $S = 1 + 4 = 5 = \dfrac{2 \cdot 3 \cdot 5}{6}$이다.
:::

:::exercise[절댓값 부등식의 등호가 성립하는 때]
$(x_i)$를 수열, $m$, $n$을 $1 \le m \le n$인 정수라 하자.

1. $\left|\sum_{i=m}^{n} x_i\right| = \sum_{i=m}^{n} |x_i|$인 것은 정확히 "$m \le i \le n$인 모든 정수 $i$에서 $0 \le x_i$"이거나 "$m \le i \le n$인 모든 정수 $i$에서 $x_i \le 0$"일 때임을 보여라.
2. $x_1 = 3$, $x_2 = -1$, $x_3 = 2$일 때 $m = 1$, $n = 3$에서 두 쪽을 계산해 1과 맞는지 보아라.
:::

:::solution
아래에서 [[linearity-and-order-of-finite-sums|유한 합의 선형성과 부등식]]의 번호를 "선형성 (1)"처럼, [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (iii)"처럼 쓰고, 절댓값은 [[absolute-value|절댓값]]의 것이다. $X = \sum_{i=m}^{n} x_i$, $Y = \sum_{i=m}^{n} |x_i|$로 둔다.

1. (모든 항이 $0$ 이상이면) 절댓값의 (1)에 의해 범위의 모든 $i$에서 $|x_i| = x_i$이므로 [[finite-sum-of-reals|실수의 유한 합]]의 (4)에 의해 $Y = X$이다. 선형성 (6)에 의해 $0 \le X$이므로 절댓값의 (1)에 의해 $|X| = X = Y$이다.

   (모든 항이 $0$ 이하이면) 절댓값의 (1)에 의해 범위의 모든 $i$에서 $|x_i| = -x_i = (-1)x_i$이다([[real-number-arithmetic|실수의 계산 법칙]]의 (K9)). 유한 합의 (4)와 선형성 (1)(상수배)에 의해 $Y = (-1)X = -X$이다. 또 모든 항이 $0$인 수열과 비교하면 선형성 (3)과 (2)에 의해 $X \le (n - m + 1) \cdot 0 = 0$이므로 절댓값의 (1)에 의해 $|X| = -X = Y$이다.

   (둘 다 아니면 등호가 아니다) "모든 $i$에서 $0 \le x_i$"가 아니므로 $0 \le x_j$가 아닌 $j$($m \le j \le n$)가 있고, 순서 성질 (1)의 (iii)에 의해 $x_j < 0$이다. 같은 방법으로 $0 < x_k$인 $k$($m \le k \le n$)가 있다.
   - 선형성 (1)의 둘째 식에 의해 $Y - X = \sum_{i=m}^{n} (|x_i| - x_i)$이다. 절댓값의 (6)에 의해 모든 항이 $0$ 이상이고, $j$번째 항은 $|x_j| - x_j = -x_j - x_j = -2x_j$로 순서 성질 (3)의 (ii)와 [[real-order-axioms|실수의 순서]]의 (W4)에 의해 양수이다. 선형성 (6)의 둘째 문장에 의해 $0 < Y - X$, 곧 $X < Y$이다(순서 성질 (3)의 (i)).
   - 선형성 (1)의 첫째 식에 의해 $Y + X = \sum_{i=m}^{n} (|x_i| + x_i)$이다. 절댓값의 (6)의 $-|x_i| \le x_i$와 순서 성질 (3)의 (i)에 의해 모든 항이 $0$ 이상이고, $k$번째 항은 $|x_k| + x_k = 2x_k$로 양수이다. 선형성 (6)에 의해 $0 < Y + X$이고, 순서 성질 (2)의 (ii)로 양변에 $-X$를 더하면 $-X < Y$이다.

   두 부등식 $-Y < X < Y$(뒤의 것에 순서 성질 (3)의 (iii))와 절댓값의 (7)에 의해 $|X| < Y$이고, 순서 성질 (1)의 (i)에 의해 $|X| \ne Y$이다.

   세 경우를 합치면, 등호가 성립하는 것은 정확히 두 조건 가운데 하나가 성립할 때이다.

2. $X = 3 + (-1) + 2 = 4$이고 $Y = 3 + 1 + 2 = 6$이므로 $|X| = 4 < 6 = Y$이다. $x_2 < 0 < x_1$이어서 1의 두 조건이 모두 성립하지 않고, 실제로 등호가 아니다.
:::

:::exercise[[0, 1] 안의 n 개의 점 가운데 가까운 두 점]
$n \ge 2$인 정수 $n$과 원소를 $n$개 갖는 $A \subseteq [0, 1]$을 생각한다.

1. $A$의 서로 다른 두 원소 $x$, $y$로서 $|x - y| \le \dfrac{1}{n - 1}$인 것이 있음을 보여라.
2. $n = 3$, $A = \{0, \frac{1}{2}, 1\}$에서 서로 다른 두 원소의 거리가 모두 $\dfrac{1}{2}$ 이상임을 확인하라. 곧 $n = 3$에서는 1의 $\dfrac{1}{n - 1}$을 더 작은 수로 바꿀 수 없다.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (iii)"처럼, [[linearity-and-order-of-finite-sums|유한 합의 선형성과 부등식]]의 번호를 "선형성 (2)"처럼 쓴다. $N = n - 1$로 두면 $N$은 $1$ 이상인 정수이다.

1. [[increasing-listing-of-finite-set|유한집합을 크기순으로 늘어놓기]]의 (1)에 의해 $A$의 크기순 나열 $u : \{1, \dots, n\} \to A$가 있다. $0 \le j \le N$인 정수 $j$마다 $c_j = u(j + 1)$로 두면 [[telescoping-sum|망원 합]]의 "0 부터 번호가 붙은 실수" $c_0, \dots, c_N$이다. $1 \le j \le N$에서 $d_j = c_j - c_{j-1} = u(j + 1) - u(j)$로 두면, $u$가 순증가이므로 $u(j) < u(j + 1)$이고 순서 성질 (3)의 (i)에 의해 $0 < d_j$이다.

   망원 합의 (1)과 크기순 나열의 (2)에 의해
   $$
   \begin{aligned}
   \sum_{j=1}^{N} d_j &= c_N - c_0 = u(n) - u(1) \\
   &= \max A - \min A
   \end{aligned}
   $$
   이다. $\max A$, $\min A$는 $A \subseteq [0, 1]$의 원소이므로 $\max A \le 1$, $0 \le \min A$이고, 순서 성질 (3)의 (iii)과 (2)의 (iii)에 의해 $\max A - \min A \le 1 - 0 = 1$이다.

   모든 $j$($1 \le j \le N$)에서 $\dfrac{1}{N} < d_j$라고 하자. 선형성 (8)에 의해 범위에서만 정해진 항에도 선형성 (7)과 (2)를 쓸 수 있고, 모든 항이 $\dfrac{1}{N}$인 합과 비교하면($j = 1$에서 진짜 부등식)
   $$
   \begin{aligned}
   1 &= N \cdot \frac{1}{N} = \sum_{j=1}^{N} \frac{1}{N} \\
   &< \sum_{j=1}^{N} d_j \le 1
   \end{aligned}
   $$
   이 되어 순서 성질 (1)의 (i)에 어긋난다. 따라서 $\dfrac{1}{N} < d_k$가 아닌 $k$($1 \le k \le N$)가 있고, 순서 성질 (1)의 (iii)에 의해 $d_k \le \dfrac{1}{N}$이다. $x = u(k + 1)$, $y = u(k)$로 두면 둘은 $A$의 원소이고 $y < x$이므로 서로 다르며, [[absolute-value|절댓값]]의 (1)에 의해 $|x - y| = d_k \le \dfrac{1}{n - 1}$이다.

2. 서로 다른 두 원소의 쌍은 $\{0, \frac{1}{2}\}$, $\{\frac{1}{2}, 1\}$, $\{0, 1\}$뿐이고 거리는 각각 $\frac{1}{2}$, $\frac{1}{2}$, $1$이다. 모두 $\frac{1}{2} = \frac{1}{3 - 1}$ 이상이다. 1의 증명에서 $d_1 = d_2 = \frac{1}{2}$이고 합은 $1 = \max A - \min A$이다.
:::

:::exercise[교집합의 최댓값과 최솟값]
$A$, $B$를 $\mathbb{R}$의 공집합이 아닌 유한 부분집합이라 하자.

1. $A \cap B \ne \emptyset$이면 $\max (A \cap B) \le \min\{\max A, \max B\}$이고 $\max\{\min A, \min B\} \le \min (A \cap B)$임을 보여라.
2. $A = \{1, 2, 5\}$, $B = \{0, 2, 4\}$에서 1의 두 부등식이 모두 등식이 아님을 확인하라. 곧 [[maximum-of-finite-set|유한집합의 최댓값과 최솟값]]의 (4)의 합집합의 등식을 교집합으로 바꾼 꼴은 성립하지 않을 수 있다.
3. $A \cap B = \emptyset$인 예를 하나 들고, 그때 $\max (A \cap B)$가 없음을 보여라.
:::

:::solution
1. $A \cap B$는 $A$의 공집합이 아닌 부분집합이므로, 유한집합의 최댓값과 최솟값의 (3)에 의해 유한집합이고 $\min A \le \min (A \cap B) \le \max (A \cap B) \le \max A$이다. $A \cap B$는 $B$의 부분집합이기도 하므로 같은 (3)에 의해 $\min B \le \min (A \cap B)$이고 $\max (A \cap B) \le \max B$이다. [[absolute-value|절댓값]]의 (10)에 의해 $\max (A \cap B)$는 $\max A$와 $\max B$ 둘 다 이하이므로 $\max (A \cap B) \le \min\{\max A, \max B\}$이고, $\min (A \cap B)$는 $\min A$와 $\min B$ 둘 다 이상이므로 $\max\{\min A, \min B\} \le \min (A \cap B)$이다.

2. $A \cap B = \{2\}$이므로 유한집합의 최댓값과 최솟값의 (2)에 의해 $\max (A \cap B) = \min (A \cap B) = 2$이다. $\max A = 5$, $\max B = 4$이므로 $\min\{5, 4\} = 4$이고 $2 < 4$이다. $\min A = 1$, $\min B = 0$이므로 $\max\{1, 0\} = 1$이고 $1 < 2$이다. 반면 합집합에서는 $A \cup B = \{0, 1, 2, 4, 5\}$이고 $\max (A \cup B) = 5 = \max\{5, 4\}$, $\min (A \cup B) = 0 = \min\{1, 0\}$으로 (4)대로 등식이다.

3. $A = \{0\}$, $B = \{1\}$이면 $0 \ne 1$이므로 $A \cap B = \emptyset$이다. 최댓값은 그 집합의 원소여야 하는데([[upper-bound-and-supremum|상계와 상한]]의 정의) $\emptyset$에는 원소가 없으므로 $\max (A \cap B)$는 없다. 그래서 1은 $A \cap B \ne \emptyset$을 가정한다.
:::
