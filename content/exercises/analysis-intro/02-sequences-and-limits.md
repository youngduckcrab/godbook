:::exercise[(2n + 1)/(n + 3) 의 극한과 가장 작은 번호]
$n$번째 항이 $x_n = (2n + 1)(n + 3)^{-1}$인 수열 $(x_n)$을 생각한다.

1. 모든 자연수 $n$에서 $|x_n - 2| = 5(n + 3)^{-1}$임을 보여라.
2. $\varepsilon = 10^{-1}$일 때, "$M$ 이상인 모든 자연수 $n$에서 $|x_n - 2| < \varepsilon$"을 만족하는 자연수 $M$ 가운데 가장 작은 것을 구하라.
3. 수열의 극한의 정의로 $\lim_{n \to \infty} x_n = 2$임을 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓴다. 자연수 $n$에 대하여 $n + 3$은 자연수이므로 순서 성질 (10)에 의해 $0 < n + 3$이고, 순서 성질 (6)의 (i)에 의해 $0 < (n + 3)^{-1}$이다. 따라서 [[sequence|수열]]의 (1)에 의해 $(x_n)$은 수열이다.

1. [[real-number-arithmetic|실수의 계산 법칙]]의 (K8)의 (iii)에 의해 $(n + 3)(n + 3)^{-1} = 1$이므로 $2 = 2(n + 3)(n + 3)^{-1}$이다((K2), (K4)). (K9)의 $(-a)b = -(ab)$와 (K12)의 (i)로 묶으면
   $$
   \begin{aligned} x_n - 2 &= (2n + 1)(n + 3)^{-1} \\ &\quad - 2(n + 3)(n + 3)^{-1} \\ &= \bigl((2n + 1) - 2(n + 3)\bigr) \\ &\quad \cdot (n + 3)^{-1} \end{aligned}
   $$
   이고, (K1)–(K3)과 (K7)에 의해 $(2n + 1) - 2(n + 3) = 2n + 1 - 2n - 6 = -5$이다. 따라서 $x_n - 2 = (-5)(n + 3)^{-1}$이다. [[absolute-value|절댓값]]의 (4)에 의해 $|x_n - 2| = |-5|\,|(n + 3)^{-1}|$이다. $-5 < 0$(순서 성질 (10))이므로 절댓값의 정의와 (K9)에 의해 $|-5| = -(-5) = 5$이고, $0 < (n + 3)^{-1}$이므로 [[absolute-value|절댓값]]의 (1)에 의해 $|(n + 3)^{-1}| = (n + 3)^{-1}$이다. 곧 $|x_n - 2| = 5(n + 3)^{-1}$이다.

2. 답은 $M = 48$이다.

   먼저 자연수 $n$에 대하여 "$5(n + 3)^{-1} < 10^{-1}$인 것은 정확히 $48 \le n$일 때"임을 보인다. $c = 10(n + 3)$로 두면 [[real-order-axioms|실수의 순서]]의 (W4)에 의해 $0 < c$이므로, 순서 성질 (6)의 (iv)에 의해 $5(n + 3)^{-1} < 10^{-1}$인 것은 정확히 $5(n + 3)^{-1} c < 10^{-1} c$일 때이다. (K1), (K2), (K4), (K8)의 (iii)과 (K7)에 의해 $5(n + 3)^{-1} c = 50$이고 $10^{-1} c = n + 3$이다. 순서 성질 (2)의 (ii)로 양변에 $-3$을 더하면, $50 < n + 3$인 것은 정확히 $47 < n$일 때이다. 정수 $47$, $n$에 대하여 $47 < n$이면 [[prime-number|소수]]의 (Z1)에 의해 $48 \le n$이고, 거꾸로 $48 \le n$이면 $47 < 48$이므로 순서 성질 (1)의 (v)에 의해 $47 < n$이다(순서 성질 (10)에 의해 정수의 부등식과 실수의 부등식은 같다).

   1에 의해 $|x_n - 2| < 10^{-1}$인 것은 정확히 $48 \le n$일 때이다. 따라서 $M = 48$은 조건을 만족한다. $M \le 47$인 자연수 $M$은 조건을 만족하지 않는다. $n = 47$은 $M$ 이상이지만 $48 \le 47$이 아니므로 $|x_{47} - 2| < 10^{-1}$이 성립하지 않기 때문이다. [[well-ordering-principle|정렬 원리]]의 (Z5)와 (Z1)에 의해 모든 자연수 $M$은 $M \le 47$이거나 $48 \le M$이므로, 조건을 만족하는 자연수는 정확히 $48$ 이상인 것들이고 그 가운데 가장 작은 것은 $48$이다.

   검산으로 $x_{47} = 95 \cdot 50^{-1}$이고 $|x_{47} - 2| = 5 \cdot 50^{-1} = 10^{-1}$이어서 등호가 되고, $x_{48}$에서는 $|x_{48} - 2| = 5 \cdot 51^{-1}$이고 $50 < 51$이다.

3. 양의 실수 $\varepsilon$을 잡는다. 순서 성질 (10)과 (6)의 (i)에 의해 $0 < 5^{-1}$이고, (W4)에 의해 $0 < 5^{-1}\varepsilon$이다. [[archimedean-property|아르키메데스 성질]]의 (3)에 의해 $M$ 이상인 모든 자연수 $n$에서 $n^{-1} < 5^{-1}\varepsilon$인 자연수 $M$이 있다.

   $n \ge M$인 자연수 $n$을 잡는다. $0 < 3$이므로 순서 성질 (2)의 (ii)에 의해 $n < n + 3$이고, $0 < n$이므로 순서 성질 (6)의 (ii)에 의해 $(n + 3)^{-1} < n^{-1}$이다. $0 < 5$이므로 순서 성질 (4)의 (i)에 의해 $5(n + 3)^{-1} < 5n^{-1}$이고 $5n^{-1} < 5(5^{-1}\varepsilon) = \varepsilon$이다. (W2)와 1에 의해 $|x_n - 2| < \varepsilon$이다.

   $\varepsilon$은 아무 양수였으므로 [[limit-of-sequence|수열의 극한]]의 정의에 의해 $(x_n)$은 $2$로 수렴하고, [[limit-is-unique|극한의 유일성]]의 기호로 $\lim_{n \to \infty} x_n = 2$이다.

2와 3을 맞대어 보면, 3의 방법이 $\varepsilon = 10^{-1}$에 대해 주는 $M$은 $M^{-1} < 50^{-1}$, 곧 ($0 < 50$, $0 < M$이므로 순서 성질 (6)의 (ii)와 (1)의 (i)에 의해) $50 < M$인 자연수이다. 이런 $M$은 $51$ 이상이어서 가장 작은 $48$보다 크다. 정의는 조건을 만족하는 $M$이 하나 있기만 하면 되므로 가장 작은 것을 찾을 필요가 없다.
:::

:::exercise[양수인 극한의 절반보다 큰 꼬리]
$(x_n)$을 수열, $L$을 실수라 하고 $\lim_{n \to \infty} x_n = L$이라 하자.

1. $0 < L$이면, 어떤 자연수 $M$이 있어 $M$ 이상인 모든 자연수 $n$에서 $\dfrac{L}{2} < x_n$임을 보여라. 따라서 그 $n$에서 $x_n$은 양수이다.
2. $L = 0$이면 1의 마지막 결론이 성립하지 않을 수 있음을, $n$번째 항이 $-n^{-1}$인 수열로 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓰고, $\dfrac{L}{2}$는 $L \cdot 2^{-1}$이다.

1. $0 < L$이므로 순서 성질 (8)에 의해 $0 < \dfrac{L}{2} < L$이다. [[limit-of-sequence|수열의 극한]]의 정의를 $\varepsilon = \dfrac{L}{2}$에 쓰면, $M$ 이상인 모든 자연수 $n$에서 $|x_n - L| < \dfrac{L}{2}$인 자연수 $M$이 있다. 같은 항목의 (1)에 의해 그런 $n$에서 $L - \dfrac{L}{2} < x_n$이다.

   [[real-number-arithmetic|실수의 계산 법칙]]의 (K3), (K7), (K8)의 (iii), (K4)에 의해 $\dfrac{L}{2} + \dfrac{L}{2} = L(2^{-1} + 2^{-1}) = L\bigl((1 + 1)2^{-1}\bigr) = L(2 \cdot 2^{-1}) = L$이므로, 양변에서 $\dfrac{L}{2}$를 빼면 ((K2), (K4), (K8)의 (ii)) $L - \dfrac{L}{2} = \dfrac{L}{2}$이다. 따라서 $M$ 이상인 모든 자연수 $n$에서 $\dfrac{L}{2} < x_n$이고, $0 < \dfrac{L}{2}$와 [[real-order-axioms|실수의 순서]]의 (W2)에 의해 $0 < x_n$이다.

2. $x_n = -n^{-1}$로 두면 [[sequence|수열]]의 (1)에 의해 수열이 정해진다. 순서 성질 (10)에 의해 $0 < n^{-1}$이고 순서 성질 (3)의 (ii)에 의해 $x_n < 0$이므로, 순서 성질 (1)의 (i)에 의해 어느 항도 양수가 아니다. 곧 "어떤 $M$ 이상인 모든 $n$에서 $x_n$은 양수"는 어떤 자연수 $M$에 대해서도 성립하지 않는다($n = M$이 깨뜨린다).

   그런데 $(x_n)$은 $0$으로 수렴한다. [[absolute-value|절댓값]]의 (3)에 의해 모든 $n$에서 $|x_n - 0| = |-n^{-1}| = |n^{-1}| = |n^{-1} - 0|$이다((K4)와 (K9)로 $-n^{-1} - 0 = -n^{-1}$, $n^{-1} - 0 = n^{-1}$). [[basic-limits|기본적인 극한]]의 (2)에 의해 $n$번째 항이 $n^{-1}$인 수열은 $0$으로 수렴하므로, 양수 $\varepsilon$마다 $M$ 이상인 모든 $n$에서 $|n^{-1} - 0| < \varepsilon$인 자연수 $M$이 있고, 같은 $M$에 대해 $|x_n - 0| < \varepsilon$이다. 따라서 $\lim_{n \to \infty} x_n = 0$이다.

1의 증명은 $\varepsilon = \dfrac{L}{2}$가 양수라는 데서 $0 < L$을 썼다. $L = 0$이면 이 $\varepsilon$이 $0$이 되어 정의에 넣을 수 없다.
:::

:::exercise[정수만 값으로 갖는 수렴하는 수열]
모든 항이 정수인 수열 $(x_n)$이 실수 $L$로 수렴한다고 하자.

1. 어떤 자연수 $M$이 있어 $M$ 이상인 모든 자연수 $n$에서 $x_n = x_M$임을 보여라.
2. $L = x_M$이고, 따라서 $L$은 정수임을 보여라.
3. 자연수 $n$이 짝수이면 $c_n = 0$, 홀수이면 $c_n = 1$인 수열 $(c_n)$이 발산함을 1로 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓴다. 정수 사이의 부등식은 순서 성질 (10)에 의해 정수로 읽으나 실수로 읽으나 같다.

먼저 작은 사실 하나를 보인다. **정수 $a$, $b$가 $|a - b| < 1$이면 $a = b$이다.** $a \ne b$라 하자. [[well-ordering-principle|정렬 원리]]의 (Z5)에 의해 $b < a$이거나 $a < b$이다. $b < a$이면 [[prime-number|소수]]의 (Z1)에 의해 $b + 1 \le a$이고, (Z7)로 양변에서 $b$를 빼면 $1 \le a - b$이다. 그러면 $0 < 1 \le a - b$이므로 [[absolute-value|절댓값]]의 (1)에 의해 $|a - b| = a - b \ge 1$이고, 이것은 $|a - b| < 1$과 순서 성질 (1)의 (i)에 의해 함께 성립하지 않는다. $a < b$이면 같은 논증으로 $|b - a| \ge 1$이고, [[absolute-value|절댓값]]의 (3)에 의해 $|a - b| = |b - a|$이므로 역시 모순이다. 따라서 $a = b$이다. (정수의 차가 정수라는 것은 [[even-and-odd|짝수와 홀수]]에서 받아들인 사실이다.)

1. $0 < 1$이므로 순서 성질 (8)에 의해 $0 < 2^{-1}$이다. [[limit-of-sequence|수열의 극한]]의 정의를 $\varepsilon = 2^{-1}$에 쓰면, $M$ 이상인 모든 자연수 $n$에서 $|x_n - L| < 2^{-1}$인 자연수 $M$이 있다. $n \ge M$인 자연수 $n$을 잡는다. [[triangle-inequality|삼각부등식]]의 (4)에 의해 $|x_n - x_M| \le |x_n - L| + |L - x_M|$이고, [[absolute-value|절댓값]]의 (3)에 의해 $|L - x_M| = |x_M - L|$이다. $n \ge M$이고 $M \ge M$이므로 오른쪽의 두 항은 모두 $2^{-1}$보다 작고, 순서 성질 (2)의 (iv)에 의해 그 합은 $2^{-1} + 2^{-1}$보다 작다. [[real-number-arithmetic|실수의 계산 법칙]]의 (K3), (K7), (K8)의 (iii)에 의해 $2^{-1} + 2^{-1} = (1 + 1)2^{-1} = 2 \cdot 2^{-1} = 1$이다. 순서 성질 (1)의 (v)에 의해 $|x_n - x_M| < 1$이고, $x_n$과 $x_M$은 정수이므로 위의 사실에 의해 $x_n = x_M$이다.

2. 1의 $M$으로 [[tail-of-a-sequence|수열의 꼬리]]의 $M$-꼬리 $(y_n)$, 곧 $y_n = x_{n+M}$인 수열을 생각한다. 자연수 $n$에 대하여 $0 < n$이므로 (Z7)에 의해 $M < n + M$이고, 1에 의해 $y_n = x_{n+M} = x_M$이다. 곧 $(y_n)$은 모든 항이 $x_M$인 상수 수열이고, [[basic-limits|기본적인 극한]]의 (1)에 의해 $x_M$으로 수렴한다. [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $(x_n)$도 $x_M$으로 수렴한다. $(x_n)$은 $L$로도 수렴하므로 [[limit-is-unique|극한의 유일성]]에 의해 $L = x_M$이고, $x_M$은 정수이므로 $L$은 정수이다.

3. [[even-and-odd|짝수와 홀수]]에서 받아들인 사실에 의해 모든 정수는 짝수이거나 홀수이고 둘 다인 것은 없으므로, 각 $n$마다 $c_n$이 하나로 정해지고 [[sequence|수열]]의 (1)에 의해 $(c_n)$은 수열이다. 모든 항은 정수이다. $(c_n)$이 어떤 실수 $L$로 수렴한다고 하자. 1에 의해 $M$ 이상인 모든 $n$에서 $c_n = c_M$인 자연수 $M$이 있다. $2M = M + M$이고 $0 < M$이므로 (Z7)에 의해 $M < 2M < 2M + 1$이다. $2M$은 짝수이고 $2M + 1$은 홀수이므로 $c_{2M} = 0$, $c_{2M+1} = 1$이며, 둘 다 $c_M$과 같아야 하므로 $0 = 1$이 되어 (K4)에 어긋난다. 따라서 $(c_n)$은 어떤 실수로도 수렴하지 않고, [[limit-of-sequence|수열의 극한]]의 (3)의 뜻으로 발산한다.
:::

:::exercise[서로 마주 보는 두 단조수열]
수열 $(x_n)$은 단조증가이고 수열 $(y_n)$은 단조감소이며, 모든 자연수 $n$에서 $x_n \le y_n$이라 하자.

1. 모든 자연수 $n$, $m$에서 $x_n \le y_m$임을 보여라.
2. $(x_n)$과 $(y_n)$이 모두 수렴하고, $c = \lim_{n \to \infty} x_n$과 $d = \lim_{n \to \infty} y_n$이 $c \le d$를 만족하며, 모든 자연수 $n$에서 $x_n \le c \le d \le y_n$임을 보여라.
3. 여기에 더해 모든 양수 $\varepsilon$에 대하여 $y_n - x_n < \varepsilon$인 자연수 $n$이 있으면 $c = d$임을 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓰고, $X = \{x_n : n \in \mathbb{N}\}$, $Y = \{y_n : n \in \mathbb{N}\}$로 둔다.

1. 자연수 $n$, $m$을 잡고 $k = \max\{n, m\}$으로 둔다. [[absolute-value|절댓값]]의 (10)에 의해 $k$는 $n$이거나 $m$이므로 자연수이고, $n \le k$, $m \le k$이다. [[sequence|수열]]의 (4)에 의해 $(x_n)$이 단조증가이므로 $x_n \le x_k$이고, $(y_n)$이 단조감소이므로 $y_k \le y_m$이다. 가정에 의해 $x_k \le y_k$이다. 순서 성질 (1)의 (v)를 두 번 쓰면 $x_n \le y_m$이다.

2. 1을 $m = 1$에 쓰면 모든 $n$에서 $x_n \le y_1$이므로 $(x_n)$은 위로 유계이다. [[monotone-convergence-theorem|단조수렴정리]]의 (1)에 의해 $\sup X$가 있고 $(x_n)$은 $c = \sup X$로 수렴하며, 모든 $n$에서 $x_n \le c$이다. 1을 $n = 1$에 쓰면 모든 $m$에서 $x_1 \le y_m$이므로 $(y_n)$은 아래로 유계이고, 같은 정리의 (2)에 의해 $(y_n)$은 $d = \inf Y$로 수렴하며 모든 $n$에서 $d \le y_n$이다.

   $X$와 $Y$는 [[sequence|수열]]의 (2)에 의해 공집합이 아니다. $X$의 원소 $a$와 $Y$의 원소 $b$는 어떤 $n$, $m$에 대하여 $a = x_n$, $b = y_m$이므로 1에 의해 $a \le b$이다. [[supremum-and-arithmetic|상한과 덧셈·곱셈]]의 (5)에 의해 $\sup X \le \inf Y$, 곧 $c \le d$이다. 순서 성질 (1)의 (v)로 모으면 모든 $n$에서 $x_n \le c \le d \le y_n$이다.

3. $e = d - c$로 두면 2와 순서 성질 (3)의 (i)에 의해 $0 \le e$이다. 양수 $\varepsilon$을 잡고, 가정에 의해 $y_n - x_n < \varepsilon$인 자연수 $n$을 잡는다. 2에서 $x_n \le c$이므로 순서 성질 (3)의 (iii)에 의해 $-c \le -x_n$이고, $d \le y_n$과 함께 순서 성질 (2)의 (iii)에 의해 $d + (-c) \le y_n + (-x_n)$, 곧 $e \le y_n - x_n$이다. 순서 성질 (1)의 (v)에 의해 $e < \varepsilon$이고, 따라서 $e \le \varepsilon$이다. $\varepsilon$은 아무 양수였으므로 순서 성질 (9)에 의해 $e \le 0$이고, $0 \le e$이므로 $e = 0$이다. [[real-number-arithmetic|실수의 계산 법칙]]의 (K12)의 (v)에 의해 $d = c$이다.

:::

:::exercise[가까운 항이 끝없이 있다는 조건과 수렴의 차이]
수열 $(x_n)$과 실수 $L$에 대한 다음 조건을 생각한다.

> (조건 F) 모든 양의 실수 $\varepsilon$과 모든 자연수 $M$에 대하여, $n \ge M$이고 $|x_n - L| < \varepsilon$인 자연수 $n$이 있다.

[[basic-limits|기본적인 극한]]의 (3)의 수열 $(a_n)$($n$이 짝수이면 $a_n = 1$, 홀수이면 $a_n = -1$)에 대하여 다음을 보여라.

1. $(a_n)$과 $L = 1$은 조건 F를 만족한다.
2. $(a_n)$과 $L = -1$도 조건 F를 만족한다.
3. 그런데 $(a_n)$은 발산한다. 따라서 조건 F는 "$(x_n)$이 $L$로 수렴한다"와 같은 뜻이 아니다.
:::

:::solution
양의 실수 $\varepsilon$과 자연수 $M$을 잡는다. $0 < M$이므로 [[well-ordering-principle|정렬 원리]]의 (Z7)에 의해 $M = M + 0 < M + M = 2M$이고, 같은 성질로 $2M < 2M + 1$이다. 따라서 $2M \ge M$이고 $2M + 1 \ge M$이다. [[even-and-odd|짝수와 홀수]]의 정의에 의해 $2M$은 짝수이고 $2M + 1$은 홀수이다.

1. $n = 2M$으로 둔다. $n \ge M$이고 $a_n = 1$이므로 $|a_n - 1| = |0| = 0$이다([[absolute-value|절댓값]]의 (2)). $0 < \varepsilon$이므로 $|a_n - 1| < \varepsilon$이다.

2. $n = 2M + 1$로 둔다. $n \ge M$이고 $a_n = -1$이므로 $|a_n - (-1)| = |0| = 0 < \varepsilon$이다.

3. [[basic-limits|기본적인 극한]]의 (3)에 의해 $(a_n)$은 발산한다. 1에 의해 $(a_n)$과 $L = 1$은 조건 F를 만족하지만 $(a_n)$은 $1$로 수렴하지 않는다. 따라서 조건 F가 성립해도 $(x_n)$이 $L$로 수렴한다고 할 수 없다.

조건 F와 [[limit-of-sequence|수열의 극한]]의 정의는 한 곳만 다르다. 정의는 "$M$ 이상인 **모든** $n$에서 $|x_n - L| < \varepsilon$"을 요구하고, 조건 F는 "$M$ 이상인 **어떤** $n$에서"만 요구한다. 거꾸로 $(x_n)$이 $L$로 수렴하면 조건 F가 성립한다. 양수 $\varepsilon$과 자연수 $M$이 주어지면 정의가 주는 번호 $M'$에 대하여 $n = \max\{M, M'\}$을 잡는다. [[absolute-value|절댓값]]의 (10)에 의해 $n$은 자연수이며 $n \ge M$, $n \ge M'$이므로 $|x_n - L| < \varepsilon$이다. 또 1과 2는 서로 다른 두 수 $1$과 $-1$이 같은 수열과 함께 조건 F를 만족함을 보인다. 수렴하는 수열의 극한은 [[limit-is-unique|극한의 유일성]]에 의해 하나뿐이므로, 이것으로도 조건 F가 수렴과 다르다는 것을 알 수 있다.
:::
