:::exercise[$[0, 2]$ 위의 $x^3 - 3x$가 최댓값과 최솟값을 갖는 점]
$f(x) = x^3 - 3x$로 정한 $f : [0, 2] \to \mathbb{R}$를 생각한다. $f$가 최댓값을 갖는 점과 최솟값을 갖는 점을 모두 구하라.
:::

:::solution
최댓값과 최솟값을 갖는다는 말은 [[extreme-value-theorem|최대·최소 정리]] 항목의 것이고, 아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**두 등식.** [[power-of-a-real-number|실수의 거듭제곱]]의 (1)에 의해 $x^3 = (x x)x$이다. [[real-number-arithmetic|실수의 계산 법칙]]의 (K1)–(K4), (K12)와 (K7)의 정수 계산으로 전개하면 모든 실수 $x$에서
$$
\begin{aligned}
f(x) + 2 &= x^3 - 3x + 2 \\
&= (x x - 2x + 1)(x + 2) \\
&= (x - 1)(x - 1)(x + 2), \\
f(x) - 2 &= x^3 - 3x - 2 \\
&= (x - 2)(x x + 2x + 1) \\
&= (x - 2)(x + 1)(x + 1)
\end{aligned}
$$
이다.

**최솟값.** $x \in [0, 2]$라 하자. 순서 성질 (5)의 (iii)에 의해 $0 \le (x - 1)(x - 1)$이고, $0 \le x$와 순서 성질 (10)의 $0 < 2$에서 (2)의 (iv)에 의해 $0 < x + 2$이다. 순서 성질 (4)의 (iv)에 의해 $0 \le (x - 1)(x - 1)(x + 2) = f(x) + 2$이고, (3)의 (i)에 의해 $-2 \le f(x)$이다. $f(1) = 1 - 3 = -2$이고 $1 \in [0, 2]$이므로, 모든 $x \in [0, 2]$에서 $f(1) \le f(x)$, 곧 $f$는 $1$에서 최솟값 $-2$를 갖는다.

다른 점에서는 갖지 않는다. $f$가 $c \in [0, 2]$에서 최솟값을 가지면 최대·최소 정리의 (1)에 의해 $f(c) = f(1) = -2$이므로 $(c - 1)(c - 1)(c + 2) = 0$이다. (K10)에 의해 $c - 1 = 0$이거나 $c + 2 = 0$인데, $0 \le c$이므로 $0 < c + 2$이어서 뒤의 것은 아니다. (K12)의 (v)에 의해 $c = 1$이다.

**최댓값.** $x \in [0, 2]$이면 $x \le 2$이므로 $x - 2 \le 0$이고(순서 성질 (3)의 (i)), 순서 성질 (5)의 (iii)에 의해 $0 \le (x + 1)(x + 1)$이다. 순서 성질 (4)의 (iv)에 의해 $(x - 2)(x + 1)(x + 1) \le 0$, 곧 $f(x) - 2 \le 0$이고 $f(x) \le 2$이다. $f(2) = 8 - 6 = 2$이므로 $f$는 $2$에서 최댓값 $2$를 갖는다.

다른 점에서는 갖지 않는다. $f$가 $c \in [0, 2]$에서 최댓값을 가지면 $f(c) = 2$이므로 $(c - 2)(c + 1)(c + 1) = 0$이고, (K10)에 의해 $c - 2 = 0$이거나 $c + 1 = 0$이다. $0 \le c$이므로 $0 < c + 1$이어서 뒤의 것은 아니고, $c = 2$이다.

따라서 최솟값을 갖는 점은 $1$ 하나, 최댓값을 갖는 점은 $2$ 하나이다.
:::

:::exercise[$[-1, 1]$ 위의 세제곱 함수의 립시츠 상수]
$f(x) = x^3$으로 정한 $f : [-1, 1] \to \mathbb{R}$를 생각한다.

1. $3$이 $f$의 립시츠 상수임을 보여라.
2. $0 \le K < 3$인 실수 $K$는 $f$의 립시츠 상수가 아님을 보여라. 곧 $3$은 $f$의 립시츠 상수 가운데 가장 작은 것이다.
:::

:::solution
립시츠 상수와 "$K$가 $f$의 부등식을 만족한다"는 말은 [[lipschitz-continuity|립시츠 연속]]의 것이다. 아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]], "절댓값"은 [[absolute-value|절댓값]]의 번호이다.

**(1)** $x$, $w \in [-1, 1]$이라 하자. [[power-of-a-real-number|실수의 거듭제곱]]의 (1)과 [[real-number-arithmetic|실수의 계산 법칙]]의 (K1)–(K3), (K12)로 전개하면
$$
x^3 - w^3 = (x - w)(x x + x w + w w)
$$
이다. $-1 \le x \le 1$이므로 절댓값 (7)에 의해 $|x| \le 1$이고, 같은 이유로 $|w| \le 1$이다. 절댓값 (2)의 $0 \le |x|$, $0 \le |w|$와 순서 성질 (11)의 (i)에 의해 $|x|\,|x| \le 1$, $|x|\,|w| \le 1$, $|w|\,|w| \le 1$이다. [[triangle-inequality|삼각부등식]]의 (5), 절댓값 (4), 순서 성질 (2)의 (iii)과 (K7)의 $1 + 1 + 1 = 3$에 의해
$$
\begin{aligned}
&|x x + x w + w w| \\
&\le |x|\,|x| + |x|\,|w| + |w|\,|w| \\
&\le 3
\end{aligned}
$$
이다. 절댓값 (4)와 순서 성질 (4)의 (iii)(곱하는 $|x - w|$는 $0$ 이상)에 의해 $|x^3 - w^3| = |x - w|\,|x x + x w + w w| \le 3\,|x - w|$이다. 따라서 $3$은 $f$의 부등식을 만족하고, $0 \le 3$이므로 $f$의 립시츠 상수이다.

**(2)** $0 \le K < 3$이라 하고 $t = \min\{1, 3^{-1}(3 - K)\}$로 둔다. 순서 성질 (3)의 (i)과 (6)의 (i), [[real-order-axioms]]의 (W4)에 의해 $3^{-1}(3 - K)$는 양수이므로 절댓값 (10)에 의해 $0 < t \le 1$이고 $t \le 3^{-1}(3 - K)$이다. $w = 1 - t$로 두면 $0 \le w < 1$이므로 $w \in [-1, 1]$이고, $|1 - w| = t$이다(절댓값 (1)).

(K1)–(K3), (K12)로 전개하면 $1 - w^3 = 1 - (1 - t)^3 = t\,(3 - 3t + t t)$이다. $t \le 3^{-1}(3 - K)$에 순서 성질 (4)의 (iii)을 $c = 3$으로 쓰면 $3t \le 3 - K$, 곧 $K \le 3 - 3t$이고, 순서 성질 (5)의 (i)에 의해 $0 < t t$이므로 (2)의 (iv)에 의해 $K < 3 - 3t + t t$이다. $0 < t$이므로 순서 성질 (4)의 (i)에 의해
$$
\begin{aligned}
K\,|1 - w| = t K &< t\,(3 - 3t + t t) \\
&= 1 - w^3
\end{aligned}
$$
이고, 특히 $0 \le tK < 1 - w^3$이어서 절댓값 (1)에 의해 $|f(1) - f(w)| = 1 - w^3 > K\,|1 - w|$이다. 따라서 $K$는 $f$의 부등식을 만족하지 않는다. (1)과 함께 보면 $3$은 $f$의 립시츠 상수 가운데 가장 작은 것이다(립시츠 상수는 정의에 의해 $0$ 이상이다).
:::

:::exercise[양수만 갖는 연속함수의 역수]
$a < b$인 실수 $a$, $b$를 잡는다.

1. $f : [a, b] \to \mathbb{R}$가 연속함수이고 모든 $x \in [a, b]$에서 $0 < f(x)$이면, 모든 $x \in [a, b]$에서 $m \le f(x)$인 양의 실수 $m$이 있음을 보이고, $1/f$가 유계임을 보여라.
2. 반열린구간 $(0, 1]$ 위의 항등함수 $g$는 연속함수이고 모든 값이 양수이지만, 모든 $x \in (0, 1]$에서 $m \le g(x)$인 양의 실수 $m$은 없음을 보여라.
:::

:::solution
아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**(1)** [[extreme-value-theorem|최대·최소 정리]]의 (2)에 의해 $f$가 최솟값을 갖는 점 $d \in [a, b]$가 있다. 곧 모든 $x \in [a, b]$에서 $f(d) \le f(x)$이다. $m = f(d)$로 두면 가정에 의해 $0 < m$이다.

$f$는 $[a, b]$의 모든 점에서 $0$이 아니므로 [[real-valued-function|실함수와 그 연산]]의 (5)에 의해 $1/f$의 정의역은 $[a, b]$이다. $x \in [a, b]$에서 $0 < m \le f(x)$이므로, $m < f(x)$이면 순서 성질 (6)의 (ii)에 의해 $f(x)^{-1} < m^{-1}$이고, $m = f(x)$이면 $f(x)^{-1} = m^{-1}$이다. 또 순서 성질 (6)의 (i)에 의해 $0 < f(x)^{-1}$이다. [[absolute-value|절댓값]]의 (1)에 의해 $|(1/f)(x)| = f(x)^{-1} \le m^{-1}$이므로, [[bounded-function|유계인 함수]]의 정의에 의해 $1/f$는 $B = m^{-1}$로 유계이다.

**(2)** [[continuous-function|연속함수]]의 (4)에 의해 $g$는 연속함수이고, $x \in (0, 1]$이면 $g(x) = x > 0$이다. 양의 실수 $m$을 아무것이나 잡고 $x = \min\{1, 2^{-1}m\}$으로 두자. 절댓값의 (10)에 의해 $x$는 $1$이거나 $2^{-1}m$이어서 양수이고 $x \le 1$이므로 $x \in (0, 1]$이며, $x \le 2^{-1}m$이다. 순서 성질 (8)에 의해 $2^{-1}m < m$이므로 순서 성질 (1)의 (v)에 의해 $g(x) = x < m$이다. 따라서 그런 $m$은 없다. 1의 증명은 최대·최소 정리를 썼고, 그 정리의 정의역은 닫힌구간이다.
:::

:::exercise[$[0, 1]$ 위의 연속함수의 고정점]
1. $f : [0, 1] \to \mathbb{R}$가 연속함수이고 $0 \le f(0)$, $f(1) \le 1$이면, $f(c) = c$인 $c \in [0, 1]$가 있음을 보여라. 특히 모든 $x \in [0, 1]$에서 $0 \le f(x) \le 1$이면 그렇다.
2. $f(x) = x + 1$로 정한 $f : [0, 1] \to \mathbb{R}$에는 $f(c) = c$인 $c \in [0, 1]$가 없음을 보여라. 곧 1에서 "$f(1) \le 1$"이라는 가정을 빼면 결론이 깨질 수 있다.
:::

:::solution
**(1)** $i$를 $[0, 1]$ 위의 항등함수라 하고 $g = f - i$로 둔다. [[continuous-function|연속함수]]의 (4)와 [[continuity-of-sum-and-product|연속함수의 합·곱·몫]]의 (3)에 의해 $g$는 연속함수이다. 가정에 의해 $0 \le f(0)$이고 $f(1) \le 1$이므로, [[order-properties-of-reals|실수의 순서의 성질]]의 (3)의 (i)에 의해 $g(1) = f(1) - 1 \le 0 \le f(0) - 0 = g(0)$이다. $0 < 1$이므로 [[intermediate-value-theorem|사잇값 정리]]의 (2)를 $y = 0$으로 쓰면 $g(c) = 0$인 $c \in [0, 1]$가 있다. [[real-number-arithmetic|실수의 계산 법칙]]의 (K12)의 (v)에 의해 $f(c) = c$이다.

**(2)** $f(c) = c$이면 $c + 1 = c$이고, 양변에 $-c$를 더하면 (K1), (K2), (K4), (K8)의 (ii)에 의해 $1 = 0$이 되어 (K4)의 $0 \ne 1$에 어긋난다. 따라서 그런 $c$는 없다. 이 $f$는 $0 \le f(0) = 1$이지만 $f(1) = 2$이어서 $f(1) \le 1$이 성립하지 않고, 1의 증명에서 쓴 $g(1) \le 0$도 성립하지 않는다($g$는 값이 $1$인 상수함수이다).
:::

:::exercise[양 끝 값이 같은 연속함수의 반 구간 떨어진 두 점]
1. $f : [0, 1] \to \mathbb{R}$가 연속함수이고 $f(0) = f(1)$이면, $f(c + 2^{-1}) = f(c)$인 $c \in [0, 2^{-1}]$가 있음을 보여라.
2. $f(x) = x x - x$로 정한 $f : [0, 1] \to \mathbb{R}$에 대하여 1의 $c$를 모두 구하라.
:::

:::solution
아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**(1)** 순서 성질 (8)에 의해 $0 < 2^{-1} < 1$이므로 $J = [0, 2^{-1}]$은 닫힌구간이고 $J \subseteq [0, 1]$이다. $x \in J$이면 순서 성질 (2)의 (i)과 $2^{-1} + 2^{-1} = 1$([[real-number-arithmetic|실수의 계산 법칙]]의 (K12)의 (i), (K7))에 의해 $0 < 2^{-1} \le x + 2^{-1} \le 1$이므로 $x + 2^{-1} \in [0, 1]$이다.

$s(x) = x + 2^{-1}$로 정한 $s : J \to \mathbb{R}$는 $J$ 위의 항등함수와 값이 $2^{-1}$인 상수함수의 합이므로 [[continuous-function|연속함수]]의 (4)와 [[continuity-of-sum-and-product|연속함수의 합·곱·몫]]의 (3)에 의해 연속함수이고, 모든 값이 $[0, 1]$에 속한다. [[composition-of-continuous-functions|연속함수의 합성]]의 (3), (2)에 의해 $f \circ s : J \to \mathbb{R}$는 연속함수이다. 연속함수의 (5)에 의해 제한 $f|_J$도 연속함수이므로, 연속함수의 합·곱·몫의 (3)에 의해 $g = f \circ s - f|_J$는 $J$ 위의 연속함수이고 $g(x) = f(x + 2^{-1}) - f(x)$이다.

$g(0) = f(2^{-1}) - f(0)$이고, $f(1) = f(0)$이므로 (K12)의 (iv), (K9)에 의해 $g(2^{-1}) = f(1) - f(2^{-1}) = f(0) - f(2^{-1}) = -g(0)$이다. 순서 성질 (1)의 (iii)에 의해 $g(0) \le 0$이거나 $0 < g(0)$이다.

- $g(0) \le 0$이면 순서 성질 (3)의 (iii)에 의해 $0 \le -g(0) = g(2^{-1})$이므로 $g(0) \le 0 \le g(2^{-1})$이다.
- $0 < g(0)$이면 순서 성질 (3)의 (ii)에 의해 $g(2^{-1}) = -g(0) < 0$이므로 $g(2^{-1}) \le 0 \le g(0)$이다.

어느 경우든 [[intermediate-value-theorem|사잇값 정리]]의 (2)를 $a = 0$, $b = 2^{-1}$, $y = 0$으로 쓰면 $g(c) = 0$인 $c \in [0, 2^{-1}]$가 있다. (K12)의 (v)에 의해 $f(c + 2^{-1}) = f(c)$이다.

**(2)** $f(0) = 0 = f(1)$이고, $f$는 연속함수이다([[power-function-is-continuous|거듭제곱 함수와 제곱근 함수의 연속]]의 (1)과 연속함수의 합·곱·몫의 (3), 연속함수의 (5)). $c \in [0, 2^{-1}]$에 대하여 (K1)–(K3), (K12)로 전개하면
$$
\begin{aligned}
f(c + 2^{-1}) &= c c + c + 4^{-1} - c - 2^{-1} \\
&= c c - 4^{-1}
\end{aligned}
$$
이다($2^{-1} \cdot 2^{-1} = 4^{-1}$은 (K12)의 (vi), $4^{-1} - 2^{-1} = -4^{-1}$은 $2^{-1} = 2 \cdot 4^{-1}$에서). 따라서 $f(c + 2^{-1}) = f(c)$인 것은 정확히 $c c - 4^{-1} = c c - c$, 곧 $c = 4^{-1}$일 때이다((K12)의 (v)와 (K8)의 (ii)). 순서 성질 (8)에 의해 $0 < 4^{-1} < 2^{-1}$이므로 $4^{-1} \in [0, 2^{-1}]$이고, 1의 $c$는 $4^{-1}$ 하나뿐이다. 실제로 $f(4^{-1}) = 16^{-1} - 4^{-1} = -3 \cdot 16^{-1}$, $f(3 \cdot 4^{-1}) = 9 \cdot 16^{-1} - 12 \cdot 16^{-1} = -3 \cdot 16^{-1}$이다.
:::

:::exercise[상이 닫힌구간인 불연속함수]
$0 \le x \le 1$이면 $f(x) = x$, $1 < x \le 2$이면 $f(x) = x - 1$로 정한 $f : [0, 2] \to \mathbb{R}$를 생각한다.

1. $f([0, 2]) = [0, 1]$임을 보여라.
2. $f$가 $1$에서 불연속임을 보여라. 곧 "상이 닫힌구간이면 연속함수이다"는 성립하지 않는다.
:::

:::solution
상은 [[image-and-preimage|상과 역상]]의 것이고, 아래에서 "순서 성질"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다. 순서 성질 (1)의 (iii)에 의해 $[0, 2]$의 각 원소는 $x \le 1$과 $1 < x$ 가운데 정확히 한 경우에 들므로, [[real-valued-function|실함수와 그 연산]]의 (1)에 의해 $f$는 실함수이다.

**(1)** $x \in [0, 2]$라 하자. $x \le 1$이면 $f(x) = x \in [0, 1]$이다. $1 < x \le 2$이면 순서 성질 (2)의 (ii)에 의해 $0 < x - 1 \le 1$이므로 $f(x) = x - 1 \in [0, 1]$이다. 따라서 상과 역상의 (1)에 의해 $f([0, 2]) \subseteq [0, 1]$이다. 거꾸로 $y \in [0, 1]$이면 $y \le 1 < 2$이므로 $y \in [0, 2]$이고 $f(y) = y$이어서 $y \in f([0, 2])$이다. 두 집합의 원소가 일치하므로 [[set|집합]]의 같음에 의해 $f([0, 2]) = [0, 1]$이다.

**(2)** $x_n = 1 + (2n)^{-1}$로 둔다. 자연수 $n$은 [[prime-number]]의 (Z1)과 순서 성질 (10)에 의해 $1 \le n$이므로 $2 \le 2n$이고, 순서 성질 (6)의 (i), (ii)에 의해 $0 < (2n)^{-1} \le 2^{-1}$이다. 따라서 $1 < x_n \le 1 + 2^{-1} < 2$이므로 $x_n \in [0, 2]$이고 $f(x_n) = (2n)^{-1}$이다. [[real-number-arithmetic|실수의 계산 법칙]]의 (K12)의 (vi)에 의해 $(2n)^{-1} = 2^{-1} n^{-1}$이므로, [[basic-limits]]의 (2)와 [[limit-of-sum-and-product|극한의 사칙연산]]의 (5)에 의해 $(f(x_n))$은 $2^{-1} \cdot 0 = 0$으로 수렴하고 $(x_n)$은 $1 + 0 = 1$로 수렴한다. $f(1) = 1 \ne 0$이므로 [[limit-is-unique|극한의 유일성]]에 의해 $(f(x_n))$은 $f(1)$로 수렴하지 않는다. [[sequences-and-continuity|수열로 본 극한과 연속]]의 (3)의 (i)에 의해 $f$는 $1$에서 불연속이다.

[[intermediate-value-theorem|사잇값 정리]]의 (4)는 연속함수의 상이 닫힌구간이거나 원소가 하나인 집합이라고 말한다. 이 예는 그 역이 성립하지 않음을 보인다.
