:::exercise[(n² + 3n)/(2n² + 1) 의 극한]
$n$번째 항이 $x_n = (n^2 + 3n)(2n^2 + 1)^{-1}$인 수열 $(x_n)$의 극한을 극한의 사칙연산으로 구하라.
:::

:::solution
극한은 $\dfrac{1}{2}$이다. 아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓰고, 거듭제곱은 [[power-of-a-real-number|실수의 거듭제곱]]의 것이다.

먼저 항을 고쳐 쓴다. 자연수 $n$에 대하여 $u = n^{-1}$로 두면 $nu = 1$이다. 거듭제곱의 (1)에 의해 $n^2 = nn$이고 $u^2 = uu$이며, (2)의 (iii)에 의해 $n^2 u^2 = (nu)^2 = 1^2 = 1$이다((2)의 (iv)). [[real-number-arithmetic|실수의 계산 법칙]]의 (K1)–(K4)에 의해 $n^2(1 + 3u) = n^2 + 3n(nu) = n^2 + 3n$이고 $n^2(2 + u^2) = 2n^2 + n^2u^2 = 2n^2 + 1$이다. $0 < n$이므로 거듭제곱의 (6)의 (i)에 의해 $0 < n^2$이고 $n^2 \ne 0$이다. 또 $0 < u$이므로 거듭제곱의 (6)의 (i)에 의해 $0 \le u^2$이고, 순서 성질 (2)의 (iv)에 의해 $0 < 2 + u^2$이고 $2 + u^2 \ne 0$이다. (K12)의 (vi)에 의해 $(n^2(2 + u^2))^{-1} = (n^2)^{-1}(2 + u^2)^{-1}$이므로, (K1), (K2), (K8)의 (iii), (K4)에 의해
$$
\begin{aligned} x_n &= n^2(1 + 3u)\,(n^2)^{-1}(2 + u^2)^{-1} \\ &= (1 + 3n^{-1})\,\bigl(2 + (n^{-1})^2\bigr)^{-1} \end{aligned}
$$
이다.

이제 [[limit-of-sum-and-product|극한의 사칙연산]]의 번호를 쓴다. [[basic-limits|기본적인 극한]]의 (2)에 의해 $\lim_{n \to \infty} n^{-1} = 0$이다.

- (5)에 의해 $n$번째 항이 $3n^{-1}$인 수열은 $3 \cdot 0 = 0$으로 수렴하고, 다시 (5)에 의해 $n$번째 항이 $1 + 3n^{-1}$인 수열은 $1 + 0 = 1$로 수렴한다.
- (6)을 $k = 2$로 쓰면 $n$번째 항이 $(n^{-1})^2$인 수열은 $0^2 = 0$으로 수렴하고(거듭제곱의 (2)의 (iv)), (5)에 의해 $n$번째 항이 $2 + (n^{-1})^2$인 수열은 $2$로 수렴한다.
- 위에서 본 대로 모든 $n$에서 $2 + (n^{-1})^2 \ne 0$이고 극한 $2$도 $0$이 아니므로, (4)에 의해 $n$번째 항이 $(1 + 3n^{-1})(2 + (n^{-1})^2)^{-1}$인 수열은 $1 \cdot 2^{-1} = \dfrac{1}{2}$로 수렴한다.

이 수열은 위의 계산에 의해 $(x_n)$과 모든 항이 같으므로 [[sequence|수열]]의 진술(함수의 같음)에 의해 $(x_n)$이고, $\lim_{n \to \infty} x_n = \dfrac{1}{2}$이다.

검산으로 $x_1 = 4 \cdot 3^{-1}$, $x_{10} = 130 \cdot 201^{-1}$, $x_{100} = 10300 \cdot 20001^{-1}$이다. 마지막 값과 $\dfrac{1}{2}$의 차는 $x_{100} - \dfrac{1}{2} = (20600 - 20001)(40002)^{-1} = 599 \cdot 40002^{-1}$이다.

분자와 분모를 각각 수열로 보아 몫의 극한을 곧바로 쓸 수는 없다. 자연수 $n$에서 $0 < 2n$이고 $0 \le n^2$이므로 순서 성질 (2)의 (iv)에 의해 $0 < 2n + n^2$이고, 순서 성질 (2)의 (ii)에 의해 $n < n + (2n + n^2) = n^2 + 3n$이다. 실수 $B$가 주어지면 [[archimedean-property|아르키메데스 성질]]의 (1)에 의해 $B < n$인 자연수 $n$이 있고 $B < n^2 + 3n$이므로, 분자의 수열은 위로 유계가 아니고 [[sequence|수열]]의 (3)에 의해 유계가 아니다. [[convergent-sequence-is-bounded|수렴하는 수열은 유계라는 정리]]의 (2)에 의해 분자의 수열은 수렴하지 않으므로 (4)의 가정이 성립하지 않는다. $n^2$으로 나누어 둔 것은 이 때문이다.
:::

:::exercise[2ⁿ/(3ⁿ + 1) 을 등비수열로 누르기]
$n$번째 항이 $x_n = 2^n(3^n + 1)^{-1}$인 수열이 $0$으로 수렴함을 조임 정리로 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓰고, 거듭제곱은 [[power-of-a-real-number|실수의 거듭제곱]]의 것이다. 자연수 $n$을 잡는다.

$0 < 2$, $0 < 3$이므로 거듭제곱의 (6)의 (i)에 의해 $0 < 2^n$이고 $0 < 3^n$이다. $0 < 1$이므로 순서 성질 (2)의 (ii)에 의해 $3^n < 3^n + 1$이고, (W2)에 의해 $0 < 3^n + 1$이다. 따라서 $x_n$이 정해지고([[sequence|수열]]의 (1)), 순서 성질 (6)의 (i)과 [[real-order-axioms|실수의 순서]]의 (W4)에 의해 $0 < x_n$이다.

순서 성질 (6)의 (ii)를 $0 < 3^n < 3^n + 1$에 쓰면 $(3^n + 1)^{-1} < (3^n)^{-1}$이고, $0 < 2^n$이므로 순서 성질 (4)의 (i)에 의해 $x_n < 2^n(3^n)^{-1}$이다. $3 \ne 0$이므로 거듭제곱의 (3)에 의해 $(3^n)^{-1} = (3^{-1})^n$이고, (2)의 (iii)에 의해 $2^n(3^{-1})^n = (2 \cdot 3^{-1})^n$이다. $c = 2 \cdot 3^{-1}$로 두면 모든 $n$에서
$$
0 \le x_n \le c^n
$$
이다.

$c$의 크기를 본다. $0 < 3^{-1}$(순서 성질 (6)의 (i))이고 $2 < 3$이므로 순서 성질 (4)의 (i)에 의해 $2 \cdot 3^{-1} < 3 \cdot 3^{-1} = 1$이다. (W4)에 의해 $0 < c$이다. 따라서 [[absolute-value|절댓값]]의 (1)에 의해 $|c| = c < 1$이고, [[geometric-sequence-limit|등비수열의 극한]]의 (1)에 의해 $\lim_{n \to \infty} c^n = 0$이다. 모든 항이 $0$인 상수 수열은 [[basic-limits|기본적인 극한]]의 (1)에 의해 $0$으로 수렴한다. [[squeeze-lemma|조임 정리]]의 (1)을 $a_n = 0$, $b_n = c^n$, $L = 0$으로 쓰면 $(x_n)$은 수렴하고 $\lim_{n \to \infty} x_n = 0$이다.

검산으로 $x_1 = 2 \cdot 4^{-1} = \tfrac{1}{2}$이고 $c^1 = \tfrac{2}{3}$이며, $x_2 = 4 \cdot 10^{-1} = \tfrac{2}{5}$이고 $c^2 = \tfrac{4}{9}$이다. $\tfrac{1}{2} < \tfrac{2}{3}$($3 < 4$), $\tfrac{2}{5} < \tfrac{4}{9}$($18 < 20$)이다.
:::

:::exercise[x₁ = 0, xₙ₊₁ = √(xₙ + 2) 인 수열]
$x_1 = 0$이고 모든 자연수 $n$에서 $x_{n+1} = \sqrt{x_n + 2}$인 수열 $(x_n)$을 생각한다.

1. 이런 수열이 정확히 하나 있고 모든 항이 $0$ 이상임을 재귀 정리로 보여라.
2. 모든 자연수 $n$에서 $x_n < x_{n+1} < 2$임을 보여라.
3. $(x_n)$이 수렴하고 $\lim_{n \to \infty} x_n = 2$임을 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓰고, 제곱근은 [[square-root-exists|제곱근의 존재]]의 것이다.

1. $X = \{t \in \mathbb{R} : 0 \le t\}$로 둔다. $t \in X$이면 $0 < 2$, $0 \le t$와 순서 성질 (2)의 (iv)에 의해 $0 < 2 + t$이므로 제곱근의 존재의 (1)에 의해 $\sqrt{t + 2}$가 실수 하나로 정해지고 $0 \le \sqrt{t + 2}$, 곧 $\sqrt{t + 2} \in X$이다. [[recursion-theorem|재귀 정리]]의 (1)에 의해 $g(n, t) = \sqrt{t + 2}$인 함수 $g : \mathbb{N} \times X \to X$가 있다. $0 \in X$이므로 재귀 정리와 그 (3)에 의해 $x_1 = 0$이고 모든 $n$에서 $x_{n+1} = g(n, x_n) = \sqrt{x_n + 2}$인 수열이 정확히 하나 있고, 모든 항이 $X$에 속한다. 곧 모든 $n$에서 $0 \le x_n$이다.

2. 먼저 $\sqrt{4} = 2$이다. $2 \cdot 2 = 4$이고 $0 \le 2$이므로 제곱근의 존재의 (1)의 유일성에 의해서이다. 자연수 $n$에 대한 명제 "$x_n < x_{n+1} < 2$"를 [[mathematical-induction|수학적 귀납법]]으로 보인다.

   (기초 단계) $x_2 = \sqrt{0 + 2} = \sqrt{2}$이다. $0 < 2$이므로 제곱근의 존재의 (1)에 의해 $0 < \sqrt{2}$, 곧 $x_1 < x_2$이다. $2 < 4$이므로 제곱근의 존재의 (2)에 의해 $\sqrt{2} < \sqrt{4} = 2$이다.

   (귀납 단계) 자연수 $k$에 대하여 $x_k < x_{k+1} < 2$라 하자. 순서 성질 (2)의 (ii)로 $2$를 더하면 $x_k + 2 < x_{k+1} + 2 < 4$이다. 1에 의해 $0 \le x_k$, $0 \le x_{k+1}$이므로 세 수 $x_k + 2$, $x_{k+1} + 2$, $4$는 모두 $0$ 이상이고, 제곱근의 존재의 (2)에 의해 $\sqrt{x_k + 2} < \sqrt{x_{k+1} + 2} < \sqrt{4} = 2$이다. 곧 $x_{k+1} < x_{k+2} < 2$이다.

   기초 단계와 귀납 단계에 의해 모든 자연수 $n$에서 $x_n < x_{n+1} < 2$이다.

3. 2에 의해 $(x_n)$은 단조증가이고 모든 $n$에서 $x_n \le 2$이므로 위로 유계이다. [[monotone-convergence-theorem|단조수렴정리]]의 (1)에 의해 $(x_n)$은 수렴한다. $L = \lim_{n \to \infty} x_n$으로 두면, 1과 [[limits-preserve-inequalities|극한과 부등식]]의 (3)에 의해 $0 \le L$이다.

   [[limit-of-sum-and-product|극한의 사칙연산]]의 (5)에 의해 $n$번째 항이 $x_n + 2$인 수열은 $L + 2$로 수렴하고, 그 모든 항은 $0$ 이상이다. [[limit-of-absolute-value-and-square-root|절댓값과 제곱근의 극한]]의 (2)에 의해 $n$번째 항이 $\sqrt{x_n + 2}$인 수열은 $\sqrt{L + 2}$로 수렴한다. 그런데 이 수열의 $n$번째 항은 $x_{n+1}$이므로, 이 수열은 $(x_n)$의 $1$-꼬리와 모든 항이 같고 [[sequence|수열]]의 진술(함수의 같음)에 의해 $1$-꼬리이다. [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $1$-꼬리는 $L$로 수렴하므로, [[limit-is-unique|극한의 유일성]]에 의해 $L = \sqrt{L + 2}$이다.

   제곱근의 정의에 의해 $LL = L + 2$이다. (K1)–(K4)와 (K7), (K12)에 의해 $(L - 2)(L + 1) = LL + L - 2L - 2 = LL - L - 2 = (L + 2) - L - 2 = 0$이고, (K10)에 의해 $L - 2 = 0$이거나 $L + 1 = 0$, 곧 (K12)의 (v)에 의해 $L = 2$이거나 $L = -1$이다. $-1 < 0 \le L$이므로 순서 성질 (1)의 (i)과 (v)에 의해 $L \ne -1$이다. 따라서 $L = 2$이다.

처음 몇 항은 $x_1 = 0$, $x_2 = \sqrt{2}$, $x_3 = \sqrt{2 + \sqrt{2}}$이다.

극한을 구하는 마지막 단계는 수렴한다는 것을 먼저 보인 뒤에만 쓸 수 있다. 식 $L = \sqrt{L + 2}$는 "극한이 있다면 그 값"을 말할 뿐이다.
:::

:::exercise[곱의 수열과 0 이 아닌 극한에서 다른 수열의 극한 구하기]
수열 $(x_n)$, $(y_n)$에 대하여 $\lim_{n \to \infty} x_n = L$이고 $n$번째 항이 $x_n y_n$인 수열이 실수 $P$로 수렴한다고 하자.

1. $L \ne 0$이면, 어떤 자연수 $M$이 있어 $M$ 이상인 모든 자연수 $n$에서 $x_n \ne 0$임을 보여라.
2. $L \ne 0$이면 $(y_n)$은 수렴하고 $\lim_{n \to \infty} y_n = P / L$임을 보여라.
3. $L = 0$이면 2의 결론이 성립하지 않을 수 있음을, $x_n = n^{-1}$과 [[basic-limits|기본적인 극한]]의 (3)의 수열 $(s_n)$($n$이 짝수이면 $1$, 홀수이면 $-1$)을 $y_n = s_n$으로 두어 보여라.
:::

:::solution
아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓴다.

1. $L \ne 0$이므로 [[absolute-value|절댓값]]의 (2)에 의해 $0 \le |L|$이고 $|L| \ne 0$이어서 $0 < |L|$이며, 순서 성질 (8)에 의해 $0 < |L|\,2^{-1}$이다. [[limit-of-sequence|수열의 극한]]의 정의를 $\varepsilon = |L|\,2^{-1}$에 쓰면, $M$ 이상인 모든 자연수 $n$에서 $|x_n - L| < |L|\,2^{-1}$인 자연수 $M$이 있다. 그런 $n$에서 [[absolute-value|절댓값]]의 (6)에 의해 $|L| - |x_n| \le \bigl|\,|L| - |x_n|\,\bigr|$이고, [[triangle-inequality|삼각부등식]]의 (2)와 [[absolute-value|절댓값]]의 (3)에 의해 $\bigl|\,|L| - |x_n|\,\bigr| \le |L - x_n| = |x_n - L| < |L|\,2^{-1}$이며, 순서 성질 (1)의 (v)에 의해 $|L| - |x_n| < |L|\,2^{-1}$이다. 양변에 $|x_n| - |L|\,2^{-1}$을 더하면 순서 성질 (2)의 (ii)와 [[real-number-arithmetic|실수의 계산 법칙]]의 (K1)–(K4), (K8), (K3)($|L| = |L|\,2^{-1} + |L|\,2^{-1}$)에 의해 $|L|\,2^{-1} < |x_n|$이다. (W2)에 의해 $0 < |x_n|$이고, 순서 성질 (1)의 (i)과 [[absolute-value|절댓값]]의 (2)에 의해 $x_n \ne 0$이다.

2. 1의 $M$으로 [[tail-of-a-sequence|수열의 꼬리]]의 $M$-꼬리를 쓴다. $u_n = x_{n+M}$, $w_n = x_{n+M}\,y_{n+M}$, $v_n = y_{n+M}$으로 두면 $(u_n)$, $(w_n)$, $(v_n)$은 각각 $(x_n)$, 곱의 수열, $(y_n)$의 $M$-꼬리이다. 꼬리의 (1)에 의해 $(u_n)$은 $L$로, $(w_n)$은 $P$로 수렴한다. 자연수 $n$에서 $0 < n$이므로 [[well-ordering-principle|정렬 원리]]의 (Z7)에 의해 $M < n + M$이고, 1에 의해 $u_n = x_{n+M} \ne 0$이다.

   [[limit-of-sum-and-product|극한의 사칙연산]]의 (4)를 $(w_n)$과 $(u_n)$에 쓰면($L \ne 0$이고 모든 $u_n \ne 0$), $n$번째 항이 $w_n / u_n$인 수열은 $P / L$로 수렴한다. (K1), (K2), (K8)의 (iii), (K4)에 의해
   $$
   \begin{aligned} w_n / u_n &= x_{n+M}\,y_{n+M}\,x_{n+M}^{-1} \\ &= y_{n+M}\,(x_{n+M}\,x_{n+M}^{-1}) \\ &= y_{n+M} = v_n \end{aligned}
   $$
   이므로 이 수열은 $(v_n)$이다([[sequence|수열]]의 진술, 함수의 같음). 곧 $(y_n)$의 $M$-꼬리가 $P / L$로 수렴하고, 꼬리의 (1)에 의해 $(y_n)$이 $P / L$로 수렴한다.

3. [[basic-limits|기본적인 극한]]의 (2)에 의해 $\lim_{n \to \infty} n^{-1} = 0$이므로 $L = 0$이다. 모든 $n$에서 $|s_n| = 1$이므로($|1| = 1$이고 $|-1| = -(-1) = 1$, (K9)) $C = 1$로 두면 $|s_n| \le C$이다. [[limit-of-sum-and-product|극한의 사칙연산]]의 (7)에 의해 $n$번째 항이 $n^{-1} s_n$인 수열은 $0$으로 수렴한다. 곧 곱의 수열은 $P = 0$으로 수렴한다. 그러나 [[basic-limits|기본적인 극한]]의 (3)에 의해 $(y_n) = (s_n)$은 발산한다.

2의 증명에서 $L \ne 0$은 두 곳에 쓰였다. 1에서 $\varepsilon = |L|\,2^{-1}$이 양수가 되게 하는 곳과, 몫의 극한에서 분모의 극한이 $0$이 아니어야 하는 곳이다.
:::

:::exercise[항의 절댓값이 줄어들기만 하는 수열]
$n$번째 항이 $x_n = 1 + n^{-1}$인 수열 $(x_n)$을 생각한다.

1. 모든 자연수 $n$에서 $x_n \ne 0$이고 $|x_{n+1}| < |x_n|$임을 보여라. 따라서 $q_n = |x_{n+1}|\,|x_n|^{-1}$로 두면 모든 $n$에서 $q_n < 1$이다.
2. 그런데 $(x_n)$은 $0$이 아닌 $1$로 수렴함을 보여라.
3. $(q_n)$의 극한을 구하고, [[ratio-test-for-sequences|수열의 비 판정법]]의 (1)의 가정 "$L < 1$"을 "모든 $n$에서 $q_n < 1$"로 바꿀 수 없음을 설명하라.
:::

아래에서 [[order-properties-of-reals|실수의 순서의 성질]]의 번호를 "순서 성질 (1)의 (i)"처럼 쓴다.

1. 자연수 $n$에서 순서 성질 (10)에 의해 $0 < n^{-1}$이고, $0 < 1$과 순서 성질 (2)의 (iv)에 의해 $0 < 1 + n^{-1} = x_n$이다. 따라서 순서 성질 (1)의 (i)에 의해 $x_n \ne 0$이고, [[absolute-value|절댓값]]의 (1)에 의해 $|x_n| = x_n$이다. $0 < n < n + 1$(순서 성질 (2)의 (ii))이므로 순서 성질 (6)의 (ii)에 의해 $(n + 1)^{-1} < n^{-1}$이고, 순서 성질 (2)의 (ii)로 $1$을 더하면 $x_{n+1} < x_n$, 곧 $|x_{n+1}| < |x_n|$이다. $0 < x_n$이므로 순서 성질 (6)의 (i)에 의해 $0 < x_n^{-1}$이고, 순서 성질 (4)의 (i)에 의해 $q_n = x_{n+1} x_n^{-1} < x_n x_n^{-1} = 1$이다.

2. [[basic-limits|기본적인 극한]]의 (2)에 의해 $\lim_{n \to \infty} n^{-1} = 0$이고, [[limit-of-sum-and-product|극한의 사칙연산]]의 (5)에 의해 $\lim_{n \to \infty} (1 + n^{-1}) = 1 + 0 = 1$이다. $1 \ne 0$이다([[real-number-arithmetic|실수의 계산 법칙]]의 (K4)).

3. 극한은 $1$이다. $(x_{n+1})$은 $(x_n)$의 $1$-꼬리이므로 [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $1$로 수렴한다. 1에 의해 $q_n = x_{n+1}\,x_n^{-1} = x_{n+1} / x_n$이고, 모든 $n$에서 $x_n \ne 0$이며 $\lim_{n \to \infty} x_n = 1 \ne 0$이므로, [[limit-of-sum-and-product|극한의 사칙연산]]의 (4)에 의해 $\lim_{n \to \infty} q_n = 1 / 1 = 1$이다((K4), (K8)의 (iii)).

   따라서 이 수열에서 비 판정법의 $L$은 $1$이고, 판정법의 (1)도 (2)도 쓸 수 없다. 이 수열은 모든 $n$에서 $q_n < 1$을 만족하지만 2에 의해 $0$으로 수렴하지 않는다. 그래서 (1)의 가정 "$L < 1$"을 "모든 $n$에서 $q_n < 1$"로 바꾸면 결론이 거짓이 될 수 있다. 또 이 수열에는 $r < 1$이고 어떤 자연수 $M$ 이상인 모든 $n$에서 $q_n \le r$인 실수 $r$이 없으므로, 판정법의 (3)을 $r < 1$로 쓸 수도 없다. $r < 1$이면 $0 < 1 - r$이므로 $\lim_{n \to \infty} q_n = 1$의 정의를 $\varepsilon = 1 - r$에 쓰면 어떤 번호 $M'$ 이상인 모든 $n$에서 $1 - (1 - r) < q_n$, 곧 $r < q_n$이고([[limit-of-sequence|수열의 극한]]의 (1)), $n = \max\{M, M'\}$([[absolute-value|절댓값]]의 (10))에서 순서 성질 (1)의 (i)에 의해 $q_n \le r$이 깨지기 때문이다.
