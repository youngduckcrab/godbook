:::exercise[닫힌구간 [0, 2] 위의 xⁿ/(1 + xⁿ)]
자연수 $n$과 $x \in [0, 2]$에 대하여 $g_n(x) = x^n(1 + x^n)^{-1}$로 두고, $n$번째 사상이 $x$를 $g_n(x)$로 보내는 $[0, 2]$에서 $\mathbb{R}$(보통 거리)로의 사상의 열 $(g_n)$을 생각한다.

1. $(g_n)$의 점별 극한 $h$를 구하라.
2. $0 < a < 1 < b < 2$인 실수 $a$, $b$에 대하여 $E = [0, a] \cup [b, 2]$로 두면, $(g_n)$이 $E$ 위에서 $h|_E$로 고르게 수렴함을 보여라.
3. $(g_n)$이 $[0, 2]$에서 $\mathbb{R}$로의 어떤 사상으로도 고르게 수렴하지 않음을 보여라.
:::

:::solution
사상의 열, 점별 수렴, 제한의 열과 "$A$ 위에서"는 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고, 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이다. 아래에서 "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "거듭제곱 (n)"은 [[power-of-a-real-number|실수의 거듭제곱]]의 번호, "절댓값 (n)"은 [[absolute-value|절댓값]]의 번호이고, 실수의 계산은 [[real-number-arithmetic|실수의 계산 법칙]]의 것이다.

**준비.** $x \in [0, 2]$이고 $n$이 자연수이면 거듭제곱 (6)의 (i)에 의해 $0 \le x^n$이고, 순서 (5)의 (ii)의 $0 < 1$과 순서 (2)의 (iv)에 의해 $0 < 1 + x^n$이며, 순서 (6)의 (i)에 의해 $0 < (1 + x^n)^{-1}$이다. 그래서 $g_n(x)$는 식으로 정해진 실수이고, 점별 수렴의 항목의 (1)에 의해 열 $(g_n)$이 있다. 다음 두 사실을 쓴다.

- (가) $0 \le g_n(x) \le x^n$이다. 순서 (4)의 (iv)에 의해 $0 \le g_n(x)$이다. 계산으로 $g_n(x)(1 + x^n) = x^n$, 곧 $x^n = g_n(x) + g_n(x)\,x^n$이고, 순서 (4)의 (iv)에 의해 $0 \le g_n(x)\,x^n$이므로 순서 (2)의 (i)에 의해 $g_n(x) \le x^n$이다.
- (나) $0 < x$이면 $0 < 1 - g_n(x) \le (x^{-1})^n$이다. 계산으로 $1 - g_n(x) = (1 + x^n)^{-1}$이고 이것은 양수이다. 거듭제곱 (6)의 (i)에 의해 $0 < x^n$이고 순서 (2)의 (ii)에 의해 $x^n < 1 + x^n$이므로, 순서 (6)의 (ii)에 의해 $(1 + x^n)^{-1} < (x^n)^{-1}$이고, 거듭제곱 (3)에 의해 $(x^n)^{-1} = (x^{-1})^n$이다.

**1.** $0 \le x < 1$이면 $h(x) = 0$, $h(1) = 2^{-1}$, $1 < x \le 2$이면 $h(x) = 1$로 정한다. 순서 (1)의 (iii)과 (i)에 의해 $[0, 2]$의 각 점은 $x < 1$, $x = 1$, $1 < x$ 가운데 정확히 하나에 들므로, [[real-valued-function|실함수]]의 (1)에 의해 $h : [0, 2] \to \mathbb{R}$가 정해진다. 점마다 실수열 $(g_n(x))$를 본다.

- $0 \le x < 1$이면 절댓값 (1)에 의해 $|x| = x < 1$이므로 [[geometric-sequence-limit|등비수열의 극한]]의 (1)에 의해 $(x^n)$은 $0$으로 수렴한다. (가)의 두 끝은 상수 수열 $0$([[basic-limits|기본적인 극한]]의 (1))과 $(x^n)$이므로 [[squeeze-lemma|조임 정리]]의 (1)에 의해 $(g_n(x))$는 $0$으로 수렴한다.
- $x = 1$이면 거듭제곱 (2)의 (iv)에 의해 모든 $n$에서 $1^n = 1$이므로 $g_n(1) = 1 \cdot (1 + 1)^{-1} = 2^{-1}$이고, 기본적인 극한의 (1)에 의해 $(g_n(1))$은 $2^{-1}$로 수렴한다.
- $1 < x \le 2$이면 $0 < 1 < x$이므로 순서 (6)의 (ii)에 의해 $0 < x^{-1} < 1$이고, 등비수열의 극한의 (1)에 의해 $((x^{-1})^n)$은 $0$으로 수렴한다. (나)와 조임 정리의 (1)에 의해 $(1 - g_n(x))$는 $0$으로 수렴한다. $g_n(x) = 1 + (-1)(1 - g_n(x))$이므로 [[limit-of-sum-and-product|수열의 합과 곱의 극한]]의 (5)를 두 번 쓰면 $(g_n(x))$는 $1 + (-1) \cdot 0 = 1$로 수렴한다.

어느 점에서나 $(g_n(x))$는 해석학 입문의 뜻으로 $h(x)$로 수렴하므로, 점별 수렴의 항목의 (8)에 의해 $(g_n)$은 $h$로 점별 수렴하고, 그 (3)에 의해 점별 극한은 $h$뿐이다.

**2.** *$[0, a]$ 위.* $x \in [0, a]$이면 $x \le a < 1$이므로 $h(x) = 0$이고, 거듭제곱 (6)의 (ii)에 의해 $x^n \le a^n$이다. (가)와 절댓값 (1)에 의해
$$
|g_n(x) - h(x)| = g_n(x) \le a^n
$$
이다. $|a| = a < 1$이므로 등비수열의 극한의 (1)에 의해 $(a^n)$은 $0$으로 수렴한다. [[adding-or-removing-an-element]]의 함수의 제한에 의해 $x \in [0, a]$에서 $g_n|_{[0, a]}(x) = g_n(x)$, $h|_{[0, a]}(x) = h(x)$이므로, 고른 수렴의 항목의 (4)를 열 $(g_n|_{[0, a]})$, 사상 $h|_{[0, a]}$, 실수열 $(a^n)$, $K = 1$에 쓰면 $(g_n)$은 $[0, a]$ 위에서 $h|_{[0, a]}$로 고르게 수렴한다.

*$[b, 2]$ 위.* $x \in [b, 2]$이면 $1 < b \le x$이므로 $h(x) = 1$이다. $0 < b \le x$이므로 순서 (6)의 (ii)에 의해(등호이면 그대로) $x^{-1} \le b^{-1}$이고, $0 < x^{-1}$이므로 거듭제곱 (6)의 (ii)에 의해 $(x^{-1})^n \le (b^{-1})^n$이다. (나), 절댓값 (3)과 (1)에 의해
$$
|g_n(x) - h(x)| = 1 - g_n(x) \le (b^{-1})^n
$$
이다. 앞 경우와 같이 $0 < b^{-1} < 1$이므로 $((b^{-1})^n)$은 $0$으로 수렴하고, 고른 수렴의 항목의 (4)에 의해 $(g_n)$은 $[b, 2]$ 위에서 $h|_{[b, 2]}$로 고르게 수렴한다.

*합치기.* $[0, a]$와 $[b, 2]$는 $[0, 2]$의 부분집합이므로 고른 수렴의 항목의 (7)에 의해 $(g_n)$은 $E$ 위에서 $h|_E$로 고르게 수렴한다.

**3.** *$g_n$은 연속함수이다.* [[power-function-is-continuous|거듭제곱 함수의 연속]]의 (1)과 [[continuous-function|연속함수]]의 (5)에 의해 $x^n$으로 정한 $[0, 2]$ 위의 함수는 연속이고, 같은 항목의 (4)에 의해 상수함수 $1$도 연속이다. [[continuity-of-sum-and-product|연속함수의 합과 곱]]의 (3)에 의해 $1 + x^n$으로 정한 함수는 연속이고 준비에 의해 $[0, 2]$에서 $0$이 아니므로, 같은 (3)에 의해 몫 $g_n$은 $[0, 2]$ 위의 연속함수이다.

*$h$는 $1$에서 불연속이다.* $\varepsilon = 4^{-1}$로 두고 양의 실수 $\delta$를 잡는다. 절댓값 (10)에 의해 $m = \min\{\delta, 1\}$은 $\delta$이거나 $1$이어서 양수이고 $m \le \delta$, $m \le 1$이다. $t = 2^{-1}m$이면 순서 (8)에 의해 $0 < t < m$이고 순서 (1)의 (v)에 의해 $t < \delta$, $t < 1$이다. $x_0 = 1 - t$로 두면 순서 (3)의 (i)과 (2)의 (ii)에 의해 $0 < x_0 < 1$이므로 $x_0 \in [0, 2]$이고 $h(x_0) = 0$이며, 절댓값 (3), (1)에 의해 $|x_0 - 1| = t < \delta$이다. 그런데 $|h(x_0) - h(1)| = 2^{-1} \ge 4^{-1}$이다(순서 (6)의 (ii)). [[continuous-function|연속함수]]의 (1)에 의해 $h$는 $1$에서 불연속이다.

*결론.* $(g_n)$이 어떤 사상 $g : [0, 2] \to \mathbb{R}$로 고르게 수렴한다고 하자. 고른 수렴의 항목의 (2)와 1에 의해 $g = h$이다. 고른 수렴의 항목의 (8)에 의해 모든 양의 실수 $\varepsilon$에 자연수 $N$이 있어 $n \ge N$과 모든 $x \in [0, 2]$에서 $|g_n(x) - h(x)| < \varepsilon$이므로, [[uniform-limit-of-continuous-maps|연속 사상의 고른 극한은 연속이다]]의 (3)을 $S = [0, 2]$에 쓰면 $h$는 연속함수이다. 이것은 앞 문단과 어긋난다. 따라서 $(g_n)$은 어떤 사상으로도 고르게 수렴하지 않는다. 2의 $E$가 $1$의 둘레를 빼고 있는 것은 이 때문이다.
:::

:::exercise[고르게 연속인 사상과의 합성]
$X$가 집합이고 $(Y, d_Y)$, $(Z, d_Z)$가 거리공간이며, $X$에서 $Y$로의 사상의 열 $(f_n)$이 사상 $f : X \to Y$로 고르게 수렴한다고 하자.

1. $\varphi : Y \to Z$가 고르게 연속이면, $n$번째 사상이 $\varphi \circ f_n$인 $X$에서 $Z$로의 사상의 열이 $\varphi \circ f$로 고르게 수렴함을 보여라.
2. $X = Y = \{x \in \mathbb{R} : 0 < x \le 1\}$(보통 거리의 부분공간 거리), $Z = \mathbb{R}$(보통 거리)로 두고 $f_n(x) = n x (n + 1)^{-1}$, $f(x) = x$, $\varphi(y) = y^{-1}$이라 하자. $(f_n)$은 $f$로 고르게 수렴하고 $\varphi$는 해석학 입문의 뜻의 연속함수이지만, $n$번째 사상이 $\varphi \circ f_n$인 열은 $\varphi \circ f$로 고르게 수렴하지 않음을 보여라. 이로부터 $\varphi$가 고르게 연속이 아님을 이끌어라.
:::

:::solution
사상의 열과 그 식으로 정한 열은 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고, 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이며, 고르게 연속인 사상은 [[uniformly-continuous-map|거리공간 사이의 고르게 연속인 사상]]의 것이다. 합성의 값 $(\varphi \circ f_n)(x) = \varphi(f_n(x))$는 [[function-composition|합성함수]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**1.** 각 자연수 $n$과 $x \in X$에서 $\varphi(f_n(x))$는 이미 정해진 $Z$의 원소이므로, 점별 수렴의 항목의 (1)에 의해 $n$번째 사상이 $x$를 $\varphi(f_n(x))$로 보내는 열이 있고 그 $n$번째 항은 $\varphi \circ f_n$이다. 양의 실수 $\varepsilon$을 잡는다. $\varphi$가 고르게 연속이므로 양의 실수 $\delta$가 있어 $d_Y(p, q) < \delta$인 모든 $p$, $q \in Y$에서 $d_Z(\varphi(p), \varphi(q)) < \varepsilon$이다. 고른 수렴의 정의를 $\delta$에 쓰면 자연수 $N$이 있어 $n \ge N$과 모든 $x \in X$에서 $d_Y(f_n(x), f(x)) < \delta$이고, 따라서
$$
d_Z\bigl(\varphi(f_n(x)), \varphi(f(x))\bigr) < \varepsilon
$$
이다. 이 $N$은 $x$에 따르지 않으므로, 열 $(\varphi \circ f_n)$은 $\varphi \circ f$로 고르게 수렴한다.

**2.** $Y$의 거리는 [[metric-space-examples|거리공간의 예]]의 (3)과 (1)에 의해 $|u - v|$이다.

*$f_n$은 $Y$로 가는 사상이다.* 순서 (10)에 의해 $0 < n < n + 1$이고 $0 < (n + 1)^{-1}$이므로, 순서 (6)의 (iv)에 의해 $q_n = n(n + 1)^{-1}$은 $0 < q_n < 1$이다. $0 < x \le 1$이면 순서 (4)의 (i)과 (iv)에 의해 $0 < x q_n < x \le 1$이므로 $f_n(x) \in Y$이다. 점별 수렴의 항목의 (1)에 의해 열 $(f_n)$이 있다.

*고른 수렴.* 계산으로 $q_n - 1 = -(n + 1)^{-1}$이므로 [[absolute-value|절댓값]]의 (4), (3), (1)에 의해 $|f_n(x) - f(x)| = |x|\,|q_n - 1| = x(n + 1)^{-1} \le (n + 1)^{-1}$이다(순서 (4)의 (iii)). $n$번째 항이 $(n + 1)^{-1}$인 수열은 $n$번째 항이 $n^{-1}$인 수열의 $1$-꼬리이므로 [[basic-limits|기본적인 극한]]의 (2)와 [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $0$으로 수렴한다. 고른 수렴의 항목의 (4)에 의해 $(f_n)$은 $f$로 고르게 수렴한다.

*$\varphi$는 연속함수이다.* $Y$의 원소는 $0$이 아니므로 [[continuity-of-sum-and-product|연속함수의 합과 곱]]의 (3)을 $Y$ 위의 항등함수([[continuous-function|연속함수]]의 (4))의 역수에 쓰면 $\varphi$는 연속함수이다.

*합성은 고르게 수렴하지 않는다.* $x \in Y$이면 계산으로
$$
\begin{aligned}
&\varphi(f_n(x)) - \varphi(f(x)) \\
&\quad = (n + 1)(n x)^{-1} - x^{-1} \\
&\quad = (n x)^{-1}
\end{aligned}
$$
이다. 자연수 $N$을 아무것이나 잡고 $x = N^{-1}$로 두면, 순서 (10)과 (6)의 (ii)(또는 $N = 1$이면 등호)에 의해 $0 < N^{-1} \le 1$이므로 $x \in Y$이고, $\varphi(f_N(x)) - \varphi(f(x)) = (N \cdot N^{-1})^{-1} = 1$이다. 그래서 $\varepsilon = 1$에 대하여 "$n \ge N$과 모든 $x \in Y$에서 $|\varphi(f_n(x)) - \varphi(f(x))| < 1$"인 자연수 $N$은 없고, 고른 수렴의 항목의 (8)에 의해 열 $(\varphi \circ f_n)$은 $\varphi \circ f$로 고르게 수렴하지 않는다.

*$\varphi$는 고르게 연속이 아니다.* $\varphi$가 고르게 연속이라면 1에 의해 $(\varphi \circ f_n)$이 $\varphi \circ f$로 고르게 수렴해야 하는데, 앞 문단과 어긋난다. 그래서 1의 가정 "고르게 연속"을 "연속"으로 바꾸면 결론이 성립하지 않을 수 있다.
:::

:::exercise[고르게 수렴하는 부분수열을 가진 고르게 코시인 열]
$X$가 집합이고 $(Y, d)$가 거리공간이다.

1. $X$에서 $Y$로의 사상의 열 $(f_n)$이 고르게 코시이고, 첨자열 $(n_i)$로 얻은 부분수열 $(f_{n_i})$가 사상 $f : X \to Y$로 고르게 수렴하면, $(f_n)$이 $f$로 고르게 수렴함을 보여라. $Y$가 완비라고 가정하지 않는다.
2. $X \ne \emptyset$이고 $Y = \mathbb{R}$(보통 거리)이며, $n$이 홀수이면 $f_n$은 값이 $0$인 상수 사상, $n$이 짝수이면 값이 $1$인 상수 사상이라 하자. 고르게 수렴하는 부분수열이 있지만 $(f_n)$은 어떤 사상으로도 고르게 수렴하지 않음을 보여라.
:::

:::solution
사상의 열과 그 부분수열은 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고(그 (6)), 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이며, 고르게 코시는 [[uniformly-cauchy-sequence-of-maps|고르게 코시인 사상의 열]]의 것이다. 첨자열은 [[subsequence|부분수열]]의 것이다. 자연수 $P$, $Q$에 대하여 $P + Q$는 자연수이고 $P < P + Q$, $Q < P + Q$이다([[even-and-odd|짝수와 홀수]], [[well-ordering-principle|정렬 원리]]의 (Z6), (Z7), [[prime-number|소수]]의 (Z1)). 양수 $\varepsilon$에 대하여 $0 < \varepsilon \cdot 2^{-1}$이고 $\varepsilon \cdot 2^{-1} + \varepsilon \cdot 2^{-1} = \varepsilon$이다([[order-properties-of-reals|실수의 순서의 성질]]의 (8), [[real-number-arithmetic|실수의 계산 법칙]]).

**1.** 양의 실수 $\varepsilon$을 잡는다. 고르게 코시의 정의에 의해 자연수 $N_1$이 있어 $m, k \ge N_1$과 모든 $x \in X$에서 $d(f_m(x), f_k(x)) < \varepsilon \cdot 2^{-1}$이고, $(f_{n_i})$의 고른 수렴에 의해 자연수 $N_2$가 있어 $i \ge N_2$와 모든 $x \in X$에서 $d(f_{n_i}(x), f(x)) < \varepsilon \cdot 2^{-1}$이다.

$n \ge N_1$이고 $x \in X$라 하자. $i = N_1 + N_2$로 두면 $i > N_2$이고, [[subsequence|부분수열]]의 (1)에 의해 $n_i \ge i > N_1$이다. 그래서 두 부등식을 함께 쓸 수 있고, [[metric-space|거리공간]]의 조건 (iv)와 실수의 순서의 성질의 (2)의 (iv)에 의해
$$
\begin{aligned}
&d(f_n(x), f(x)) \\
&\quad \le d(f_n(x), f_{n_i}(x)) \\
&\qquad + d(f_{n_i}(x), f(x)) \\
&\quad < \varepsilon
\end{aligned}
$$
이다. $N_1$은 $x$에 따르지 않으므로 $(f_n)$은 $f$로 고르게 수렴한다. $i$는 $x$와 $n$을 정한 뒤에 정했지만 결론에 나타나지 않는다.

**2.** [[even-and-odd|짝수와 홀수]]에 의해 각 자연수는 짝수와 홀수 가운데 정확히 하나이므로, 점별 수렴의 항목의 (1)에 의해 열 $(f_n)$이 정해진다.

*고르게 수렴하는 부분수열.* $n_i = 2i - 1$로 두면 $n_i$는 홀수인 자연수이고 $n_{i+1} - n_i = 2 > 0$이므로, [[subsequence|부분수열]]의 (2)에 의해 $(n_i)$는 첨자열이다. 모든 $i$에서 $f_{n_i}$는 값이 $0$인 상수 사상이므로 고른 수렴의 항목의 (3)에 의해 $(f_{n_i})$는 그 상수 사상으로 고르게 수렴한다.

*$(f_n)$은 고르게 수렴하지 않는다.* $(f_n)$이 어떤 사상 $g$로 고르게 수렴한다고 하자. $X$의 점 $p$를 잡으면 고른 수렴의 항목의 (1)과 점별 수렴의 항목의 (8)에 의해 실수열 $(b_n) = (f_n(p))$는 해석학 입문의 뜻으로 수렴한다. $b_n$은 $n$이 짝수이면 $1$, 홀수이면 $0$이다. [[basic-limits|기본적인 극한]]의 (3)의 수열 $(a_n)$($n$이 짝수이면 $1$, 홀수이면 $-1$)은 모든 $n$에서 $a_n = 2b_n + (-1)$이므로 [[limit-of-sum-and-product|수열의 합과 곱의 극한]]의 (5)에 의해 수렴해야 한다. 이것은 기본적인 극한의 (3)과 어긋난다. 따라서 $(f_n)$은 어떤 사상으로도 고르게 수렴하지 않는다. 1에 의해 이 열은 고르게 코시도 아니다. 그래서 1에서 "고르게 코시"라는 가정은 뺄 수 없다.
:::

:::exercise[닫힌구간 [0, 1] 위의 xⁿ(1 − x)]
$[0, 1]$에서 $\mathbb{R}$로의 사상의 열 $(u_n)$을 $u_n(x) = x^n(1 - x)$로 정한다.

1. 디니 정리를 써서 $(u_n)$이 값이 $0$인 상수함수로 고르게 수렴함을 보여라.
2. $u_n(x) = x^n - x^{n+1}$이다. $n$번째 사상이 $x$를 $x^n$으로 보내는 열과 $x^{n+1}$로 보내는 열이 둘 다 $[0, 1]$ 위에서 어떤 사상으로도 고르게 수렴하지 않음을 보여라.
3. 고른 수렴과 적분의 관계로 $\int_0^1 u_n$이 $0$으로 수렴함을 보이고, $\int_0^1 u_n$을 직접 계산해 확인하라.
:::

:::solution
사상의 열은 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고, 고른 수렴과 열 $(p_n)$은 [[uniform-convergence|고른 수렴]]의 것이다(그 (9)). "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "거듭제곱 (n)"은 [[power-of-a-real-number|실수의 거듭제곱]]의 번호이다. 각 $n$과 $x$에서 $x^n(1 - x)$는 식으로 정해진 실수이므로 점별 수렴의 항목의 (1)에 의해 열 $(u_n)$이 있다.

**1.** [[dini-theorem|디니 정리]]의 (3)을 $a = 0$, $b = 1$에 쓴다. 가정을 차례로 본다.

- *연속.* [[power-function-is-continuous|거듭제곱 함수의 연속]]의 (1)과 [[continuous-function|연속함수]]의 (5)에 의해 $x^n$으로 정한 $[0, 1]$ 위의 함수는 연속이고, 연속함수의 (4)와 [[continuity-of-sum-and-product|연속함수의 합과 곱]]의 (3)에 의해 $1 - x$로 정한 함수와 곱 $u_n$은 연속함수이다.
- *줄어들고 $0$ 이상이다.* $0 \le x \le 1$이면 순서 (3)의 (i)에 의해 $0 \le 1 - x$이고 거듭제곱 (6)의 (i)에 의해 $0 \le x^n$이므로 순서 (4)의 (iv)에 의해 $0 \le u_n(x)$이다. 거듭제곱 (1)에 의해 $x^{n+1} = x\,x^n$이므로 $u_{n+1}(x) = x\,u_n(x)$이고, $x \le 1$과 $0 \le u_n(x)$에서 순서 (4)의 (iii)에 의해 $x\,u_n(x) \le u_n(x)$이다. 곧 $0 \le u_{n+1}(x) \le u_n(x)$이다.
- *점마다 $0$으로 수렴한다.* $0 \le x < 1$이면 [[absolute-value|절댓값]]의 (1)에 의해 $|x| = x < 1$이므로 [[geometric-sequence-limit|등비수열의 극한]]의 (1)에 의해 $(x^n)$은 $0$으로 수렴하고, [[limit-of-sum-and-product|수열의 합과 곱의 극한]]의 (5)에 의해 $(u_n(x)) = ((1 - x)x^n)$은 $(1 - x) \cdot 0 = 0$으로 수렴한다. $x = 1$이면 모든 $n$에서 $u_n(1) = 1 \cdot 0 = 0$이므로 [[basic-limits|기본적인 극한]]의 (1)에 의해 $0$으로 수렴한다.

디니 정리의 (3)에 의해 모든 양의 실수 $\varepsilon$에 자연수 $N$이 있어 $n \ge N$과 모든 $x \in [0, 1]$에서 $0 \le u_n(x) < \varepsilon$이고, $(u_n)$은 값이 $0$인 상수함수로 고르게 수렴한다.

**2.** 계산으로 $x^n(1 - x) = x^n - x^n x = x^n - x^{n+1}$이다. $n$번째 사상이 $x^n$인 열은 고른 수렴의 항목의 (9)의 $(p_n)$이고, 그 (9)의 (ii)에 의해 어떤 사상으로도 고르게 수렴하지 않는다.

$n$번째 사상이 $x^{n+1}$인 열 $(r_n)$이 어떤 사상 $g$로 고르게 수렴한다고 하자. 모든 $n$에서 $r_n = p_{n+1}$이다. 양의 실수 $\varepsilon$에 대한 $(r_n)$의 번호를 $N$이라 하면, $n \ge N + 1$이고 $x \in [0, 1]$일 때 $n - 1$은 자연수이고 $n - 1 \ge N$이므로([[well-ordering-principle|정렬 원리]]의 (Z6), (Z7)) $|p_n(x) - g(x)| = |r_{n-1}(x) - g(x)| < \varepsilon$이다. 곧 $N + 1$이 $(p_n)$의 고른 수렴의 번호가 되어 앞 문단과 어긋난다. 따라서 $(r_n)$도 어떤 사상으로도 고르게 수렴하지 않는다. 고르게 수렴하지 않는 두 열의 차 $(u_n)$이 1에 의해 고르게 수렴하는 것이다.

**3.** *극한.* 1의 연속에 의해 $u_n$은 연속함수이고, [[fundamental-theorem-of-calculus-second-form|미적분의 기본정리 둘째 꼴]]의 (4)와 [[oriented-integral|방향 있는 적분]]의 정의($0 < 1$)에 의해 $[0, 1]$에서 리만 적분가능하다. 1과 [[uniform-convergence-and-integral|고른 수렴과 적분]]의 (2)에 의해 $\int_0^1 u_n$은 값이 $0$인 상수함수의 적분으로 수렴하고, [[riemann-integral|리만 적분]]의 (5)에 의해 그 값은 $0$이다.

*직접 계산.* [[antiderivative-and-integral-of-power|원시함수와 거듭제곱의 적분]]의 (3)과 거듭제곱 (2)의 (iv)($n + 1 \ge 1$이면 $0^{n+1} = 0$)에 의해 $\int_0^1 x^n\,dx = (n + 1)^{-1}$이고 $\int_0^1 x^{n+1}\,dx = (n + 2)^{-1}$이다. [[linearity-of-the-integral|적분의 선형성]]의 (4)에 의해
$$
\begin{aligned}
\int_0^1 u_n &= (n + 1)^{-1} - (n + 2)^{-1} \\
&= \bigl((n + 1)(n + 2)\bigr)^{-1}
\end{aligned}
$$
이다. 예를 들어 $n = 1$이면 $\int_0^1 x(1 - x)\,dx = 2^{-1} - 3^{-1} = 6^{-1}$이다. 순서 (10)과 (6)의 (ii)에 의해 $0 < \bigl((n + 1)(n + 2)\bigr)^{-1} \le n^{-1}$이므로, [[basic-limits|기본적인 극한]]의 (1), (2)와 [[squeeze-lemma|조임 정리]]의 (1)에 의해 이 수열은 $0$으로 수렴하고 앞의 결론과 맞는다.
:::

:::exercise[n ln(1 + x/n) 의 고른 수렴과 복리의 수열]
자연수 $n$과 $x \in [0, 1]$에 대하여 $v_n(x) = n \ln(1 + x n^{-1})$로 두고, $n$번째 사상이 $x$를 $v_n(x)$로 보내는 $[0, 1]$에서 $\mathbb{R}$로의 사상의 열 $(v_n)$을 생각한다.

1. 고른 수렴과 미분의 관계를 써서, $(v_n)$이 $[0, 1]$ 위의 항등함수로 고르게 수렴하고 모든 $n$과 $x$에서 $|v_n(x) - x| \le n^{-1}$임을 보여라.
2. $n$번째 항이 $\int_0^1 v_n$인 실수열이 $2^{-1}$로 수렴함을 보여라.
3. 문제 2의 1을 써서, $n$번째 사상이 $x$를 $(1 + x n^{-1})^n$으로 보내는 $[0, 1]$에서 $\mathbb{R}$로의 사상의 열이 $\exp$의 $[0, 1]$로의 제한으로 고르게 수렴함을 보여라.
:::

:::solution
사상의 열은 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고, 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이다. $\mathbb{R}_{>0}$과 $\ln$은 [[natural-logarithm|자연로그]]의 것이고 $\exp$는 [[exponential-function|지수함수]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다. 자연수 $n$에 대하여 $0 < n^{-1}$이다(순서 (10)).

**준비.** $x \in [0, 1]$이면 순서 (4)의 (iv)에 의해 $0 \le n^{-1}x$이므로 $1 \le 1 + n^{-1}x$이고, 따라서 $1 + n^{-1}x \in \mathbb{R}_{>0}$이며 $v_n(x)$는 식으로 정해진 실수이다. 점별 수렴의 항목의 (1)에 의해 열 $(v_n)$이 있다.

**1.** *도함수.* $s_n(x) = 1 + n^{-1}x$로 정한 $s_n : [0, 1] \to \mathbb{R}_{>0}$는 [[continuously-differentiable|연속미분가능]]의 (4)에 의해 연속미분가능하고 $s_n'$은 값이 $n^{-1}$인 상수함수이다. 자연로그의 (2)에 의해 $\ln$은 연속미분가능하고 $\ln'(t) = t^{-1}$이며, $\mathbb{R}_{>0}$은 구간이다(자연로그의 진술). 연속미분가능의 (5)와 (3)에 의해 $v_n = n(\ln \circ s_n)$은 연속미분가능하고
$$
\begin{aligned}
v_n'(x) &= n \cdot (1 + n^{-1}x)^{-1} n^{-1} \\
&= (1 + n^{-1}x)^{-1}
\end{aligned}
$$
이다.

*도함수의 고른 수렴.* $x \in [0, 1]$이면 계산으로 $v_n'(x) - 1 = -n^{-1}x\,(1 + n^{-1}x)^{-1}$이다. $1 \le 1 + n^{-1}x$이므로 순서 (6)의 (ii)에 의해(등호이면 그대로) $0 < (1 + n^{-1}x)^{-1} \le 1$이고, $0 \le n^{-1}x \le n^{-1}$(순서 (4)의 (iii))이므로 [[absolute-value|절댓값]]의 (3), (4), (1)과 순서 (4)의 (iii)에 의해
$$
\begin{aligned}
|v_n'(x) - 1| &= n^{-1}x\,(1 + n^{-1}x)^{-1} \\
&\le n^{-1}
\end{aligned}
$$
이다. [[basic-limits|기본적인 극한]]의 (2)에 의해 $(n^{-1})$은 $0$으로 수렴하므로, 고른 수렴의 항목의 (4)에 의해 도함수의 열 $(v_n')$은 값이 $1$인 상수함수로 고르게 수렴한다.

*한 점에서의 값.* 자연로그의 (1)에 의해 $v_n(0) = n \ln 1 = 0$이므로 실수열 $(v_n(0))$은 $0$으로 수렴한다(기본적인 극한의 (1)).

*결론.* [[uniform-convergence-and-derivative|고른 수렴과 미분]]을 $a = 0$, $b = 1$, $g$는 값이 $1$인 상수함수, $c = 0$, $L = 0$으로 쓴다. 그 (2)의 함수는 [[oriented-integral|방향 있는 적분]]의 (4)에 의해 $f(x) = 0 + \int_0^x 1\,dt = x$, 곧 항등함수이고, 그 (3)에 의해 $(v_n)$은 이 함수로 고르게 수렴한다. 앞에서 모든 $t$에서 $|v_n'(t) - 1| \le n^{-1}$이므로 (3)의 어림을 $\eta = n^{-1}$로 쓰면
$$
\begin{aligned}
|v_n(x) - x| &\le |v_n(0) - 0| \\
&\quad + n^{-1}(1 - 0) \\
&= n^{-1}
\end{aligned}
$$
이다.

**2.** 연속미분가능의 (1)에 의해 $v_n$은 $[0, 1]$에서 리만 적분가능하다. 1과 [[uniform-convergence-and-integral|고른 수렴과 적분]]의 (2)에 의해 $\int_0^1 v_n$은 $\int_0^1 x\,dx$로 수렴하고, [[antiderivative-and-integral-of-power|원시함수와 거듭제곱의 적분]]의 (3)에 의해 그 값은 $(1^2 - 0^2) \cdot 2^{-1} = 2^{-1}$이다.

**3.** *값의 범위.* $x \in [0, 1]$이라 하자. $t = 1 + n^{-1}x$는 $1 \le t$이므로 자연로그의 (1), (3)에 의해 $0 \le \ln t$이고, 자연로그의 (6)에 의해 $\ln t \le t - 1 = n^{-1}x$이다. $0 < n$을 곱하면(순서 (4)의 (iii)) $0 \le v_n(x) \le x \le 1$이다. 그래서 $Y = [0, 1]$에 보통 거리의 부분공간 거리를 주면 $v_n$과 항등함수 $i$는 $[0, 1]$에서 $Y$로의 사상이다. [[metric-space-examples|거리공간의 예]]의 (3)에 의해 $Y$의 거리는 $\mathbb{R}$의 거리와 같은 값이므로, 1에 의해 $(v_n)$은 $Y$로의 사상의 열로서도 $i$로 고르게 수렴한다.

*고르게 연속인 사상.* $\varphi = \exp|_{[0, 1]} : Y \to \mathbb{R}$로 둔다. 지수함수의 (2)와 [[continuous-function|연속함수]]의 (5)에 의해 $\varphi$는 연속함수이고, [[continuous-on-compact-is-uniformly-continuous|콤팩트 거리공간 위의 연속 사상은 고르게 연속이다]]의 (3)에 의해 해석학 입문의 뜻으로 고르게 연속이며, [[uniformly-continuous-map|거리공간 사이의 고르게 연속인 사상]]의 (3)에 의해 거리공간 사이의 사상으로서 고르게 연속이다.

*결론.* 문제 2의 1을 $X = [0, 1]$, $Z = \mathbb{R}$에 쓰면 $n$번째 사상이 $\varphi \circ v_n$인 열은 $\varphi \circ i$로 고르게 수렴한다. $0 < 1 + x n^{-1}$이므로 [[limit-of-compound-interest|복리의 극한]]의 (1)에 의해 $\varphi(v_n(x)) = \exp\bigl(n \ln(1 + x n^{-1})\bigr) = (1 + x n^{-1})^n$이고, $\varphi(i(x)) = \exp(x)$이다. 따라서 $n$번째 사상이 $x$를 $(1 + x n^{-1})^n$으로 보내는 열은 $\exp|_{[0, 1]}$로 고르게 수렴한다. 복리의 극한의 (2)가 점마다 말하는 수렴이 $[0, 1]$ 위에서는 고르다는 것이다.
:::

:::exercise[이웃한 두 항이 고르게 가까운 ln(n + x) 의 열]
$[0, 1]$에서 $\mathbb{R}$(보통 거리)로의 사상의 열 $(w_n)$을 $w_n(x) = \ln(n + x)$로 정한다.

1. 모든 자연수 $n$과 $x \in [0, 1]$에서 $0 < w_{n+1}(x) - w_n(x) \le n^{-1}$임을 보이고, 따라서 모든 양의 실수 $\varepsilon$에 자연수 $N$이 있어 $n \ge N$과 모든 $x \in [0, 1]$에서 $|w_{n+1}(x) - w_n(x)| < \varepsilon$임을 보여라.
2. $(w_n)$이 고르게 코시가 아니고, $[0, 1]$에서 $\mathbb{R}$로의 어떤 사상으로도 고르게 수렴하지 않음을 보여라. 곧 고르게 코시의 정의에서 두 번호 $m$, $k$를 이웃한 두 번호 $n$, $n + 1$로 바꾸면 더 약한 조건이 된다.
:::

:::solution
사상의 열은 [[pointwise-convergence|사상의 열과 점별 수렴]]의 것이고, 고르게 코시는 [[uniformly-cauchy-sequence-of-maps|고르게 코시인 사상의 열]]의 것이며, 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이다. $\mathbb{R}_{>0}$과 $\ln$은 [[natural-logarithm|자연로그]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다. $x \in [0, 1]$이고 $n$이 자연수이면 순서 (10)과 (2)의 (i)에 의해 $0 < n \le n + x$이므로 $n + x \in \mathbb{R}_{>0}$이고, 점별 수렴의 항목의 (1)에 의해 열 $(w_n)$이 있다.

**1.** $t = (n + x)^{-1}$로 두면 순서 (6)의 (i)에 의해 $0 < t$이고, $0 < n \le n + x$이므로 순서 (6)의 (ii)에 의해(등호이면 그대로) $t \le n^{-1}$이다. 계산으로 $(n + 1 + x)(n + x)^{-1} = 1 + t$이므로 [[laws-of-logarithm|로그의 성질]]의 (2)에 의해
$$
w_{n+1}(x) - w_n(x) = \ln(1 + t)
$$
이다. $1 < 1 + t$이므로 자연로그의 (3)에 의해 $0 < \ln(1 + t)$이고, 자연로그의 (6)에 의해 $\ln(1 + t) \le t \le n^{-1}$이다.

양의 실수 $\varepsilon$이 주어지면 [[archimedean-property|아르키메데스 성질]]의 (3)에 의해 자연수 $N$이 있어 $n \ge N$인 모든 자연수 $n$에서 $n^{-1} < \varepsilon$이다. 그런 $n$과 모든 $x$에서 [[absolute-value|절댓값]]의 (1)과 순서 (1)의 (v)에 의해 $|w_{n+1}(x) - w_n(x)| \le n^{-1} < \varepsilon$이다.

**2.** *고르게 코시가 아니다.* $\varepsilon = 1$로 두고 자연수 $N$을 아무것이나 잡는다. [[laws-of-logarithm|로그의 성질]]의 (5)를 $M = \ln N + 1$에 쓰면 양의 실수 $K$가 있어 $K < s$인 모든 $s \in \mathbb{R}_{>0}$에서 $\ln N + 1 < \ln s$이다. 아르키메데스 성질의 (1)에 의해 $K < j$인 자연수 $j$가 있고, $k = j + N$으로 두면 $k$는 자연수이며 $K < j < k$이고 $N < k$이다([[even-and-odd|짝수와 홀수]], [[well-ordering-principle|정렬 원리]]의 (Z6), (Z7), [[prime-number|소수]]의 (Z1), 순서 (10)). 그러면 $m = N$, 이 $k$, 점 $x = 0$에서 $m \ge N$, $k \ge N$이고
$$
\begin{aligned}
|w_k(0) - w_m(0)| &= \ln k - \ln N \\
&> 1
\end{aligned}
$$
이다(순서 (3)의 (i)과 절댓값의 (1)). 곧 $\varepsilon = 1$에 대하여 고르게 코시의 정의의 조건을 만족하는 자연수 $N$이 없으므로 $(w_n)$은 고르게 코시가 아니다.

*고르게 수렴하지 않는다.* $(w_n)$이 어떤 사상으로 고르게 수렴한다면 고르게 코시인 사상의 열의 (1)에 의해 고르게 코시여야 하는데, 앞 문단과 어긋난다. 같은 계산은 점 $0$에서의 값의 수열 $(\ln n)$이 코시 수열이 아니라는 것도 보이므로, [[cauchy-sequence-in-metric-space|거리공간의 코시 수열]]의 (3)에 의해 $(w_n)$은 점 $0$에서 점별로도 수렴하지 않는다. 따라서 1의 조건만으로는 고르게 코시가 되지 않는다.
