:::exercise[f′ = x − f, f(0) = 1 의 피카르 반복열]
$I = [-1, 1]$, $J = [0, 2]$이고 $F(x, y) = x - y$로 정한 $F : I \times J \to \mathbb{R}$, $x_0 = 0$, $y_0 = 1$을 생각한다.

1. $\alpha = 1$, $L = 1$, $M = 3$으로 피카르 정리의 설정이 성립함을 보이고, 피카르 정리의 (1)의 $h_*$를 구하라.
2. $h = h_*$로 두고 피카르 반복열의 둘째 항 $f_2$와 셋째 항 $f_3$을 구하라. $I_0 = [-h_*, h_*]$ 위의 해 $f$에 대하여 $|f_3(x) - f(x)|$를 어림하라.
3. $g(x) = x - 1 + 2\exp(-x)$로 정한 $g : I_0 \to \mathbb{R}$가 2의 해 $f$임을 보여라.
:::

:::solution
닫힌 직사각형 위의 연속함수와 둘째 변수에 대한 립시츠 조건은 [[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 것이고("직사각형 (n)"), 설정과 $h_*$, 해, 피카르 반복열은 [[picard-theorem|피카르의 존재와 유일성 정리]]의 것이다("피카르 정리 (n)"). "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "절댓값 (n)"은 [[absolute-value|절댓값]]의 번호이고, 실수의 계산은 [[real-number-arithmetic|실수의 계산 법칙]]의 것이다.

**1.** *연속.* 직사각형 (2)의 (i)에 의해 값이 $x$인 함수와 값이 $y$인 함수는 연속이고, 직사각형 (2)의 (ii)에 의해 $(-1)y$와 합 $x + (-1)y = x - y$가 차례로 연속이다.

*립시츠.* 모든 $x \in I$와 $y$, $z \in J$에서 $|F(x, y) - F(x, z)| = |z - y| = |y - z|$이므로(절댓값 (3)) $F$는 둘째 변수에 대하여 $1$-립시츠이다(직사각형 (5), $0 \le 1$).

*$M$.* $x \in I$이면 절댓값 (7)에 의해 $|x| \le 1$이고, $y \in J$이면 같은 까닭으로 $|y| \le 2$이다. [[triangle-inequality|삼각부등식]]의 (3)과 순서 (2)의 (iii)에 의해 $|x - y| \le |x| + |y| \le 3$이고 $0 < 3$이다.

*$\alpha$.* $[x_0 - 1, x_0 + 1] = [-1, 1] = I$이고 $[y_0 - 1, y_0 + 1] = [0, 2] = J$이다.

*$h_*$.* $\alpha\,(M + L\alpha)^{-1} = 1 \cdot (3 + 1)^{-1} = 4^{-1}$이고 $4^{-1} < 1$이므로 $h_* = \min\{1, 4^{-1}\} = 4^{-1}$이다(절댓값의 두 수의 최소의 정의). 피카르 정리 (1)에 의해 $h_*$는 두 조건을 만족하고, 실제로 $h_*(M + L\alpha) = 1 = \alpha$이다. 축소 상수는 $Lh_* = 4^{-1}$이다.

**2.** 피카르 정리 (3)에 의해 $f_1$은 값이 $1$인 상수함수이고 $f_{n+1}(x) = 1 + \int_0^x F(t, f_n(t))\,dt$이다. 적분은 [[antiderivative-and-integral-of-power|원시함수와 거듭제곱의 적분]]의 (3)과 [[linearity-of-the-integral|적분의 선형성]]의 (6)으로 계산한다.

$F(t, f_1(t)) = t - 1$이므로
$$
f_2(x) = 1 + \frac{x^2}{2} - x
$$
이다. $F(t, f_2(t)) = t - 1 + t - \frac{t^2}{2} = -1 + 2t - \frac{t^2}{2}$이므로
$$
f_3(x) = 1 - x + x^2 - \frac{x^3}{6}
$$
이다. 피카르 정리 (3)의 (i)을 $n = 3$, $Lh = 4^{-1}$, $Mh = 3 \cdot 4^{-1}$에 쓰면 모든 $x \in I_0$에서
$$
\begin{aligned}
|f_3(x) - f(x)| &\le \frac{(1/4)^2}{3/4} \cdot \frac{3}{4} \\
&= \frac{1}{16}
\end{aligned}
$$
이다.

**3.** $\exp$는 [[exponential-function|지수함수]]의 것이다. 피카르 정리 (2)에 의해 $I_0$ 위의 해는 하나뿐이므로, $g$가 해임을 보이면 $g = f$이다.

*미분.* $y$를 $-y$로 보내는 함수는 미분가능하고 도함수가 $-1$이므로([[derivative|미분계수]]의 (1)), 지수함수의 (3)과 [[chain-rule|연쇄 법칙]]의 (2)에 의해 $x$를 $\exp(-x)$로 보내는 함수는 미분가능하고 도함수는 $-\exp(-x)$이다. [[derivative-rules|미분의 선형성과 곱·몫의 법칙]]의 (6)과 미분계수의 (1), (2)에 의해 $g$는 미분가능하고 $g'(x) = 1 - 2\exp(-x)$이다. 한편 $F(x, g(x)) = x - (x - 1 + 2\exp(-x)) = 1 - 2\exp(-x)$이므로 $g'(x) = F(x, g(x))$이다. 지수함수의 (1)에 의해 $\exp(0) = 1$이므로 $g(0) = -1 + 2 = 1 = y_0$이다.

*값이 $J$에 든다.* 실수 $y$에 대하여 $s = \exp(y)$로 두면 지수함수의 (1)에 의해 $0 < s$이고 $\ln s = y$이므로, [[natural-logarithm|자연로그]]의 (6)의 $\ln s \le s - 1$에서 $1 + y \le \exp(y)$이다. 이것을 (가)라 부른다. $x \in I_0$이면 $-4^{-1} \le x \le 4^{-1}$이다.

- (가)를 $y = -x$에 쓰면 $1 - x \le \exp(-x)$이므로 $g(x) \ge x - 1 + 2 - 2x = 1 - x \ge 3 \cdot 4^{-1} > 0$이다.
- (가)를 $y = x$에 쓰면 $0 < 3 \cdot 4^{-1} \le 1 + x \le \exp(x)$이다. 지수함수의 (5)에 의해 $\exp(-x) = \exp(x)^{-1}$이므로 순서 (6)의 (ii)에 의해(등호이면 그대로) $\exp(-x) \le (1 + x)^{-1} \le 4 \cdot 3^{-1}$이다. 따라서 $g(x) \le 4^{-1} - 1 + 8 \cdot 3^{-1} = 23 \cdot 12^{-1} < 2$이다.

그래서 $g$의 값은 모두 $J = [0, 2]$에 들고, $g$는 $I_0$ 위의 해이다. 따라서 $g = f$이고, 2에 의해 $[-4^{-1}, 4^{-1}]$의 모든 $x$에서 $\bigl|1 - x + x^2 - \frac{x^3}{6} - (x - 1 + 2\exp(-x))\bigr| \le \frac{1}{16}$이다.
:::

:::exercise[둘째 변수에 대한 도함수로 립시츠 상수 찾기]
$I$, $J$가 구간이고 $F : I \times J \to \mathbb{R}$가 함수이며 $L$이 $0 \le L$인 실수이다. 모든 $x \in I$에 대하여 $\varphi_x(y) = F(x, y)$로 정한 $\varphi_x : J \to \mathbb{R}$가 미분가능한 함수이고 모든 $y \in J$에서 $|\varphi_x'(y)| \le L$이라 하자.

1. $F$가 둘째 변수에 대하여 $L$-립시츠임을 보여라.
2. $I = J = \mathbb{R}$이고 $F(x, y) = (1 + y^2)^{-1}$이면 $\varphi_x'(y) = -2y\bigl((1 + y^2)^2\bigr)^{-1}$이고 $|\varphi_x'(y)| \le 1$임을 보여, $F$가 둘째 변수에 대하여 $1$-립시츠임을 보여라.
:::

:::solution
둘째 변수에 대한 $L$-립시츠는 [[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 (5)의 것이다. 미분가능과 도함수는 [[derivative|미분계수]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "절댓값 (n)"은 [[absolute-value|절댓값]]의 번호이다.

**1.** $x \in I$와 $y$, $z \in J$를 잡는다. $y = z$이면 두 변이 모두 $0$이다. $y < z$라 하자. [[interval|구간]]의 (4)에 의해 $[y, z] \subseteq J$이다. [[differentiable-implies-continuous|미분가능하면 연속이다]]의 (2)에 의해 $\varphi_x$는 연속함수이고 [[continuous-function|연속함수]]의 (5)에 의해 그 $[y, z]$로의 제한도 연속함수이며, 미분계수의 (2)에 의해 그 제한은 미분가능하고 미분계수가 $\varphi_x$의 것과 같다. [[mean-value-theorem|평균값 정리]]에 의해 $c \in (y, z)$가 있어 $\varphi_x(z) - \varphi_x(y) = \varphi_x'(c)(z - y)$이다. 절댓값 (4)와 순서 (4)의 (iii)에 의해
$$
\begin{aligned}
|F(x, z) - F(x, y)| &= |\varphi_x'(c)|\,|z - y| \\
&\le L\,|z - y|
\end{aligned}
$$
이다. $z < y$이면 $y$와 $z$의 자리를 바꾸어 같은 부등식을 얻는다(절댓값 (3)). 따라서 $0 \le L$과 함께 $F$는 둘째 변수에 대하여 $L$-립시츠이다.

**2.** *도함수.* $\rho(y) = 1 + y^2$으로 정한 $\rho : \mathbb{R} \to \mathbb{R}$는 미분계수의 (1)과 [[derivative-rules|미분의 선형성과 곱·몫의 법칙]]의 (6)에 의해 미분가능하고 $\rho'(y) = 2y$이다. 순서 (5)의 (iii)에 의해 $1 \le \rho(y)$이므로 $\rho(y) \ne 0$이고, 미분의 선형성과 곱·몫의 법칙의 (6)에 의해 $1/\rho$는 미분가능하며
$$
\varphi_x'(y) = -2y\bigl((1 + y^2)^2\bigr)^{-1}
$$
이다.

*어림.* 순서 (5)의 (iii)에 의해 $0 \le (|y| - 1)^2 = |y|^2 - 2|y| + 1$이고 절댓값 (5)에 의해 $|y|^2 = y^2$이므로 $2|y| \le 1 + y^2$이다. $1 \le 1 + y^2$이므로 순서 (4)의 (iii)에 의해 $1 + y^2 \le (1 + y^2)^2$이고, 순서 (6)의 (ii)에 의해(등호이면 그대로) $\bigl((1 + y^2)^2\bigr)^{-1} \le (1 + y^2)^{-1}$이다. 절댓값 (4), (9)와 순서 (4)의 (iii)에 의해
$$
\begin{aligned}
|\varphi_x'(y)| &= 2|y|\,\bigl((1 + y^2)^2\bigr)^{-1} \\
&\le (1 + y^2)\bigl((1 + y^2)^2\bigr)^{-1} \\
&= (1 + y^2)^{-1} \le 1
\end{aligned}
$$
이다(마지막은 $1 \le 1 + y^2$과 순서 (6)의 (ii)). 1을 $L = 1$에 쓰면 $F$는 둘째 변수에 대하여 $1$-립시츠이다.
:::

:::exercise[F(x, y₀) = 0 인 초깃값 문제의 해]
피카르 정리의 설정($I$, $J$, $F$, $L$, $M$, $x_0$, $y_0$, $\alpha$, $h$)이 성립하고, 모든 $x \in I$에서 $F(x, y_0) = 0$이라 하자. $I_0 = [x_0 - h, x_0 + h]$이다.

1. $I_0$ 위의 해가 값이 $y_0$인 상수함수뿐이고, 피카르 반복열의 모든 항이 그 상수함수임을 보여라.
2. $I = [-1, 1]$, $J = [0, 2]$, $F(x, y) = y(1 - y)$, $x_0 = 0$, $y_0 = 1$에 대하여 $\alpha = 1$, $L = 3$, $M = 2$, $h = 5^{-1}$로 설정이 성립함을 보이고, 1의 결론을 적어라.
3. [[picard-theorem-examples|피카르 정리의 예]]의 (3)의 $F(x, y) = 2\sqrt{|y|}$도 $F(x, 0) = 0$을 만족하지만, $[0, h]$ 위의 해가 둘이다. 1의 가정 가운데 이 $F$에서 성립하지 않는 것을 밝혀라.
:::

:::solution
설정, 해, 피카르 반복열은 [[picard-theorem|피카르의 존재와 유일성 정리]]의 것이고("피카르 정리 (n)"), 피카르 사상 $T$는 [[picard-operator|피카르 사상]]의 것이며, 둘째 변수에 대한 립시츠 조건은 [[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 것이다("직사각형 (n)"). "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "절댓값 (n)"은 [[absolute-value|절댓값]]의 번호이다.

**1.** *상수함수는 해이다.* $\kappa : I_0 \to \mathbb{R}$를 값이 $y_0$인 상수함수라 하자. $0 < \alpha$이므로 $y_0 \in [y_0 - \alpha, y_0 + \alpha] \subseteq J$이고, $\kappa$의 값은 모두 $J$에 든다. [[derivative|미분계수]]의 (1)에 의해 $\kappa$는 미분가능하고 모든 $x$에서 $\kappa'(x) = 0 = F(x, y_0) = F(x, \kappa(x))$이며, $\kappa(x_0) = y_0$이다. 따라서 $\kappa$는 $I_0$ 위의 해이고, 피카르 정리 (2)에 의해 해는 이것뿐이다.

*반복열.* [[oriented-integral|방향 있는 적분]]의 (4)에 의해 $(T\kappa)(x) = y_0 + \int_{x_0}^x F(t, y_0)\,dt = y_0 + \int_{x_0}^x 0\,dt = y_0$이므로 $T\kappa = \kappa$이다. 피카르 정리 (3)에 의해 $f_1 = \kappa$이고 $f_{n+1} = Tf_n$이므로, [[mathematical-induction|수학적 귀납법]]으로 모든 자연수 $n$에서 $f_n = \kappa$이다.

**2.** *연속.* $y(1 - y) = y + (-1)\,y\,y$이므로 직사각형 (2)의 (i), (ii)에 의해 $F$는 연속이다.

*$L = 3$.* $y$, $z \in J$이면 계산으로 $F(x, y) - F(x, z) = (y - z)(1 - y - z)$이다. $0 \le y + z \le 4$이므로 $-3 \le 1 - (y + z) \le 1$이고 절댓값 (7)에 의해 $|1 - y - z| \le 3$이다. 절댓값 (4)와 순서 (4)의 (iii)에 의해 $|F(x, y) - F(x, z)| \le 3|y - z|$이다.

*$M = 2$.* $y \in J$이면 $-1 \le 1 - y \le 1$이므로 $|1 - y| \le 1$이고, $|y| \le 2$이므로 순서 (11)의 (i)에 의해 $|F(x, y)| = |y|\,|1 - y| \le 2$이다. $0 < 2$이다.

*$\alpha$와 $h$.* $[x_0 - 1, x_0 + 1] = I$, $[y_0 - 1, y_0 + 1] = J$이다. $0 < 5^{-1} \le 1$이고 $5^{-1}(2 + 3 \cdot 1) = 1 \le 1$이다.

*결론.* $F(x, 1) = 1 \cdot 0 = 0$이므로 1에 의해 $[-5^{-1}, 5^{-1}]$ 위에서 초깃값 문제 $y' = y(1 - y)$, $y(0) = 1$의 해는 값이 $1$인 상수함수 하나뿐이다.

**3.** 피카르 정리의 예의 (3)의 (i)에 의해 $F(x, y) = 2\sqrt{|y|}$는 연속이고 $\alpha = 1$, $M = 2$는 설정의 $\alpha$, $M$에 관한 조건을 만족하지만, $F$는 둘째 변수에 대하여 립시츠가 아니다. 그래서 피카르 정리의 설정이 성립하지 않고 1을 쓸 수 없다. 성립하지 않는 가정은 둘째 변수에 대한 립시츠 조건이다. 그 (3)의 (ii)에 의해 $[0, h]$ 위에서는 값이 $0$인 상수함수 밖에 $x^2$으로 정한 해도 있다. 립시츠 조건이 빠지면 "$y_0$에서 출발한 해는 상수함수뿐"이라는 결론이 이렇게 깨질 수 있다.
:::

:::exercise[f′ = (1 + f²)⁻¹ 의 해가 있는 구간]
$y_0$이 실수이고 $h$가 $0 < h < 1$인 실수이다. $\alpha = h(1 - h)^{-1}$, $I = [-\alpha, \alpha]$, $J = [y_0 - \alpha, y_0 + \alpha]$로 두고 $F(x, y) = (1 + y^2)^{-1}$로 정한 $F : I \times J \to \mathbb{R}$와 $x_0 = 0$을 생각한다.

1. $L = 1$, $M = 1$과 이 $\alpha$, $h$로 피카르 정리의 설정이 성립함을 보여라.
2. $[-h, h]$ 위에서 초깃값 문제 $y' = (1 + y^2)^{-1}$, $y(0) = y_0$의 해가 정확히 하나 있음을 보이고, 피카르 반복열의 둘째 항을 구하라.
3. 2의 해가 순증가임을 보여라.
:::

:::solution
둘째 변수에 대한 립시츠 조건과 연속은 [[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 것이고("직사각형 (n)"), 설정, 해, 피카르 반복열은 [[picard-theorem|피카르의 존재와 유일성 정리]]의 것이다("피카르 정리 (n)"). "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이고, 실수의 계산은 [[real-number-arithmetic|실수의 계산 법칙]]의 것이다.

**1.** *$\alpha$와 $h$.* $h < 1$이므로 순서 (3)의 (i)에 의해 $0 < 1 - h$이고, $0 < h$이므로 순서 (3)의 (ii)와 (2)의 (ii)에 의해 $1 - h < 1$이다. 순서 (6)의 (i), (ii)에 의해(등호이면 그대로) $0 < (1 - h)^{-1}$이고 $1 \le (1 - h)^{-1}$이므로, $0 < h$를 곱하면(순서 (4)의 (i), (iii)) $0 < \alpha$이고 $h \le \alpha$이다. $I$와 $J$는 닫힌구간이고 $[x_0 - \alpha, x_0 + \alpha] = I$, $[y_0 - \alpha, y_0 + \alpha] = J$이다.

*연속.* $r(y) = (1 + y^2)^{-1}$로 정한 $r : J \to \mathbb{R}$는 [[power-function-is-continuous|거듭제곱 함수의 연속]]의 (1), [[continuous-function|연속함수]]의 (4), (5), [[continuity-of-sum-and-product|연속함수의 합과 곱]]의 (3)($1 + y^2$은 $0$이 아니다)에 의해 연속함수이므로, 직사각형 (2)의 (i)에 의해 $F$는 연속이다.

*$L = 1$.* 문제 2의 2에 의해 $\mathbb{R} \times \mathbb{R}$ 위의 $(1 + y^2)^{-1}$은 둘째 변수에 대하여 $1$-립시츠이고, 직사각형 (5)의 (iv)에 의해 그 $I \times J$로의 제한 $F$도 그렇다.

*$M = 1$.* 순서 (5)의 (iii)에 의해 $1 \le 1 + y^2$이므로 순서 (6)의 (i), (ii)에 의해 $0 < F(x, y) \le 1$이고 $|F(x, y)| \le 1$이다. $0 < 1$이다.

*마지막 조건.* 계산으로
$$
\begin{aligned}
&h\,(M + L\alpha) \\
&\quad = h\bigl(1 + h(1 - h)^{-1}\bigr) \\
&\quad = h\bigl((1 - h) + h\bigr)(1 - h)^{-1} \\
&\quad = h(1 - h)^{-1} = \alpha
\end{aligned}
$$
이므로 $h\,(M + L\alpha) \le \alpha$이다.

**2.** 1과 피카르 정리 (2)에 의해 $[-h, h]$ 위의 해, 곧 값이 모두 $J$에 들고 미분가능하며 $f'(x) = (1 + f(x)^2)^{-1}$, $f(0) = y_0$인 실함수 $f$가 정확히 하나 있다. 피카르 정리 (3)에 의해 $f_1$은 값이 $y_0$인 상수함수이고, [[oriented-integral|방향 있는 적분]]의 (4)에 의해
$$
\begin{aligned}
f_2(x) &= y_0 + \int_0^x (1 + y_0^2)^{-1}\,dt \\
&= y_0 + x\,(1 + y_0^2)^{-1}
\end{aligned}
$$
이다.

**3.** 모든 $x \in [-h, h]$에서 1의 $M$의 계산에 의해 $f'(x) = (1 + f(x)^2)^{-1} > 0$이다. [[derivative-and-monotonicity|도함수와 증가·감소]]의 (4)에 의해 $f$는 순증가이다.

$0 < h < 1$이 아무 수였으므로, 이 방정식에서는 $1$보다 작은 어떤 반지름 $h$에도 $[-h, h]$ 위의 해가 있다. $\alpha$를 크게 잡을수록 $h = \alpha(1 + \alpha)^{-1}$이 $1$에 가까워진다.
:::

:::exercise[피카르 반복열의 도함수]
피카르 정리의 설정($I$, $J$, $F$, $L$, $M$, $x_0$, $y_0$, $\alpha$, $h$)이 성립하고, $f$가 $I_0 = [x_0 - h, x_0 + h]$ 위의 해이며, $(f_n)$이 피카르 반복열이라 하자.

1. 모든 자연수 $n$에서 $f_{n+1}$이 연속미분가능하고, 모든 $x \in I_0$에서
   $$
   \begin{aligned}
   &|f_{n+1}'(x) - f'(x)| \\
   &\quad \le L\,|f_n(x) - f(x)| \\
   &\quad \le L \cdot \frac{(Lh)^{n-1}}{1 - Lh}\,Mh
   \end{aligned}
   $$
   임을 보여라.
2. $n$번째 사상이 $f_{n+1}'$인 $I_0$에서 $\mathbb{R}$로의 사상의 열이 $f'$으로 고르게 수렴함을 보여라.
3. 문제 1의 방정식에서 $f_3'$을 구해 $f_3'(x) = x - f_2(x)$임을 확인하고, $[-4^{-1}, 4^{-1}]$ 위에서 $|f_3'(x) - f'(x)|$를 1로 어림하라.
:::

:::solution
설정, 해, 피카르 반복열은 [[picard-theorem|피카르의 존재와 유일성 정리]]의 것이고("피카르 정리 (n)"), $Z$, $G_f$, 피카르 사상 $T$는 [[picard-operator|피카르 사상]]의 것이다("피카르 사상 (n)"). 연속미분가능은 [[continuously-differentiable|연속미분가능]]의 것이고, 고른 수렴은 [[uniform-convergence|고른 수렴]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호이다.

**1.** 피카르 정리 (3)에 의해 $f_n \in Z$이고 $f_{n+1} = Tf_n$이다. 피카르 사상 (1)에 의해 $f_{n+1}$은 연속미분가능하고 $f_{n+1}' = G_{f_n}$, 곧 모든 $x \in I_0$에서 $f_{n+1}'(x) = F(x, f_n(x))$이다. $f$는 해이므로 $f'(x) = F(x, f(x))$이다. $f_n(x)$와 $f(x)$는 $J$에 들므로(피카르 사상의 $Z$의 정의와 해의 정의) 둘째 변수에 대한 $L$-립시츠 조건([[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 (5))에 의해
$$
|f_{n+1}'(x) - f'(x)| \le L\,|f_n(x) - f(x)|
$$
이다. 피카르 정리 (3)의 (i)과 $0 \le L$, 순서 (4)의 (iii)에 의해 둘째 부등식이 나온다.

**2.** 각 $n$에서 $f_{n+1}'$은 이미 정해진 함수이므로 [[pointwise-convergence|사상의 열과 점별 수렴]]의 (1)에 의해 이 열이 있다. $c = Lh$로 두면 피카르 사상 (3)에 의해 $0 \le c < 1$이고 [[absolute-value|절댓값]]의 (1)에 의해 $|c| < 1$이다. $n$번째 항이 $c^{n-1}$인 실수열의 $1$-꼬리는 $n$번째 항이 $c^n$인 수열이고, 이것은 [[geometric-sequence-limit|등비수열의 극한]]의 (1)에 의해 $0$으로 수렴하므로, [[tail-of-a-sequence|수열의 꼬리]]의 (1)에 의해 $(c^{n-1})$도 $0$으로 수렴한다. [[limit-of-sum-and-product|수열의 합과 곱의 극한]]의 (5)에 의해 $n$번째 항이 $a_n = L(1 - c)^{-1}Mh \cdot c^{n-1}$인 실수열은 $0$으로 수렴한다. 1에 의해 모든 $n$과 $x$에서 $|f_{n+1}'(x) - f'(x)| \le a_n$이므로, 고른 수렴의 (8)과 (4)($K = 1$)에 의해 이 열은 $f'$으로 고르게 수렴한다.

**3.** 문제 1에서 $L = 1$, $M = 3$, $h = 4^{-1}$이고 $f_2(x) = 1 - x + \frac{x^2}{2}$, $f_3(x) = 1 - x + x^2 - \frac{x^3}{6}$이다. 연속미분가능의 (3), (4)에 의해
$$
f_3'(x) = -1 + 2x - \frac{x^2}{2}
$$
이고, $x - f_2(x) = x - 1 + x - \frac{x^2}{2}$과 같다. 1을 $n = 2$에 쓰면 모든 $x \in [-4^{-1}, 4^{-1}]$에서
$$
\begin{aligned}
|f_3'(x) - f'(x)| &\le 1 \cdot \frac{1/4}{3/4} \cdot \frac{3}{4} \\
&= \frac{1}{4}
\end{aligned}
$$
이다. 문제 1의 3에 의해 $f'(x) = 1 - 2\exp(-x)$이다.
:::

:::exercise[연속이 아닌 F 의 초깃값 문제에서 해가 없는 예]
$I = J = [-1, 1]$이고, $x < 0$이면 $F(x, y) = 0$, $0 \le x$이면 $F(x, y) = 1$로 정한 $F : I \times J \to \mathbb{R}$를 생각한다. $0 < h \le 1$인 실수 $h$에 대하여, 다음 셋을 만족하는 실함수 $f : [-h, h] \to \mathbb{R}$를 이 문제에서 "$[-h, h]$ 위의 해"라 부른다: 모든 $x$에서 $f(x) \in J$이다; $f$는 미분가능하고 모든 $x$에서 $f'(x) = F(x, f(x))$이다; $f(0) = 0$이다.

1. $F$가 둘째 변수에 대하여 $0$-립시츠이고 $|F| \le 1$이며, $\alpha = 1$, $L = 0$, $M = 1$, $x_0 = y_0 = 0$과 모든 $h \in (0, 1]$이 피카르 정리의 설정의 부등식을 만족함을 보여라.
2. 모든 $h \in (0, 1]$에 대하여 $[-h, h]$ 위의 해가 없음을 보여라.
3. $[0, h]$ 위에서는 같은 세 조건을 만족하는 함수가 있음을 보이고, 피카르 정리로부터 $F$가 직사각형 위의 연속함수가 아님을 이끌어라.
:::

:::solution
둘째 변수에 대한 립시츠 조건과 직사각형 위의 연속함수는 [[continuous-function-on-a-rectangle|닫힌 직사각형 위의 연속함수]]의 것이고, 피카르 정리의 설정은 [[picard-theorem|피카르의 존재와 유일성 정리]]의 것이다. 미분가능, 미분계수, 차분몫 $q_c$는 [[derivative|미분계수]]의 것이고, 함수의 수렴은 [[limit-of-a-function|함수의 극한]]의 것이다. "순서 (n)"은 [[order-properties-of-reals|실수의 순서의 성질]]의 번호, "절댓값 (n)"은 [[absolute-value|절댓값]]의 번호이다. 순서 (1)의 (iii)에 의해 각 $x$는 $x < 0$과 $0 \le x$ 가운데 정확히 하나에 들므로 $F$가 정해진다.

**1.** 모든 $x$와 $y$, $z \in J$에서 $F(x, y) = F(x, z)$이므로 $|F(x, y) - F(x, z)| = 0 = 0 \cdot |y - z|$이고, $F$는 둘째 변수에 대하여 $0$-립시츠이다. $F$의 값은 $0$이나 $1$이므로 $|F| \le 1$이다. $[0 - 1, 0 + 1] = I$, $[0 - 1, 0 + 1] = J$이고, $0 < h \le 1 = \alpha$이며 $h\,(1 + 0 \cdot 1) = h \le 1$이다. 피카르 정리의 설정 가운데 $F$의 연속만 확인하지 않았다.

**2.** $h \in (0, 1]$이고 $f$가 $[-h, h]$ 위의 해라고 하자.

*$x_0$의 왼쪽에서 $f$는 $0$이다.* $-h \le x < 0$이라 하자. [[differentiable-implies-continuous|미분가능하면 연속이다]]의 (2)에 의해 $f$는 연속함수이고 [[continuous-function|연속함수]]의 (5)에 의해 그 $[x, 0]$으로의 제한도 연속이며, 미분계수의 (2)에 의해 그 제한은 미분가능하고 미분계수가 $f$의 것과 같다. [[mean-value-theorem|평균값 정리]]에 의해 $c \in (x, 0)$이 있어 $f(0) - f(x) = f'(c)(0 - x)$이다. $c < 0$이므로 $f'(c) = F(c, f(c)) = 0$이고, 따라서 $f(x) = f(0) = 0$이다.

*$0$에서의 미분계수.* $f'(0) = F(0, f(0)) = 1$이므로, 미분계수의 정의에 의해 차분몫 $q_0$은 $0$에서 $1$로 수렴한다. 함수의 극한의 정의를 $\varepsilon = 2^{-1}$에 쓰면 양의 실수 $\delta$가 있어 $x \in [-h, h]$, $x \ne 0$, $|x| < \delta$인 모든 $x$에서 $|q_0(x) - 1| < 2^{-1}$이다. 절댓값 (10)에 의해 $m = \min\{\delta, h\}$는 양수이고 $\delta$ 이하, $h$ 이하이므로 $x_1 = -2^{-1}m$은 순서 (8)과 (3)의 (ii), (iii)에 의해 $-h < x_1 < 0$이고 $|x_1| = 2^{-1}m < \delta$이다(절댓값 (1), (3)). 앞 문단에 의해 $f(x_1) = 0 = f(0)$이므로 $q_0(x_1) = (f(x_1) - f(0))(x_1 - 0)^{-1} = 0$이고 $|q_0(x_1) - 1| = 1 \ge 2^{-1}$이다. 이것은 $\delta$의 성질과 어긋난다. 따라서 $[-h, h]$ 위의 해는 없다.

**3.** $u(x) = x$로 정한 $u : [0, h] \to \mathbb{R}$는 값이 $[0, h] \subseteq J$에 들고, 미분계수의 (1)에 의해 미분가능하며 모든 $x \in [0, h]$에서 $u'(x) = 1 = F(x, u(x))$이고($0 \le x$), $u(0) = 0$이다. 그래서 $x_0 = 0$의 오른쪽에서만 보면 세 조건을 만족하는 함수가 있다.

$F$가 직사각형 위의 연속함수라고 하자. 그러면 1에 의해 피카르 정리의 설정이 모두 성립하고, 피카르 정리의 (2)에 의해 $[-h, h]$ 위의 해(값이 $J$에 들고 미분가능하며 $f' = F(x, f)$, $f(0) = 0$인 함수)가 있어야 한다. 이것은 2와 어긋나므로 $F$는 연속이 아니다. 둘째 변수에 대한 립시츠 조건과 $|F| \le M$만으로는 해가 있다는 결론이 깨질 수 있다.
:::
