:::exercise[정수 위의 새 두 연산]
정수 $a$, $b$에 대하여
$$
\begin{aligned}
a \oplus b &= a + b - 1, \\
a \odot b &= a + b - ab
\end{aligned}
$$
로 정하자. 오른쪽은 정수의 덧셈, 뺄셈, 곱셈이다.

1. $R = (\mathbb{Z}, \oplus, \odot)$가 단위원을 갖는 가환환임을 보이고, 이 환의 $0_R$과 단위원 $1_R$이 각각 어떤 정수인지 구하라.
2. $R$이 정역임을 보여라.
3. $R$의 가역원을 모두 구하고, $R$이 체가 아님을 보여라.
:::

:::solution
정수의 덧셈과 곱셈의 교환법칙, 결합법칙, 분배법칙과 구체적인 계산은 [[well-ordering-principle|정렬 원리]]의 진술에서 받아들인 계산으로 쓴다. 정수끼리의 합, 차, 곱은 정수이므로([[even-and-odd|짝수와 홀수]]에서 받아들인 사실) 각 $(a, b) \in \mathbb{Z} \times \mathbb{Z}$에 정수 $a \oplus b$와 $a \odot b$가 하나씩 정해지고, [[recursion-theorem|재귀 정리]]의 (1)에 의해 $\oplus$와 $\odot$은 $\mathbb{Z}$ 위의 [[binary-operation|이항연산]]이다.

**(1)** *덧셈.* 정수 $a$, $b$, $c$에 대하여 $(a \oplus b) \oplus c = (a + b - 1) + c - 1 = a + b + c - 2$이고 $a \oplus (b \oplus c) = a + (b + c - 1) - 1 = a + b + c - 2$이므로 결합법칙이 성립한다. $a \oplus b = a + b - 1 = b \oplus a$이므로 교환법칙이 성립한다. $a \oplus 1 = a + 1 - 1 = a$이고 $1 \oplus a = a$이므로 정수 $1$이 $\oplus$의 항등원이다. $a \oplus (2 - a) = a + (2 - a) - 1 = 1$이고 교환법칙에 의해 $(2 - a) \oplus a = 1$이므로 $2 - a$가 $a$의 역원이다. [[group|군]]의 정의에 의해 $(\mathbb{Z}, \oplus)$는 아벨군이고, 그 항등원 $0_R$은 정수 $1$이다.

*곱셈.* $a \odot b = a + b - ab = b + a - ba = b \odot a$이므로 $\odot$은 교환법칙을 만족한다. 결합법칙은
$$
\begin{aligned}
&(a \odot b) \odot c \\
&\quad = (a + b - ab) + c \\
&\qquad - (a + b - ab)c \\
&\quad = a + b + c - ab \\
&\qquad - ac - bc + abc, \\
&a \odot (b \odot c) \\
&\quad = a + (b + c - bc) \\
&\qquad - a(b + c - bc) \\
&\quad = a + b + c - ab \\
&\qquad - ac - bc + abc
\end{aligned}
$$
에서 나온다. 분배법칙은
$$
\begin{aligned}
&a \odot (b \oplus c) \\
&\quad = a + (b + c - 1) \\
&\qquad - a(b + c - 1) \\
&\quad = 2a + b + c - ab - ac - 1, \\
&(a \odot b) \oplus (a \odot c) \\
&\quad = (a + b - ab) \\
&\qquad + (a + c - ac) - 1 \\
&\quad = 2a + b + c - ab - ac - 1
\end{aligned}
$$
이므로 $a \odot (b \oplus c) = (a \odot b) \oplus (a \odot c)$이고, 교환법칙을 쓰면 $(a \oplus b) \odot c = c \odot (a \oplus b) = (c \odot a) \oplus (c \odot b) = (a \odot c) \oplus (b \odot c)$이다. [[ring|환]]의 정의에 의해 $R$은 환이고 가환환이다.

*단위원.* $a \odot 0 = a + 0 - a \cdot 0 = a$이고 교환법칙에 의해 $0 \odot a = a$이므로 정수 $0$이 곱셈의 항등원이다. 정렬 원리의 (L3)에 의해 정수 $0$은 $0_R = 1$과 다르므로, 환의 정의에 의해 $R$은 단위원을 갖는 환이고 $1_R$은 정수 $0$이다.

**(2)** 정수 $a$, $b$에 대하여 $(1 - a)(1 - b) = 1 - a - b + ab = -(a \odot b - 1)$이다. $a \odot b = 0_R$, 곧 $a \odot b = 1$이면 $(1 - a)(1 - b) = 0$이고, [[integer-cancellation|정수 곱셈의 소거 법칙]]의 (1)에 의해 $1 - a = 0$이거나 $1 - b = 0$, 곧 $a = 0_R$이거나 $b = 0_R$이다. $R$은 단위원을 갖는 가환환이므로 [[integral-domain|영인자와 정역]]의 정의에 의해 정역이다.

**(3)** $R^{\times} = \{0, 2\}$이다(정수 $0$과 $2$). 가역원의 뜻은 [[field|가역원과 체]]의 정의이다. $a$가 가역원이면 $a \odot b = 1_R = 0$인 정수 $b$가 있다. $(1 - a)(1 - b) = 1 - (a + b - ab) = 1 - a \odot b = 1$이고 정수의 곱셈은 가환이므로, $1 - a$는 [[ring-examples|환의 예]]의 (1)의 환 $\mathbb{Z}$의 가역원이다. 가역원과 체의 (2)(i)에 의해 $\mathbb{Z}^{\times} = \{1, -1\}$이므로 $1 - a = 1$이거나 $1 - a = -1$, 곧 $a = 0$이거나 $a = 2$이다. 거꾸로 $0 \odot 0 = 0$이고 $2 \odot 2 = 2 + 2 - 4 = 0$이므로 $0$과 $2$는 가역원이다.

정수 $3$은 $0_R = 1$과 다르지만 $0$도 $2$도 아니므로 가역원이 아니다. 따라서 체의 정의에 의해 $R$은 체가 아니다. 이 환에서 정수 $1$이 영의 자리를, 정수 $0$이 단위원의 자리를 맡아, 환 $\mathbb{Z}$의 $0$, $1$, $\{1, -1\}$과 같은 모양의 성질이 나온다.
:::

:::exercise[제곱이 0인 원소와 가역원]
$R$이 단위원 $1$을 갖는 환이고 $a \in R$이 $aa = 0$을 만족한다고 하자.

1. $1 + a$와 $1 - a$가 가역원이고 $(1 + a)^{-1} = 1 - a$임을 보여라. ($R$이 가환환이라고 가정하지 않는다.)
2. $\mathbb{Z}_{12}$에서 $[7]$이 가역원임을 1로 보이고 그 역원을 구하라.
:::

:::solution
**(1)** [[ring|환]]의 오른쪽 분배법칙과 [[ring-basic-properties|환의 기본 성질]]의 (4)에 의해
$$
\begin{aligned}
&(1 + a)(1 - a) \\
&\quad = 1(1 - a) + a(1 - a) \\
&\quad = (1 - a) + (a1 - aa) \\
&\quad = (1 - a) + (a - 0) \\
&\quad = (1 - a) + a
\end{aligned}
$$
이고, 덧셈군 $(R, +)$에서 결합법칙과 교환법칙을 쓰면 $(1 - a) + a = 1 + ((-a) + a) = 1 + 0 = 1$이다. 같은 방법으로 환의 기본 성질의 (4)의 둘째 등식과 왼쪽 분배법칙에 의해
$$
\begin{aligned}
&(1 - a)(1 + a) \\
&\quad = 1(1 + a) - a(1 + a) \\
&\quad = (1 + a) - (a1 + aa) \\
&\quad = (1 + a) - (a + 0) \\
&\quad = (1 + a) - a = 1
\end{aligned}
$$
이다. 따라서 [[field|가역원과 체]]의 가역원의 정의에 의해 $1 + a$는 가역원이고 그 역원은 $1 - a$이다. 같은 두 등식은 $1 - a$가 가역원이고 그 역원이 $1 + a$라는 것도 보여 준다.

**(2)** [[ring-examples|환의 예]]의 (3)에 의해 $\mathbb{Z}_{12}$는 단위원 $[1]$을 갖는 환이다. [[integers-modulo-n|법 n의 정수]]의 (2)에 의해 $[6][6] = [36]$이고 $36 - 0 = 12 \cdot 3$이므로 [[congruence-modulo-n|합동]]과 [[equivalence-classes-equal-iff-related|두 동치류가 같을 조건]]에 의해 $[6][6] = [0]$이다. $[1] + [6] = [7]$이므로 (1)에 의해 $[7]$은 가역원이고, 역원은 $[1] - [6] = [-5]$이다. $7 - (-5) = 12$이므로 $[-5] = [7]$이다. 확인하면 $[7][7] = [49]$이고 $49 - 1 = 12 \cdot 4$이므로 $[7][7] = [1]$이다.
:::

:::exercise[정역에서 제곱이 같은 두 원소]
1. $R$이 정역이고 $a, b \in R$이라 하자. $aa = bb$인 것은 정확히 $a = b$이거나 $a = -b$일 때임을 보여라.
2. $p$가 소수이면, $\mathbb{Z}_p$에서 $[x][x] = [1]$인 것은 정확히 $[x] = [1]$이거나 $[x] = [p - 1]$일 때임을 보여라.
3. $\mathbb{Z}_8$에서는 1의 결론이 깨지는 $a$, $b$가 있음을 보이고, 그 까닭을 설명하라.
:::

:::solution
**(1)** $R$은 가환환이다([[integral-domain|영인자와 정역]]의 정의). [[ring|환]]의 왼쪽 분배법칙과 [[ring-basic-properties|환의 기본 성질]]의 (4)에 의해
$$
\begin{aligned}
&(a - b)(a + b) \\
&\quad = (a - b)a + (a - b)b \\
&\quad = (aa - ba) + (ab - bb)
\end{aligned}
$$
이고, $ba = ab$이므로 덧셈군의 결합법칙과 $(-(ab)) + ab = 0$으로 정리하면 $(a - b)(a + b) = aa - bb$이다. $aa = bb$이면 $aa - bb = 0$이므로 $(a - b)(a + b) = 0$이고, 정역의 정의에 의해 $a - b = 0$이거나 $a + b = 0$이다. 앞의 것은 $a = b$, 뒤의 것은 덧셈군에서 $a = -b$이다([[group-basic-properties|군의 기본 성질]]의 (3)의 덧셈판). 거꾸로 $a = b$이면 $aa = bb$이고, $a = -b$이면 환의 기본 성질의 (3)에 의해 $aa = (-b)(-b) = bb$이다.

**(2)** 영인자와 정역의 (3)(ii)에 의해 $\mathbb{Z}_p$는 정역이고, 단위원은 $[1]$이다. $[x][x] = [1] = [1][1]$이므로 (1)에 의해 $[x][x] = [1]$인 것은 정확히 $[x] = [1]$이거나 $[x] = -[1]$일 때이다. [[integers-modulo-n|법 n의 정수]]의 (4)에 의해 $-[1] = [-1] = [p - 1]$이다. ($p = 2$이면 $[p - 1] = [1]$이므로 해는 $[1]$ 하나이다.)

**(3)** $a = [3]$, $b = [1]$로 두면 $[3][3] = [9]$이고 $9 - 1 = 8$이므로 $[3][3] = [1] = [1][1]$이다([[congruence-modulo-n|합동]], [[equivalence-classes-equal-iff-related|두 동치류가 같을 조건]]). 그런데 법 n의 정수의 (1)에 의해 $[3] \ne [1]$이고, $-[1] = [7] \ne [3]$이다. 곧 1의 결론이 깨진다. 까닭은 $\mathbb{Z}_8$이 정역이 아니라는 데 있다($8 = 2 \cdot 4$이므로 영인자와 정역의 (3)(i)). 1의 풀이의 등식은 가환환에서 성립하므로 $([3] - [1])([3] + [1]) = [2][4] = [8] = [0]$인데, $[2]$와 $[4]$가 모두 $[0]$이 아니어서 두 인수 가운데 하나가 $[0]$이라는 결론을 끌어낼 수 없다.
:::

:::exercise[정역의 부분환의 단위원]
$R$이 정역이고 $S$가 $R$의 부분환이라 하자.

1. 환 $S$가 단위원 $e$를 갖는 환이면 $e = 1$임을 보여라. 여기서 $1$은 $R$의 단위원이다.
2. 1의 경우 $S$는 정역임을 보여라.
:::

:::solution
**(1)** $e$는 $S$의 곱셈의 항등원이고 $e \in S$이므로 $ee = e$이다. [[subring|부분환]]의 (1)에 의해 환 $S$에서의 곱 $ee$는 $R$에서의 곱과 같으므로, $R$에서도 $ee = e$이다. [[integral-domain|영인자와 정역]]의 (5)에 의해 $e = 0$이거나 $e = 1$이다. 단위원을 갖는 환의 정의([[ring|환]])에 의해 $e$는 환 $S$의 $0$과 다르고, 부분환의 (1)에 의해 환 $S$의 $0$은 $R$의 $0$이므로 $e \ne 0$이다. 따라서 $e = 1$이다.

**(2)** (1)에 의해 $1 = e \in S$이므로, 영인자와 정역의 (4)에 의해 $S$는 정역이다.

정역이라는 가정은 뺄 수 없다. 정역이 아닌 $\mathbb{Z}_6$([[integral-domain|영인자와 정역]]의 (3)(i))에서는 부분환의 (5)(iii)에 의해 $\{[0], [3]\}$이 단위원 $[3]$을 갖는 부분환이고 $[3] \ne [1]$이다.
:::

:::exercise[체의 유한 부분환]
$F$가 체이고 $S$가 $1 \in S$인 $F$의 부분환이라 하자.

1. $S$가 유한집합이면 $S$는 체임을 보여라. 또 $0$이 아닌 $a \in S$의 $S$에서의 역원은 $F$에서의 역원 $a^{-1}$과 같음을 보여라.
2. 1에서 $1 \in S$라는 가정을 빼면 결론이 깨지는 예와, $S$가 유한집합이라는 가정을 빼면 결론이 깨지는 예를 들어라.
:::

:::solution
**(1)** [[field|가역원과 체]]의 (3)에 의해 $F$는 정역이고, [[integral-domain|영인자와 정역]]의 (4)에 의해 $1$을 포함하는 그 부분환 $S$는 정역이다. $S$가 유한집합이므로 [[finite-integral-domain-is-a-field|유한 정역은 체이다]]의 (1)에 의해 $S$는 체이다.

$1 \in S$이고 $S$의 모든 원소 $x$에서 $1x = x = x1$이며 $1 \ne 0$이므로, 환 $S$의 단위원은 $1$이다. $a \in S$이고 $a \ne 0$이라 하자([[subring|부분환]]의 (1)에 의해 환 $S$의 $0$은 $F$의 $0$이다). $S$가 체이므로 $S$에서 $ab = 1$이고 $ba = 1$인 $b \in S$가 있다. 부분환의 (1)에 의해 이 곱은 $F$에서의 곱이므로 $F$에서도 $ab = 1 = ba$이고, 가역원과 체의 정의에서 그런 원소는 하나뿐이므로 $b = a^{-1}$이다.

**(2)** *$1 \in S$를 뺀 경우.* 부분환의 (3)(i)에 의해 $\{0\}$은 $F$의 부분환이고 유한집합이지만, [[ring|환]]의 (1)에 의해 영환이므로 가역원과 체의 끝 문장대로 체가 아니다.

*유한을 뺀 경우.* [[ring-examples|환의 예]]의 (2)와 가역원과 체의 (4)에 의해 $\mathbb{R}$은 체이고, 부분환의 (4)에 의해 $\mathbb{Z}$는 $1$을 포함하는 $\mathbb{R}$의 부분환이지만, 가역원과 체의 (6)에 의해 $\mathbb{Z}$는 체가 아니다.
:::

:::exercise[유한 가환환의 0이 아닌 원소]
$R$이 단위원을 갖는 가환환이라 하자.

1. $R$이 유한집합이면, $0$이 아닌 $R$의 모든 원소는 가역원이거나 영인자이고, 둘 다인 원소는 없음을 보여라.
2. $R$이 유한집합이라는 가정을 빼면 1의 결론이 깨지는 예를 들어라.
:::

:::solution
**(1)** *둘 다인 원소는 없다.* [[field|가역원과 체]]의 (3)에 의해 가환환의 가역원은 영인자가 아니다.

*어느 하나이다.* $a \in R$이고 $a \ne 0$이며 $a$가 영인자가 아니라고 하자. $a$가 가역원임을 보이면 된다. 각 $x \in R$에 $R$의 원소 $ax$가 정해져 있으므로 [[recursion-theorem|재귀 정리]]의 (1)에 의해 $f(x) = ax$인 [[function|함수]] $f : R \to R$가 있다. $f(x) = f(y)$이면 [[ring-basic-properties|환의 기본 성질]]의 (4)에 의해 $a(x - y) = ax - ay = 0$이다. $x - y \ne 0$이라면 [[integral-domain|영인자와 정역]]의 정의에 의해 $a$가 영인자가 되어 가정에 어긋나므로 $x - y = 0$, 곧 $x = y$이다. 따라서 $f$는 [[injective-surjective-bijective|단사]]이다.

$T = \{ax : x \in R\}$라 하면 $T \subseteq R$이고, $f$는 $R$에서 $T$로의 함수로 선언해도 단사이다(함수의 진술과 단사의 정의는 집합 $f$와 정의역만으로 정해진다). $T \ne R$이라면, $R$이 유한집합이므로 [[subset-of-finite-set|유한집합의 부분집합]]의 (3)에 의해 $R$에서 $T$로의 단사가 없어야 하는데 $f$가 그런 단사이므로 모순이다. 따라서 $T = R$이고 $1 \in T$이므로 $ax = 1$인 $x \in R$이 있다. $R$이 가환환이므로 $xa = 1$이기도 하고, 가역원과 체의 정의에 의해 $a$는 가역원이다.

**(2)** [[ring-examples|환의 예]]의 (1)의 환 $\mathbb{Z}$는 단위원을 갖는 가환환이다. 정수 $2$는 $0$이 아니고, 가역원과 체의 (2)(i)에 의해 $\mathbb{Z}^{\times} = \{1, -1\}$이므로 가역원이 아니다. 영인자와 정역의 (2)에 의해 $\mathbb{Z}$는 정역이므로 영인자가 없고, $2$는 영인자도 아니다. $\mathbb{Z}$가 유한집합이 아니라는 것도 여기서 나온다. 유한집합이라면 1에 의해 $2$가 가역원이거나 영인자여야 하기 때문이다.
