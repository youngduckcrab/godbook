:::exercise[13860 을 나누는 소수]
1. $84 \cdot 165 = 13860$이다. $13860$을 작은 것부터 늘어놓인 소수의 열의 곱으로 나타내고, 곱을 앞에서부터 계산해 검산하라.
2. $13860$을 나누는 소수는 정확히 $2, 3, 5, 7, 11$임을 보여라.
3. $13$은 $13860$을 나누는가? $13860$을 $13$으로 나누어 보지 말고 2를 써서 답하라.
:::

:::solution
먼저 $2, 3, 5, 7, 11$이 소수임을 확인한다. 정수 $d$, $k$와 자연수 $p$가 $dk < p < d(k + 1)$을 만족하고 $d > 0$이면 $p = dm$인 정수 $m$은 없다. [[well-ordering-principle|정렬 원리]]의 (Z5)와 [[prime-number|소수]] 항목의 (Z1)에 의해 $m \le k$이거나 $m \ge k + 1$이고, (Z3)에 의해 각각 $dm \le dk < p$, $dm \ge d(k + 1) > p$이기 때문이다. 양의 약수는 $p$ 이하이므로([[prime-number|소수]] 항목의 진술) $2 \le d \le p - 1$인 $d$만 보면 된다. $3$은 $d = 2$에서 $2 < 3 < 4$이다. $5$는 $d = 2$에서 $4 < 5 < 6$, $d = 3$에서 $3 < 5 < 6$, $d = 4$에서 $4 < 5 < 8$이다. $7$은 $d = 2$에서 $6 < 7 < 8$, $d = 3$에서 $6 < 7 < 9$, $4 \le d \le 6$에서 $d < 7 < 2d$이다. $11$은 $d = 2$에서 $10 < 11 < 12$, $d = 3$에서 $9 < 11 < 12$, $d = 4$에서 $8 < 11 < 12$, $d = 5$에서 $10 < 11 < 15$, $6 \le d \le 10$에서 $d < 11 < 2d$이다. $2$는 $2 \le d \le 1$인 $d$가 없다. 따라서 다섯 수 모두 양의 약수가 $1$과 자신뿐이어서 소수이다.

1. $84 = 2 \cdot 2 \cdot 3 \cdot 7$이고 $165 = 3 \cdot 5 \cdot 11$이므로 인수의 후보로 $2, 2, 3, 3, 5, 7, 11$을 얻는다. 작은 것부터 늘어놓인 소수의 열 $2, 2, 3, 3, 5, 7, 11$의 [[finite-product|유한 곱]]을 정의대로 앞에서부터 계산하면 $2 \cdot 2 = 4$, $4 \cdot 3 = 12$, $12 \cdot 3 = 36$, $36 \cdot 5 = 180$, $180 \cdot 7 = 1260$, $1260 \cdot 11 = 13860$이다. [[fundamental-theorem-of-arithmetic|산술의 기본 정리]]의 (2)에 의해 $13860$을 곱으로 하는 작은 것부터 늘어놓인 소수의 열은 이것 하나뿐이다.

2. 열을 $p_1, \dots, p_7 = 2, 2, 3, 3, 5, 7, 11$이라 하자.
   - 유한 곱의 (P4)에 의해 각 $p_i$는 $p_1 \cdots p_7 = 13860$을 나누므로 $2, 3, 5, 7, 11$은 모두 $13860$을 나누는 소수이다.
   - 거꾸로 소수 $q$가 $13860 = p_1 \cdots p_7$을 나눈다고 하자. [[euclids-lemma|유클리드 보조정리]]의 (2)에 의해 $q \mid p_i$인 $i$가 있다. $q$는 양의 정수이므로 소수 $p_i$의 양의 약수이고, 따라서 $q = 1$ 또는 $q = p_i$이다. $q$는 소수이므로 $q \ne 1$이다(소수의 정의에서 $1$은 소수가 아니다). 따라서 $q = p_i$이고 $q$는 $2, 3, 5, 7, 11$ 가운데 하나이다.

3. 나누지 않는다. $13$은 소수이다. 위와 같이 $d = 2, \dots, 6$에서 $12 < 13 < 14$, $12 < 13 < 15$, $12 < 13 < 16$, $10 < 13 < 15$, $12 < 13 < 18$이고 $7 \le d \le 12$에서 $d < 13 < 2d$이기 때문이다. $13$이 $13860$을 나눈다면 2에 의해 $13$은 $2, 3, 5, 7, 11$ 가운데 하나여야 하는데 그렇지 않다.
:::

:::exercise[서로 다른 소수들이 모두 나누는 수]
1. $p$, $q$가 서로 다른 소수이면 $\gcd(p, q) = 1$임을 보이고, 정수 $n$에 대하여 $p \mid n$이고 $q \mid n$이면 $pq \mid n$임을 보여라.
2. $p$, $q$, $r$이 서로 다른 세 소수이고 정수 $n$이 $p \mid n$, $q \mid n$, $r \mid n$을 만족하면 $pqr \mid n$임을 보여라. 여기서 $pqr$은 열 $p, q, r$의 [[finite-product|유한 곱]] $(pq)r$이다.
:::

:::solution
소수 $p$의 양의 약수는 $1$과 $p$뿐이고 소수는 $1$이 아니다([[prime-number|소수]]의 정의).

1. $p$, $q$는 자연수이므로 둘 다 $0$은 아니다. $d$를 $p$와 $q$의 양의 공약수라 하자. $d$는 $p$의 양의 약수이므로 $d = 1$ 또는 $d = p$이다. $d = p$라면 $p$는 $q$의 양의 약수이므로 $p = 1$ 또는 $p = q$인데, 소수는 $1$이 아니고 $p \ne q$이므로 어느 것도 아니다. 따라서 $d = 1$이다. [[greatest-common-divisor|최대공약수]]의 성질 (i)에 의해 $\gcd(p, q)$는 양의 공약수이므로 $\gcd(p, q) = 1$이다.

   이제 $p \mid n$이고 $q \mid n$이면 [[coprime-divisors-product-divides|서로소인 두 약수의 곱은 약수이다]]를 $a = p$, $b = q$에 써서 $pq \mid n$이다.

2. 먼저 $\gcd(pq, r) = 1$을 보인다. $r$은 자연수이므로 $pq$와 $r$은 둘 다 $0$은 아니다. $d$를 $pq$와 $r$의 양의 공약수라 하자. $d$는 $r$의 양의 약수이므로 $d = 1$ 또는 $d = r$이다. $d = r$이라면 $r \mid pq$이고 [[euclids-lemma|유클리드 보조정리]]의 (1)에 의해 $r \mid p$ 또는 $r \mid q$이다. $r \mid p$이면 $r$은 $p$의 양의 약수이므로 $r = 1$ 또는 $r = p$인데 둘 다 아니다. $r \mid q$이어도 같은 이유로 $r = 1$ 또는 $r = q$여야 하는데 둘 다 아니다. 따라서 $d = 1$이고, 1에서처럼 $\gcd(pq, r) = 1$이다.

   1에 의해 $pq \mid n$이고 가정에서 $r \mid n$이다. 1에서 쓴 정리(서로소인 두 약수의 곱은 약수이다)를 $a = pq$, $b = r$에 쓰면 $(pq) r \mid n$이다. 유한 곱의 정의에 의해 길이 $3$인 열의 곱은 $p q r = (pq) \cdot r$이므로 $pqr \mid n$이다.

   예를 들어 $2$, $3$, $5$가 모두 $n$을 나누면 $30 \mid n$이다. 1에서 "서로 다른"이라는 가정은 $\gcd(p, q) = 1$을 보이는 데서 쓰였다. $p = q = 2$, $n = 2$이면 $2 \mid 2$이지만 $pq = 4$이고 $4 \cdot 0 < 2 < 4 \cdot 1$이므로 $4 \nmid 2$이다.
:::

:::exercise[소수들의 곱에서 1 을 뺀 수]
1. $n$이 자연수이고 $p_1, \dots, p_n$이 소수이며 곱 $P = p_1 \cdots p_n$이 $P \ge 3$을 만족한다고 하자. $P - 1$을 나누고 $p_1, \dots, p_n$ 어느 것과도 다른 소수 $q$가 있음을 보여라.
2. 1에서 $P \ge 3$이라는 가정을 빼면 결론이 성립하지 않는 $n$과 $p_1, \dots, p_n$의 예를 들어라.
:::

:::solution
1. $P \ge 3$의 양변에서 $1$을 빼면 [[well-ordering-principle|정렬 원리]]의 (Z7)에 의해 $P - 1 \ge 2$이다. $P$는 [[finite-product|유한 곱]]의 (P1)에 의해 정수이므로 $P - 1$도 정수이다. [[prime-factorization-exists|소인수분해의 존재]]에 의해 소수 $q_1, \dots, q_\ell$($\ell \ge 1$)이 있어 $P - 1 = q_1 \cdots q_\ell$이다. $q = q_1$로 두면 유한 곱의 (P4)에 의해 $q \mid P - 1$이다.

   [[proof-by-contradiction|귀류법]]으로, 어떤 $i$에 대하여 $q = p_i$라 하자. 유한 곱의 (P4)에 의해 $p_i \mid P$이므로 $P = qs$, $P - 1 = qt$인 정수 $s$, $t$가 있고 $1 = P - (P - 1) = q(s - t)$이다. $s - t$는 정수이므로 $q \mid 1$이고, $q$는 자연수 $1$의 양의 약수이다. [[prime-number|소수]] 항목의 진술에 의해 $q \le 1$이다. 그런데 $q$는 소수이므로 $q \ne 1$이고, (Z1)에 의해 $q \ge 1$이므로 $q > 1$이다. $q \le 1$과 $1 < q$는 정렬 원리의 (L1)에 의해 함께 성립하지 않으므로 모순이다. 따라서 모든 $i$에 대하여 $q \ne p_i$이다.

   예를 들어 $3$, $5$이면 $P = 15$, $P - 1 = 14 = 2 \cdot 7$이고 $q = 2$이다. $2$, $2$이면 $P = 4$, $P - 1 = 3$이고 $q = 3$이다.

2. $n = 1$, $p_1 = 2$이면 $P = 2$이고 $P - 1 = 1$이다. $1$을 나누는 소수 $q$가 있다면 1에서처럼 $q \le 1 < q$가 되어 모순이므로, $1$을 나누는 소수는 없다. 따라서 결론이 성립하지 않는다. 1의 증명에서 $P \ge 3$은 $P - 1 \ge 2$로 [[prime-factorization-exists|소인수분해의 존재]]를 쓰는 곳에서만 쓰였다.
:::

:::exercise[서로소인 두 수의 합과 곱]
$a$, $b$가 둘 다 $0$은 아닌 정수이고 $\gcd(a, b) = 1$이면, $a + b$와 $ab$도 둘 다 $0$은 아니고 $\gcd(a + b, ab) = 1$임을 보여라.
:::

:::solution
*둘 다 $0$은 아니다.* $ab = 0$이라 하자. [[integer-cancellation|정수 곱셈의 소거 법칙]]의 (1)에 의해 $a = 0$ 또는 $b = 0$이다. $a = 0$이면 가정에 의해 $b \ne 0$이므로 $a + b = b \ne 0$이다. $b = 0$이면 $a \ne 0$이므로 $a + b = a \ne 0$이다. 따라서 $ab = 0$이면 $a + b \ne 0$이다.

*$\gcd(a + b, ab) = 1$이다.* $g = \gcd(a + b, ab)$라 하자. [[greatest-common-divisor|최대공약수]]의 성질 (i)에 의해 $g \ge 1$이다. [[proof-by-contradiction|귀류법]]으로 $g \ne 1$이라 하자. 그러면 $g > 1$이고 [[prime-number|소수]] 항목의 (Z1)에 의해 $g \ge 2$이다. [[prime-factorization-exists|소인수분해의 존재]]에 의해 $g = p_1 \cdots p_\ell$인 소수 $p_1, \dots, p_\ell$이 있고, $p = p_1$로 두면 [[finite-product|유한 곱]]의 (P4)에 의해 $p \mid g$이다. $g \mid ab$이고 $g \mid a + b$이므로 [[divisibility-is-transitive|나누어떨어짐의 추이성]]에 의해 $p \mid ab$이고 $p \mid a + b$이다. [[euclids-lemma|유클리드 보조정리]]의 (1)에 의해 $p \mid a$ 또는 $p \mid b$이다.

- $p \mid a$인 경우: $a + b = ps$, $a = pt$인 정수 $s$, $t$가 있고 $b = (a + b) - a = p(s - t)$이므로 $p \mid b$이다.
- $p \mid b$인 경우: $a + b = ps$, $b = pt$인 정수 $s$, $t$가 있고 $a = (a + b) - b = p(s - t)$이므로 $p \mid a$이다.

어느 경우든 $p$는 $a$와 $b$의 공약수이므로 최대공약수의 정의의 조건 2에 의해 $p \le \gcd(a, b) = 1$이다. 그런데 $p$는 소수이므로 $p \ne 1$이고 (Z1)에 의해 $p \ge 1$이어서 $1 < p$이다. $p \le 1$과 $1 < p$는 [[well-ordering-principle|정렬 원리]]의 (L1)에 의해 함께 성립하지 않으므로 모순이다. 따라서 $g = 1$이다.

예를 들어 $a = 4$, $b = 9$이면 $a + b = 13$, $ab = 36$이다. $13$의 양의 약수는 $1$과 $13$뿐이고($13$이 소수라는 것은 문제 1의 3) $13 \nmid 36$($26 < 36 < 39$)이므로 $\gcd(13, 36) = 1$이다.
:::

:::exercise[두 소수의 곱의 양의 약수]
$p$, $q$가 서로 다른 소수일 때, $pq$의 양의 약수는 정확히 $1, p, q, pq$이고 이 넷은 서로 다름을 보여라.
:::

:::solution
*넷은 $pq$의 양의 약수이다.* $p$, $q$는 양의 정수이므로 $pq$도 양의 정수이다([[finite-product|유한 곱]]의 (P5)). $pq = 1 \cdot (pq) = p \cdot q = q \cdot p = (pq) \cdot 1$이므로 $1$, $p$, $q$, $pq$는 모두 $pq$를 나눈다.

*다른 양의 약수는 없다.* $d$를 $pq$의 양의 약수라 하고 $d \ne 1$이라 하자. [[prime-number|소수]] 항목의 (Z1)에 의해 $d \ge 1$이므로 $d > 1$이고 다시 (Z1)에 의해 $d \ge 2$이다. [[prime-factorization-exists|소인수분해의 존재]]와 유한 곱의 (P4)에 의해 $d$를 나누는 소수 $s$가 있다. [[divisibility-is-transitive|나누어떨어짐의 추이성]]에 의해 $s \mid pq$이고, [[euclids-lemma|유클리드 보조정리]]의 (1)에 의해 $s \mid p$ 또는 $s \mid q$이다. $s$는 양의 정수이므로 $s \mid p$이면 소수 $p$의 양의 약수, $s \mid q$이면 소수 $q$의 양의 약수이다. 소수는 $1$이 아니므로 $s \ne 1$이고, 따라서 $s = p$ 또는 $s = q$이다.

- $s = p$인 경우: $d = pe$인 정수 $e$가 있다. $d \mid pq$이므로 $pq = df$인 정수 $f$가 있고 $pq = p(ef)$이다. $p \ne 0$이므로 [[integer-cancellation|정수 곱셈의 소거 법칙]]의 (2)에 의해 $q = ef$이다. 또 $e > 0$이다. $e \le 0$이면 (Z2)에 의해 $d = pe \le 0$이 되어 $d > 0$과 함께 성립하지 않기 때문이다([[well-ordering-principle|정렬 원리]]의 (Z5)). 따라서 $e$는 $q$의 양의 약수이고 $e = 1$ 또는 $e = q$이다. 곧 $d = p$ 또는 $d = pq$이다.
- $s = q$인 경우: $d = qe$인 정수 $e$가 있고 $pq = df$인 정수 $f$가 있다. 곱셈의 교환·결합법칙으로 $qp = pq = q(ef)$이고 $q \ne 0$이므로 소거 법칙의 (2)에 의해 $p = ef$이다. 위와 같이 $e > 0$이므로 $e$는 $p$의 양의 약수이고 $e = 1$ 또는 $e = p$이다. 곧 $d = q$ 또는 $d = qp = pq$이다.

따라서 $pq$의 양의 약수는 $1, p, q, pq$ 가운데 하나이다.

*넷은 서로 다르다.* 소수는 $1$이 아니므로 $p \ne 1$, $q \ne 1$이고 가정에서 $p \ne q$이다. $p \ge 2$이고 $q \ge 2$이므로(소수는 $1$보다 큰 정수이고 (Z1)) 유한 곱의 (P5)의 둘째 주장에 의해 $p < pq$, $q < pq$이다. 따라서 $pq \ne p$, $pq \ne q$이고, $1 < p < pq$이므로(정렬 원리의 (Z6)) $pq \ne 1$이다.

예를 들어 $77 = 7 \cdot 11$의 양의 약수는 $1, 7, 11, 77$이다.
:::

:::exercise[참처럼 보이는 두 명제의 반례]
다음 두 명제가 거짓임을 반례로 보여라.

1. 정수 $a$, $b$, $c$가 $\gcd(a, b) = 1$이고 $\gcd(a, c) = 1$이면 $\gcd(b, c) = 1$이다.
2. 소수 $p$와 정수 $a$, $b$가 $p \mid a + b$를 만족하면 $p \mid a$ 또는 $p \mid b$이다.
:::

:::solution
1. $a = 2$, $b = 3$, $c = 9$로 둔다. $2$의 양의 약수는 $1, 2$이고 $2 \nmid 3$($2 < 3 < 4$), $2 \nmid 9$($8 < 9 < 10$)이므로 $2$와 $3$, $2$와 $9$의 양의 공약수는 $1$뿐이어서 $\gcd(2, 3) = 1$, $\gcd(2, 9) = 1$이다([[greatest-common-divisor|최대공약수]]의 성질 (i)에 의해 최대공약수는 양의 공약수이다). 그런데 $3$의 양의 약수 $1, 3$은 모두 $9 = 3 \cdot 3$을 나누므로 $\gcd(3, 9) = 3 \ne 1$이다. 따라서 명제는 거짓이다.

   이 예에서는 $b$와 $c$가 각각 $a$와 서로소이지만 $b$와 $c$끼리는 서로소가 아니다.

2. $p = 5$, $a = 2$, $b = 3$으로 둔다. $5$는 소수이고(문제 1의 풀이 첫 문단) $a + b = 5 = 5 \cdot 1$이므로 $5 \mid a + b$이다. 그러나 $5 \cdot 0 < 2 < 5 \cdot 1$, $5 \cdot 0 < 3 < 5 \cdot 1$이므로 문제 1의 풀이 첫 문단과 같은 이유로 $5 \nmid 2$, $5 \nmid 3$이다. 따라서 명제는 거짓이다. [[euclids-lemma|유클리드 보조정리]]의 (1)은 곱 $ab$에 대한 것이다.
:::
