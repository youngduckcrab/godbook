:::exercise[자연수의 짧은 구간들로 된 집합족]
자연수 $n$마다 $D(n) = \{m \in \mathbb{N} : n \le m \le n + 2\}$라 하고, 식으로 정한 $\mathbb{N}$의 집합족 $\mathcal{D} = \{D(n) : n \in \mathbb{N}\}$을 생각한다.

1. $\bigcup \mathcal{D} = \mathbb{N}$임을 보여라.
2. $\bigcap \{D(n) : n \in \{1, 2\}\}$와 $\bigcap \{D(n) : n \in \{1, 4\}\}$를 구하라.
3. $T = \emptyset$일 때 $\{D(n) : n \in T\}$는 어떤 집합족인가? 그것을 $\mathbb{N}$의 집합족으로 본 교집합은 무엇인가?
:::

:::solution
$D(n)$은 조건으로 정한 $\mathbb{N}$의 부분집합이므로, $\mathcal{D}$는 [[family-of-sets|집합족]]의 "식으로 정한 집합족"으로 읽은 $\mathbb{N}$의 집합족이다. 교집합은 모두 $\mathbb{N}$의 집합족으로 본 것이다. 자연수는 양의 정수이고([[natural-numbers-are-infinite|자연수의 집합에 관한 정리]]의 진술), 정수의 부등식은 [[order-properties-of-reals|실수의 순서의 성질]]의 (10)에 의해 실수의 부등식으로 읽어도 된다.

**(1)** 집합족의 정의에 의해 $\bigcup \mathcal{D} \subseteq \mathbb{N}$이다. 거꾸로 $m \in \mathbb{N}$이라 하자. 순서의 성질 (1)의 (iv)에 의해 $m \le m$이고, $0 < 2$이므로 같은 (2)의 (ii)에 의해 $m + 0 < m + 2$, 곧 $m < m + 2$이다. 따라서 $m \in D(m)$이고, 집합족의 (9)에 의해 $m \in \bigcup \mathcal{D}$이다. 두 포함에서 $\bigcup \mathcal{D} = \mathbb{N}$이다.

**(2)** 식으로 정한 집합족의 정의에 의해, 집합 $C$가 $\{D(n) : n \in \{1, 2\}\}$의 원소인 것은 정확히 $C = D(1)$이거나 $C = D(2)$일 때이다. 따라서 이 집합족은 $\{D(1), D(2)\}$이고, 집합족의 (3)에 의해 그 교집합은 $D(1) \cap D(2)$이다.

$m \in D(1) \cap D(2)$이면 $1 \le m \le 3$이고 $2 \le m \le 4$이므로 $2 \le m \le 3$이다. 거꾸로 자연수 $m$이 $2 \le m \le 3$이면 $1 < 2 \le m$에서 $1 \le m$이고 $m \le 3 < 4$에서 $m \le 4$이므로(순서의 성질 (1)의 (v)) $m \in D(1) \cap D(2)$이다. 자연수 $m$이 $2 \le m \le 3$이고 $m \ne 2$이면 $2 < m$이므로 [[prime-number|소수]]의 (Z1)에 의해 $3 \le m$이고, [[well-ordering-principle|정렬 원리]]의 (L2)에 의해 $m = 3$이다. 거꾸로 $2$와 $3$은 $2 \le m \le 3$을 만족한다. 따라서
$$
\begin{aligned}
&\bigcap \{D(n) : n \in \{1, 2\}\}\\
&\quad = D(1) \cap D(2) = \{2, 3\}
\end{aligned}
$$
이다.

같은 방식으로 $\{D(n) : n \in \{1, 4\}\} = \{D(1), D(4)\}$이고 그 교집합은 $D(1) \cap D(4)$이다. $m \in D(1) \cap D(4)$라면 $m \le 3$이고 $4 \le m$이어서 $4 \le m \le 3$, 곧 $4 \le 3$인데(순서의 성질 (1)의 (v)), 이는 $3 < 4$와 함께 순서의 성질 (1)의 (i)에 어긋난다. 따라서 $\bigcap \{D(n) : n \in \{1, 4\}\} = \emptyset$이다.

**(3)** $T = \emptyset$이면 $C = D(t)$인 $t \in T$가 있을 수 없으므로, 식으로 정한 집합족의 정의에 의해 $\{D(n) : n \in \emptyset\}$은 원소가 없는 집합족, 곧 빈 집합족 $\emptyset$이다. 집합족의 "빈 집합족" 단락에 의해 그 교집합은 $\mathbb{N}$이다.

$\emptyset \subseteq \{D(1), D(2)\}$이고 두 교집합은 $\mathbb{N} \supseteq \{2, 3\}$이다. 집합족이 커지면 교집합이 작아진다는 집합족의 (4)와 맞는다. 원소가 없는 집합족의 교집합이 가장 크다.
:::

:::exercise[실수로 옮겨 재는 거리]
$X$가 집합이고 $f : X \to \mathbb{R}$가 함수일 때, $e(x, y) = |f(x) - f(y)|$로 정한 함수 $e : X \times X \to \mathbb{R}$를 생각한다.

1. $e$가 거리의 조건 (i), (iii), (iv)를 만족함을 보여라.
2. $(X, e)$가 거리공간인 것은 정확히 $f$가 단사일 때임을 보여라.
3. $X = \mathbb{N}$이고 $f(n) = 1/n$일 때 $(\mathbb{N}, e)$가 거리공간임을 확인하고, $e(2, 3)$과 열린 공 $B_e(1, 1/2)$를 구하라.
:::

:::solution
$e$는 [[recursion-theorem|재귀 정리]]의 (1)의 뜻으로 식으로 정한 함수이다. 거리의 조건 (i)–(iv)는 [[metric-space|거리공간]]의 것이고, 절댓값의 성질은 [[absolute-value|절댓값]]의 번호로 인용한다.

**(1)** $x$, $y$, $z$가 $X$의 원소라 하자.
- (i) 절댓값의 (2)에 의해 $0 \le |f(x) - f(y)| = e(x, y)$이다.
- (iii) 절댓값의 (3)에 의해 $|f(x) - f(y)| = |f(y) - f(x)|$, 곧 $e(x, y) = e(y, x)$이다.
- (iv) [[triangle-inequality|삼각부등식]]의 (4)를 세 실수 $f(x)$, $f(y)$, $f(z)$에 쓰면 $|f(x) - f(z)| \le |f(x) - f(y)| + |f(y) - f(z)|$, 곧 $e(x, z) \le e(x, y) + e(y, z)$이다.

**(2)** 먼저 $x$, $y \in X$에 대하여 $e(x, y) = 0$인 것은 정확히 $f(x) = f(y)$일 때임을 본다. 절댓값의 (2)에 의해 $e(x, y) = 0$인 것은 정확히 $f(x) - f(y) = 0$일 때이고, [[real-number-arithmetic|실수의 계산 법칙]]의 (K12)의 (v)에 의해 이것은 정확히 $f(x) = f(y)$일 때이다.

$f$가 단사라 하자. $e(x, y) = 0$이면 $f(x) = f(y)$이고, [[injective-surjective-bijective|단사, 전사, 전단사]]의 단사의 동치 꼴에 의해 $x = y$이다. 거꾸로 $x = y$이면 $f(x) = f(y)$이므로 $e(x, y) = 0$이다. 따라서 (ii)가 성립하고, (1)과 함께 $(X, e)$는 거리공간이다.

거꾸로 $(X, e)$가 거리공간이라 하자. $f(x) = f(y)$이면 $e(x, y) = 0$이고 (ii)에 의해 $x = y$이다. 단사의 동치 꼴에 의해 $f$는 단사이다.

**(3)** 단사: $n$, $m$이 서로 다른 자연수라 하자. [[well-ordering-principle|정렬 원리]]의 (Z5)에 의해 $n < m$이거나 $m < n$이다. $n < m$이면 [[order-properties-of-reals|실수의 순서의 성질]]의 (10)에 의해 $0 < n < m$이고 (6)의 (ii)에 의해 $1/m < 1/n$이므로 (1)의 (i)에 의해 $1/n \ne 1/m$이다. $m < n$이어도 같다. 따라서 $f$는 단사이고, (2)에 의해 $(\mathbb{N}, e)$는 거리공간이다.

$e(2, 3)$: $1/2 - 1/3 = 3/6 - 2/6 = 1/6$이고 $0 < 1/6$이므로 절댓값의 (1)에 의해 $e(2, 3) = 1/6$이다.

$B_e(1, 1/2)$: [[open-ball|열린 공]]의 정의에 의해 자연수 $m$이 $B_e(1, 1/2)$에 드는 것은 정확히 $|1 - 1/m| < 1/2$일 때이다. (Z1)에 의해 $1 \le m$이므로, $m = 1$이면 $1/m = 1$이고 $1 < m$이면 순서의 성질 (6)의 (ii)에 의해 $1/m < 1$이다. 어느 쪽이든 $1/m \le 1$이고, 순서의 성질 (3)의 (i)에 의해 $0 \le 1 - 1/m$이므로 절댓값의 (1)에 의해 $|1 - 1/m| = 1 - 1/m$이다. 순서의 성질 (2)의 (ii)로 양변에 $1/m - 1/2$를 더하면 $1 - 1/m < 1/2$인 것은 정확히 $1/2 < 1/m$일 때이다. $0 < 2m$이므로 (6)의 (iv)로 양변에 $2m$을 곱하면 이것은 정확히 $m < 2$일 때이다. $m < 2$이면 (Z1)에 의해 $m + 1 \le 2$, 곧 $m \le 1$이고, $1 \le m$과 (L2)에 의해 $m = 1$이다. 거꾸로 $m = 1$이면 $1 < 2$이다. 따라서 $B_e(1, 1/2) = \{1\}$이다.
:::

:::exercise[두 거리의 최대와 최소]
$d_1$, $d_2$가 집합 $X$ 위의 거리라 하자.

1. $X$의 점 $x$, $y$에서 값이 $\max\{d_1(x, y),\ d_2(x, y)\}$인 함수 $m : X \times X \to \mathbb{R}$는 $X$ 위의 거리임을 보여라.
2. 값이 $\min\{d_1(x, y),\ d_2(x, y)\}$인 함수는 거리가 아닐 수 있음을, 세 점으로 된 집합 위의 두 거리로 보여라.
:::

:::solution
거리의 조건 (i)–(iv)는 [[metric-space|거리공간]]의 것이고, 두 수의 최대와 최소의 성질은 [[absolute-value|절댓값]]의 (10)이다. $m$은 [[recursion-theorem|재귀 정리]]의 (1)의 뜻으로 식으로 정한 함수이다.

**(1)** $x$, $y$, $z$가 $X$의 점이라 하자.
- (i) 절댓값의 (10)에 의해 $d_1(x, y) \le m(x, y)$이고, $d_1$의 (i)에 의해 $0 \le d_1(x, y)$이므로 [[order-properties-of-reals|실수의 순서의 성질]]의 (1)의 (v)에 의해 $0 \le m(x, y)$이다.
- (ii) $x = y$이면 $d_1(x, y) = d_2(x, y) = 0$이고, 절댓값의 (10)에 의해 $m(x, y)$는 둘 가운데 하나이므로 $0$이다. 거꾸로 $m(x, y) = 0$이면 $0 \le d_1(x, y) \le m(x, y) = 0$이므로 순서의 성질 (1)의 (ii)에 의해 $d_1(x, y) = 0$이고, $d_1$의 (ii)에 의해 $x = y$이다.
- (iii) $d_1(x, y) = d_1(y, x)$이고 $d_2(x, y) = d_2(y, x)$이므로 $m(x, y)$와 $m(y, x)$는 같은 두 수의 최대이다.
- (iv) $d_1$의 (iv)와 절댓값의 (10)에 의해 $d_1(x, z) \le d_1(x, y) + d_1(y, z)$이고 $d_1(x, y) \le m(x, y)$, $d_1(y, z) \le m(y, z)$이다. 순서의 성질 (2)의 (iii)과 (1)의 (v)에 의해 $d_1(x, z) \le m(x, y) + m(y, z)$이다. 같은 방식으로 $d_2(x, z) \le m(x, y) + m(y, z)$이다. 두 수가 모두 $m(x, y) + m(y, z)$ 이하이므로 절댓값의 (10)에 의해 $m(x, z) \le m(x, y) + m(y, z)$이다.

따라서 $m$은 $X$ 위의 거리이다.

**(2)** $p$, $q$, $s$가 서로 다른 세 대상이고 $X = \{p, q, s\}$라 하자. 두 함수 $d_1$, $d_2$를 같은 점의 쌍에서는 $0$으로, 서로 다른 두 점의 쌍에서는 순서에 상관없이 다음 표의 값으로 정한다.

| 쌍 | $\{p, q\}$ | $\{q, s\}$ | $\{p, s\}$ |
|---|---|---|---|
| $d_1$ | $1$ | $4$ | $4$ |
| $d_2$ | $4$ | $1$ | $4$ |

$X \times X$의 아홉 원소마다 값을 하나씩 적었으므로 둘 다 함수이고, 표의 값이 모두 양수이므로 (i), (ii), (iii)이 성립한다. (iv) $d(x, z) \le d(x, y) + d(y, z)$는, $x = z$이면 왼쪽이 $0$이라 성립하고, $y = x$이거나 $y = z$이면 오른쪽의 한 항이 $0$이고 다른 항이 왼쪽과 같아서 성립한다. 남은 것은 $x$, $y$, $z$가 서로 다른 경우이고, (iii)에 의해 $\{x, z\}$가 어느 쌍인지만 보면 된다.

- $d_1$: $\{p, s\}$의 값 $4 \le 1 + 4 = d_1(p, q) + d_1(q, s)$, $\{p, q\}$의 값 $1 \le 4 + 4$, $\{q, s\}$의 값 $4 \le 1 + 4 = d_1(q, p) + d_1(p, s)$.
- $d_2$: $\{p, s\}$의 값 $4 \le 4 + 1 = d_2(p, q) + d_2(q, s)$, $\{p, q\}$의 값 $4 \le 4 + 1 = d_2(p, s) + d_2(s, q)$, $\{q, s\}$의 값 $1 \le 4 + 4$.

따라서 $d_1$, $d_2$는 $X$ 위의 거리이다. 그런데 값이 최소인 함수 $n$은 $n(p, q) = 1$, $n(q, s) = 1$, $n(p, s) = 4$이고 $4 > 2 = n(p, q) + n(q, s)$이므로 거리의 삼각부등식 (iv)가 깨진다. 최소는 (i), (ii), (iii)은 지키지만, 두 거리가 서로 다른 쌍에서 작아질 때 둘의 작은 값을 이어 붙인 길이 너무 짧아질 수 있다.
:::

:::exercise[최대 거리로 본 평면에서 첫 성분이 더 작은 점들]
곱집합 $\mathbb{R} \times \mathbb{R}$에 최대 거리 $d_{\max}$를 준다.
$$
\begin{aligned}
U &= \{(s, t) \in \mathbb{R} \times \mathbb{R} : s < t\},\\
F &= \{(s, t) \in \mathbb{R} \times \mathbb{R} : s \le t\}
\end{aligned}
$$
라 할 때, $U$는 열린집합이고 $F$는 닫힌집합임을 보여라.
:::

:::solution
최대 거리는 [[metric-space-examples|거리공간의 예]]의 (5)의 것이고, 열린집합과 닫힌집합은 [[open-set-in-metric-space|거리공간의 열린집합과 닫힌집합]]의 정의대로 읽는다. 실수의 계산과 순서는 [[real-number-arithmetic|실수의 계산 법칙]]과 [[order-properties-of-reals|실수의 순서의 성질]]의 번호로 인용한다.

**$U$는 열린집합이다.** $p = (p_1, p_2) \in U$라 하자. $p_1 < p_2$이므로 순서의 성질 (3)의 (i)에 의해 $0 < p_2 - p_1$이고, 같은 (8)에 의해 $r = (p_2 - p_1)/2$는 양수이다. $r + r = p_2 - p_1$이므로 $p_1 + r + r = p_2$, 곧 $p_1 + r = p_2 - r$이다.

[[open-ball|열린 공]]의 (8)에 의해, 열린구간 $I = (p_1 - r, p_1 + r)$과 $J = (p_2 - r, p_2 + r)$에 대하여 $B(p, r) = I \times J$이다. $(s, t) \in B(p, r)$이면 $s \in I$이고 $t \in J$이므로 $s < p_1 + r = p_2 - r < t$이고, 순서의 성질 (1)의 (v)에 의해 $s < t$이다. 따라서 $B(p, r) \subseteq U$이다. $U$의 모든 점에서 이런 공이 있으므로 $U$는 열린집합이다.

**$F$는 닫힌집합이다.** 순서의 성질 (1)의 (iii)에 의해 "$s \le t$"가 성립하지 않는 것은 정확히 $t < s$일 때이므로
$$
\begin{aligned}
&(\mathbb{R} \times \mathbb{R}) - F\\
&\quad = \{(s, t) \in \mathbb{R} \times \mathbb{R} : t < s\}
\end{aligned}
$$
이다. 이 집합의 점 $p = (p_1, p_2)$에서는 $p_2 < p_1$이고, 위와 같이 $r = (p_1 - p_2)/2$로 두면 $0 < r$이고 $p_2 + r = p_1 - r$이다. $(s, t) \in B(p, r) = (p_1 - r, p_1 + r) \times (p_2 - r, p_2 + r)$이면 $t < p_2 + r = p_1 - r < s$이므로 $t < s$이다. 따라서 $(\mathbb{R} \times \mathbb{R}) - F$는 열린집합이고, 닫힌집합의 정의에 의해 $F$는 닫힌집합이다.
:::

:::exercise[두 공 사이의 고리]
$(X, d)$가 거리공간이고 $x \in X$이며 $r$, $s$가 양의 실수라 하자.
$$
\begin{aligned}
R &= \{y \in X : r < d(x, y) < s\},\\
K &= \{y \in X : r \le d(x, y) \le s\}
\end{aligned}
$$
로 둔다.

1. $R$은 열린집합이고 $K$는 닫힌집합임을 보여라.
2. $\mathbb{R}$에 보통 거리를 주고 $x = 0$, $r = 1$, $s = 2$일 때 $R$과 $K$를 구간으로 나타내라.
:::

:::solution
열린 공 $B(x, s)$와 닫힌 공 $C(x, s)$는 [[open-ball|열린 공]]의 것이고, 열린집합과 닫힌집합은 [[open-set-in-metric-space|거리공간의 열린집합과 닫힌집합]]의 정의대로 읽는다.

**(1)** $R$. $y \in X$가 $R$에 드는 것은 정확히 $d(x, y) < s$이고 $r < d(x, y)$일 때이므로
$$
R = B(x, s) \cap \{y \in X : r < d(x, y)\}
$$
이다. [[open-ball-is-open|열린 공은 열린집합]]의 (1)에 의해 $B(x, s)$는 열린집합이고, 같은 항목의 (3)에 의해 $\{y \in X : r < d(x, y)\}$는 열린집합이다. [[open-sets-of-a-metric-space|거리공간의 열린집합의 성질]]의 (3)에 의해 $R$은 열린집합이다.

$K$. [[order-properties-of-reals|실수의 순서의 성질]]의 (1)의 (iii)에 의해 $r \le d(x, y)$인 것은 정확히 $d(x, y) < r$가 아닐 때, 곧 $y \notin B(x, r)$일 때이다. 따라서
$$
K = C(x, s) \cap \bigl(X - B(x, r)\bigr)
$$
이다. 열린 공은 열린집합의 (2)에 의해 $C(x, s)$는 닫힌집합이다. 또 $B(x, r) \subseteq X$이므로 $X - (X - B(x, r)) = B(x, r)$이다($y \in X$가 $X - B(x, r)$에 들지 않는 것은 정확히 $y \in B(x, r)$일 때이다). 이 집합이 열린집합이므로 닫힌집합의 정의에 의해 $X - B(x, r)$은 닫힌집합이다. [[family-of-sets|집합족]]의 (3)에 의해 $K = \bigcap \{C(x, s),\ X - B(x, r)\}$이고, 이것은 닫힌집합 두 개로 된 집합족의 교집합이므로 거리공간의 열린집합의 성질의 (5)의 (ii)에 의해 닫힌집합이다.

이 논증은 $r < s$를 쓰지 않는다. $s \le r$이면 $R = \emptyset$이 되지만 그래도 위 등식과 결론은 그대로 성립한다.

**(2)** 보통 거리에서 $d(0, y) = |0 - y| = |y|$이다([[absolute-value|절댓값]]의 (3)). [[interval|구간]]의 기호로 $R = (-2, -1) \cup (1, 2)$이고 $K = [-2, -1] \cup [1, 2]$임을 보인다. 실수 $y$에 대하여 $0 \le y$이면 절댓값의 (1)에 의해 $|y| = y$이고, $y < 0$이면 $|y| = -y$이다.

- $0 \le y$인 경우: $1 < |y| < 2$인 것은 정확히 $1 < y < 2$일 때이다.
- $y < 0$인 경우: $1 < |y| < 2$인 것은 정확히 $1 < -y < 2$일 때이고, 순서의 성질 (3)의 (iii)에 의해 이것은 정확히 $-2 < y < -1$일 때이다.

$(1, 2)$의 원소는 $0$ 이상이고 $(-2, -1)$의 원소는 $0$보다 작으므로, 두 경우를 합치면 $R = (-2, -1) \cup (1, 2)$이다. 부등호 $<$를 $\le$로 바꾸어 같은 계산을 하면 $K = [-2, -1] \cup [1, 2]$이다.
:::

:::exercise[두 조각으로 된 부분공간에서 열리고 닫힌 조각]
$Y = [0, 1] \cup [2, 3]$에 $\mathbb{R}$의 보통 거리의 부분공간 거리 $d_Y$를 준다.

1. $[0, 1]$은 $(Y, d_Y)$에서 열린집합이면서 닫힌집합임을 보여라.
2. $[0, 1]$은 $\mathbb{R}$(보통 거리)에서 열린집합이 아님을 보여라.
:::

:::solution
부분공간 거리는 [[metric-space-examples|거리공간의 예]]의 (3)의 것이고, 구간의 기호는 [[interval|구간]]의 것이다. 열린집합과 닫힌집합은 [[open-set-in-metric-space|거리공간의 열린집합과 닫힌집합]]의 정의대로 읽는다.

**$Y$의 공.** $y \in Y$이면 [[open-ball|열린 공]]의 (7)과 (5)에 의해
$$
\begin{aligned}
B_Y(y, 1) &= B_{\mathbb{R}}(y, 1) \cap Y\\
&= (y - 1, y + 1) \cap Y
\end{aligned}
$$
이다.

**(1)** 열린집합이다. $y \in [0, 1]$이라 하고 $z \in B_Y(y, 1)$이라 하자. $z < y + 1$이고 $y \le 1$이므로 $z < 2$이다([[order-properties-of-reals|실수의 순서의 성질]]의 (2)의 (i)과 (1)의 (v)). 그러면 $z \notin [2, 3]$이고, $z \in Y$이므로 $z \in [0, 1]$이다. 따라서 $B_Y(y, 1) \subseteq [0, 1]$이고, $[0, 1]$은 $(Y, d_Y)$에서 열린집합이다.

닫힌집합이다. 먼저 $[0, 1] \cap [2, 3] = \emptyset$이다. $z$가 둘 다에 들면 $z \le 1 < 2 \le z$가 되어 순서의 성질 (1)의 (v)에 의해 $z < z$인데, 이는 (1)의 (i)에 어긋난다. 따라서 $Y - [0, 1] = [2, 3]$이다. $y \in [2, 3]$이고 $z \in B_Y(y, 1)$이면 $y - 1 < z$이고 $2 \le y$에서 $1 \le y - 1$이므로 $1 < z$이다. 그러면 $z \notin [0, 1]$이고 $z \in Y$이므로 $z \in [2, 3]$이다. 따라서 $[2, 3] = Y - [0, 1]$은 $(Y, d_Y)$에서 열린집합이고, 닫힌집합의 정의에 의해 $[0, 1]$은 $(Y, d_Y)$에서 닫힌집합이다.

**(2)** $0 < 1$이므로 [[open-and-closed-sets-of-reals|실수의 열린집합과 닫힌집합의 예]]의 (4)에 의해 닫힌구간 $[0, 1]$은 $\mathbb{R}$에서 열린집합이 아니다. 같은 항목의 (2)에 의해 $[0, 1]$은 $\mathbb{R}$에서 닫힌집합이기는 하다.

같은 집합 $[0, 1]$이 $Y$에서는 열려 있고 $\mathbb{R}$에서는 열려 있지 않다. $\mathbb{R}$에서는 점 $1$을 중심으로 하는 공이 모두 $1$보다 큰 점을 품지만, $Y$에서는 $1$과 $2$ 사이에 $Y$의 점이 없어서 반지름 $1$인 공이 $[0, 1]$ 밖으로 나가지 못한다.
:::
